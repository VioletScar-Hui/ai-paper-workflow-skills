# 📊 动态概念索引

> **由 Dataview 自动生成的概念全景视图。** 安装 [Dataview](obsidian://show-plugin?id=dataview) 插件后，以下查询自动从元数据聚合概念状态。

---

## 按成熟度分组

```dataview
TABLE 
  rows.file.link AS 概念,
  length(rows.file.outlinks) AS 出链数,
  length(rows.file.inlinks) AS 入链数
FROM "Wiki/概念"
GROUP BY 成熟度
SORT 成熟度 DESC
```

---

## 概念反向链接统计（入链数排序）

> 入链数 = 多少篇论文笔记链接到此概念。反映概念的知识网络覆盖度。

```dataview
TABLE 
  length(file.inlinks) AS 论文引用数,
  成熟度 AS 状态
FROM "Wiki/概念"
SORT length(file.inlinks) DESC
```

---

## 待完善的概念（成熟度为空或待补充）

```dataview
TABLE 
  file.folder AS 分类,
  length(file.inlinks) AS 论文引用数
FROM "Wiki/概念"
WHERE 成熟度 = null OR 成熟度 = ""
SORT file.folder ASC
```

---

## 强关联概念簇（出链 ≥ 5）

```dataview
TABLE 
  file.folder AS 分类,
  length(file.outlinks) AS 出链数
FROM "Wiki/概念"
WHERE length(file.outlinks) >= 5
SORT length(file.outlinks) DESC
```

---

## 最新更新概念

```dataview
TABLE 
  file.mday AS 最后修改,
  成熟度 AS 状态
FROM "Wiki/概念"
SORT file.mday DESC
LIMIT 15
```

> 💡 **使用方法**：在 Obsidian 中打开此页面，Dataview 插件会自动渲染上述表格。安装方式：设置 → 社区插件 → 搜索 "Dataview" → 安装并启用。
