# 📈 论文进度仪表板

> **论文吸收进度的动态视图。** 依赖 Dataview 插件自动渲染。

---

## 按分类统计论文数

```dataview
TABLE 
  length(rows.file.link) AS 论文数
FROM "Wiki/论文笔记"
GROUP BY file.folder
SORT length(rows.file.link) DESC
```

---

## 按成熟度过滤论文

```dataview
TABLE 
  file.folder AS 分类,
  成熟度 AS 状态,
  authors AS 作者,
  year AS 年份
FROM "Wiki/论文笔记"
WHERE 成熟度 != null
SORT 成熟度 DESC, file.name ASC
```

---

## 最新处理的论文

```dataview
TABLE 
  file.folder AS 分类,
  file.mday AS 最后修改
FROM "Wiki/论文笔记"
SORT file.mday DESC
LIMIT 20
```

---

## 按年份分布

```dataview
TABLE 
  length(rows.file.link) AS 论文数
FROM "Wiki/论文笔记"
GROUP BY year
SORT year DESC
```

---

> 📝 笔记层级字段说明：`骨干` = 完整精读，`标准` = 标准笔记，`速览` = 快速浏览
