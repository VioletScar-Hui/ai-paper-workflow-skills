# 激活函数选择

## 一句话定义
> 激活函数是神经网络能拟合非线性关系的唯一来源；从 sigmoid、tanh 到 ReLU 家族，再到 LLM 主流采用的 SwiGLU，这条演进路线本质上是一部"如何让深层网络的梯度传得动、传得稳"的历史。

---

## 寓言学习

### 寓言正文

鲜榨果汁厂新接了一条"深度过滤"的产线设计要求——原料要连续经过好几道过滤站，才能把果肉纤维彻底滤干净，得到清澈果汁，道数越多理论上滤得越干净。

厂长第一版工艺图纸上，每道站就是一个漏斗，汁液倒进去，原样从下面流出来，不做任何处理，直接接到下一道漏斗。工程师小孙算了一笔账，告诉厂长：不管中间摆几道这种漏斗，最后流出来的东西，跟只摆一道漏斗一模一样——纯倒装不处理，叠多少道都没有意义，那几道站等于白建了。

厂长换了设计，每道站装一层筛网，筛网会把通过的流量按固定比例收窄一些（比如只放行八成，扣下两成）。这次确实不再是纯倒装了，但小孙很快发现新问题：连续过六七道筛网之后，到最后一道流出来的汁液已经细若游丝——各道站扣得都不算多，但一道接一道乘下来，流量早就衰减得所剩无几，最后几道站基本上闲置，滤不出什么东西。

厂长又试了另一种筛网：只要检测到一次纤维堵塞，就判定这道筛网"坏了"，自动永久锁死，往后不管流过来的是不是干净的果汁，这道站从此完全不再放行。这次流量倒是不再一路衰减，可产线运行几天后，巡检发现有小半数的站因为早年某一次意外堵塞，从那以后就一直锁死在关闭状态，即便后来上游换了更干净的原料，这些站也没再打开过。

小孙最后定的方案，是给每道筛网留一条很窄的缝隙——正常放行时按原有比例通过，即便判定为堵塞，也留一条极窄的缝隙持续渗一点点，不完全锁死。这样，既不会因为逐级衰减把流量磨没，堵塞的站也还留着一点点被重新冲开的机会。

### 概念解析

**概念名称**：激活函数选择，属于神经网络基础/深度学习优化问题域。

**学习卡片**
- 核心张力：如果每站只是原样按比例传递（线性），叠多少站效果都等价于一站——真正带来"深度价值"的是站与站之间加入非线性处理；但非线性处理规则本身要在"信号会不会随层数增多逐渐衰减到消失"和"某个处理站会不会因为一次触发就永久失效"之间做取舍。
- 关键不变量：只要处理规则的"响应强度"存在一个持续小于1的上限，多站连续相乘的效果一定是指数衰减；只要处理规则存在"一旦低于某个阈值就完全关闭且不会再打开"的机制，就会有个别站永久失效。
- 触发条件：网络叠加多层、需要通过反向的调整信号（梯度）穿过所有层才能训练时。
- 常见误解/失败模式：选一个"响应总是被压缩变小"的规则，觉得只要叠够多层深度总归有好处，结果层数一深，调整信号在半路就已经衰减到几乎测不出；或者选一个"一旦触发就永久关闭"的规则，图它简单直接，结果一部分处理站永久失效，产能白白浪费。
- 非适用边界：如果网络本身很浅（层数很少），选择哪种非线性处理规则的差异并不明显，不必纠结哪种更抗衰减或更不容易永久失效。

**一句话核心定义**：激活函数是插入线性层之间的非线性函数，没有它多层网络在数学上等价于一层；不同激活函数在"梯度是否会随层数增多而衰减"和"神经元是否会因一次触发就永久失效"之间各有取舍。

**它试图解决的问题**：如何让多层网络真正获得超越单层的表达能力，同时让训练时的梯度能稳定地传过很多层，既不消失也不让部分神经元永久死亡。

**故事元素映射**：
- 多级过滤站 = 神经网络的多层。
- 纯倒装漏斗（无处理） = 没有非线性激活函数的线性堆叠，多层数学上等价于一层。
- 固定比例收窄、连续多道后流量趋近于零的筛网 = sigmoid/tanh 的导数恒小于等于某个上限（sigmoid 导数≤0.25，tanh 导数≤1），梯度反向连乘导致的梯度消失。
- 检测堵塞就永久锁死的筛网 = Dying ReLU：某神经元预激活值一旦恒为负，梯度永久为0，神经元"死掉"。
- 留一条窄缝的筛网 = Leaky ReLU：负区间保留很小的斜率α，修复 Dying ReLU 问题。

**比喻边界**：故事把"梯度反向传播"简化成了"流量顺着同一方向依次衰减"，但真实的梯度消失是**反向**传播时链式法则连乘导数造成的，前向计算（果汁真正流过站点）和反向的调整信号传递是两个方向、两套数值，故事没有区分这两条路径；此外，实际选择激活函数（如现代 LLM 常用的 SwiGLU）还涉及"是否引入门控、两路投影相乘"这类更复杂的设计，不只是"要不要留缝隙"这么简单。

**非适用例**：如果这条产线本来就只有一两道过滤站（网络层数很浅），选哪种筛网设计（固定比例收窄还是留缝隙）差别都不大——衰减或锁死问题只有在道数足够多、连续叠加时才会被放大暴露出来。

**现实例子**：sigmoid 的导数上限是0.25、tanh 的导数上限是1，网络层数一深，这些恒小于等于某个上限的导数连续相乘会指数级衰减，这是早期深层网络训练不稳定的主要原因之一；ReLU 用"要么完全传递、要么完全归零"替代了这种连续收缩，解决了梯度消失，却带来了"某神经元一旦预激活值恒为负就永久拿到0梯度、再也学不动"的 Dying ReLU 问题；Leaky ReLU 在负区间保留一个很小的斜率，让"死掉"的神经元仍有非零梯度可以被重新激活，这正是现代 LLM 最终选用 SwiGLU 这类更精细的门控/平滑激活函数的演进起点。

### 检验问题

1. 理解检验：故事里第二版设计（固定比例收窄的筛网），如果只叠两三道站，还会出现"流量所剩无几"的问题吗？为什么？
2. 迁移检验：如果一个多级审批系统里，每一级审批人只有"通过/驳回"两个选项，一旦某一级驳回过一次，系统就把这一级审批人从后续所有流程里永久移除——你觉得这和故事里哪种筛网设计属于同一类问题？换成"驳回一次并不代表永久移除资格，只是这次审批更谨慎"会对应哪种修正？

## 核心机制

### 为什么没有非线性，多层网络就退化成线性变换

如果层与层之间没有非线性函数，每一层都只是一次矩阵乘法（线性变换）。多层堆叠在数学上可以合并成一次矩阵乘法：

$$W_1(W_2 \mathbf{x}) = (W_1 W_2)\mathbf{x} = W\mathbf{x}$$

也就是说，不管叠多少层纯线性层，最终的表达能力都等价于一层线性层——**加层数没有任何意义**。一旦在层间插入非线性函数，多层网络才能获得远超单层的表达能力，理论上可以逼近任意复杂的函数。这就是激活函数存在的根本原因。

### 常见激活函数

**sigmoid**：$\sigma(x) = \dfrac{1}{1+e^{-x}} \in (0,1)$

- 适合把输出解释为概率，但很少用在隐藏层
- **梯度消失**：其导数 $\sigma(x)(1-\sigma(x)) \le 0.25$，网络层数一深，梯度沿着链式法则连续相乘，很快就衰减到接近 0
- **非零中心**：输出恒为正数，导致同一层里所有神经元的下游梯度符号一致（同正或同负，取决于上游梯度的符号），不利于优化路径的收敛效率

**tanh**：$\tanh(x) = \dfrac{e^x - e^{-x}}{e^x+e^{-x}} = 2\sigma(2x)-1 \in (-1,1)$

- 导数在 $x=0$ 处取得峰值 1.0，比 sigmoid 更好，但仍然会随层数增多而衰减——因为 $\tanh'(x) = 1-\tanh^2(x) \in (0,1]$，永远小于等于 1，连续相乘只会越乘越小，梯度消失问题依然存在，只是比 sigmoid 缓和

**softmax**：把一组实数变成一个概率分布

$$\text{softmax}(\mathbf{x})_i = \frac{e^{x_i}}{\sum_j e^{x_j}}$$

引入温度参数 $T$ 后：

$$\text{softmax}(\mathbf{x}/T)_i = \frac{e^{x_i/T}}{\sum_j e^{x_j/T}}$$

$T$ 越大，分布越平滑（越接近均匀分布）；$T$ 越小，分布越尖锐（越接近 one-hot / argmax）。

**ReLU**：$\text{ReLU}(x) = \max(x,0) \in (0,\infty)$

- 导数在 $x>0$ 时为 1，$x<0$ 时为 0，计算极简单，梯度不会因为连乘而衰减到很小
- **Dying ReLU 问题**：如果某个神经元的预激活值对所有输入都变成了负数，它就会永久性地拿到 0 梯度，再也学不动了——训练过程中，网络的一部分神经元可能就此"死掉"

**Leaky ReLU**：

$$\text{LeakyReLU}(x) = \begin{cases} x & x>0 \\ \alpha x & x \le 0 \end{cases}$$

在负区间保留一个很小的斜率 $\alpha$，从而修复了 dying ReLU 问题（负值区域仍有非零梯度）。

**Swish**（平滑、非单调）：

$$\text{Swish}(x) = x \cdot \sigma(x)$$

**GLU（Gated Linear Unit）**：用一路线性投影产生"内容"，另一路过 sigmoid 产生"门控"，两路逐元素相乘：

$$\text{GLU}(x) = xW_1 \odot \sigma(xW_2)$$

**SwiGLU**：把 Swish 代入 GLU 内部作为门控的激活函数：

$$\text{SwiGLU}(x) = (xW_1) \odot \text{Swish}(xW_2)$$

这是当前主流 LLM（如 LLaMA 系列）FFN 层的标准激活函数选择。

## 为什么 AI PM 要懂这个

- 面试常问"为什么现在的 LLM 都用 SwiGLU 而不是 ReLU"，能讲清楚 dying ReLU、梯度消失这些具体机制是加分项，而不是只会说"效果更好"。
- GLU/SwiGLU 类激活需要额外一路线性投影，会影响 FFN 层的参数量计算，进而影响显存和算力预算的估算。
- softmax 的温度参数直接对应产品里能感知的"生成随机性"调节旋钮——理解这个公式就理解了 API 里 `temperature` 参数的数学来源。
- 帮助判断"某个新模型换了个激活函数"这类技术更新，到底是增量优化还是架构级改动。
