# RoPE 旋转位置编码

## 一句话定义
> RoPE（Rotary Position Embedding）通过在复数空间中对 Query 和 Key 向量施加与位置相关的旋转变换，使注意力分数自然地包含相对位置信息，同时具备外推能力。

## 寓言学习

### 寓言正文

商场中庭立着一座可以旋转的多层陈列架，货品挂在架子外圈的挂钩上。补货员上新货时，不是记"3号挂钩挂什么"，而是记"这款新到的香水，要挂在离主打香水顺时针数第几个挂钩"。这样不管整座架子今天转到哪个起始角度，只要主打香水和新款之间的夹角对了，两款产品在视觉上的相对位置就永远是对的——顾客从哪个方向看过去，主打款和它的搭配款之间的间隔感受都一样，不需要知道架子此刻转到了第几度。

架子起初只有二十个挂钩，角度间距大，补货员凭夹角记忆基本不会挂错。后来商场把陈列架扩容成两百个挂钩，间距变得密集很多，补货员还是按老办法凭手感数夹角，结果新款和主打款之间差了好几个挂钩的位置都挂错了——夹角记忆的方法本身没有问题，问题是挂钩密度远超过当初练手熟悉的那种稀疏架子，手感需要重新校准，不然细小的角度误差会被放大成明显的位置错误。

### 概念解析

**概念名称**：RoPE 旋转位置编码，属于 Transformer 位置信息表示问题域。

**学习卡片**
- 核心张力：记录每件货品的"绝对编号位置"（简单直接，但架子一转起始点变了，编号和实际相对关系就对不上）vs. 记录货品之间的"相对夹角"（不管架子转到哪个起始角度，只要夹角不变，相对位置关系天然保持一致）。
- 关键不变量：两件货品之间的相对位置关系，只由它们之间的夹角决定，与架子当前转到第几度（绝对位置）无关——这个"只看差值、不看绝对值"的性质必须在任何旋转起点下都成立。
- 触发条件：需要表示序列中两个元素之间的相对位置关系，且这种关系应当只依赖于两者的距离/间隔，不依赖它们各自的绝对位置编号时。
- 常见误解/失败模式：以为这套方法可以无限扩展到任意密集或任意长的场景而不用调整——实际上训练/练习时熟悉的角度间距是有限的，超出这个范围很多之后，原有的夹角感知精度会跟着变得粗糙，需要重新校准才能保持准确。
- 非适用边界：如果场景根本不关心"谁和谁隔多远"这种相对关系，只需要知道每个位置绝对是第几号（比如按固定编号严格排序、不允许任意旋转起点），直接用绝对编号反而更直接，用不上这套相对夹角的设计。

**一句话核心定义**：RoPE 通过给每个位置的向量施加一个与位置成比例的旋转角度，使得任意两个位置的向量内积只依赖于它们的相对角度差，从而让注意力天然获得相对位置信息，且具备一定的外推能力。

**它试图解决的问题**：传统的绝对位置编码把位置信息和内容耦合在一起，换一个起始点或换一个长度就容易失真；如何设计一种位置表示方法，让两个 token 之间的关系天然只取决于它们相隔多远，而不是各自绝对站在第几个位置上。

**故事元素映射**：
- 陈列架 = 一整条序列（Query 和 Key 所在的整个位置空间）。
- 每件货品挂钩位置 = 每个 token 的位置。
- 按"离主打香水顺时针第几个挂钩"记忆 = 用旋转角度编码相对位置（RoPE 的核心机制）。
- 架子转到不同起始角度，相对间隔关系不变 = 内积只依赖相对位置差 (m-n)，与绝对位置无关。
- 挂钩从二十个扩容到两百个后手感失准 = 序列长度超出训练时的范围后需要位置插值/重新校准（对应 YaRN、位置插值等外推技术）。

**比喻边界**：故事把"旋转角度"简化成了一个直观的夹角手感，真实的 RoPE 是对高维向量按不同频率分组、每组做一次二维旋转，低频分量转得慢、高频分量转得快，多组频率叠加才共同决定最终的位置编码效果，并非只有一个统一的夹角。

**非适用例**：如果陈列架从不旋转、每个挂钩位置固定对应固定编号（比如按合同规定几号位必须摆哪个品牌），补货员只需要记绝对编号，不需要相对夹角这套设计——这对应某些场景下位置是严格绝对、不需要相对关系表示的情况。

**现实例子**：LLaMA、DeepSeek、Qwen 等主流 LLM 都采用 RoPE 作为位置编码；当上下文长度需要从训练时的几千扩展到几十万 token 时，会用 YaRN 等分频段插值技术重新校准旋转角度的计算方式，避免长距离位置关系失真。

### 检验问题

1. 理解检验：架子扩容到两百个挂钩后出错，是补货员记忆相对夹角这个方法本身错了，还是别的原因？
2. 迁移检验：如果有人说"我们的模型训练时上下文是 4k，现在想不做任何调整直接用在 128k 的长文档上"，结合这个故事，你会提醒他可能出现什么问题？

## 核心原理

**传统位置编码的局限：**

- 绝对位置编码（Sinusoidal/Learned）：将位置信息加到 token embedding 上，但注意力分数 Q·K^T 中位置和内容耦合，泛化性差
- 相对位置编码（T5 bias、ALiBi）：显式在注意力分数上加位置偏置，但增加了额外的参数和计算

**RoPE 的核心思想：**

对于位置 m 的 Query 向量和位置 n 的 Key 向量，RoPE 期望：

```
<f(q, m), f(k, n)> = g(q, k, m-n)
```

即内积只依赖于相对位置 (m-n)，而不是绝对位置。

**数学实现（2D 情形）：**

```
f(x, m) = x · e^{im·θ}

具体地，对向量 x = [x₁, x₂]，旋转后为：
[x₁·cos(mθ) - x₂·sin(mθ)]
[x₁·sin(mθ) + x₂·cos(mθ)]
```

对于 d 维向量，将其分成 d/2 对，每对使用不同频率 θ_k = 10000^{-2k/d}（与正弦位置编码同频率）。

**ASCII 示意图：**

```
位置 m 的 Query:  q = [q₁, q₂, q₃, q₄, ...]
                        |    |    |    |
                    旋转(θ₁,m) 旋转(θ₂,m) ...
                        |    |    |    |
                       [q₁', q₂', q₃', q₄', ...]

内积 Q_m · K_n 只含 cos((m-n)θ_k) 项，即相对位置
```

**为何能外推？**

RoPE 的旋转操作本质上是一个频率叠加，低频分量变化慢，高频分量变化快。训练时见过的最长序列决定了低频分量的有效旋转范围。通过以下技术可扩展：

- **位置插值（PI）**：将超出训练长度的位置 m 缩放为 m' = m · (L_train / L_target)
- **YaRN**：分频段插值，高频不插值（保留局部信息），低频插值（扩展全局范围）
- **LongRoPE**：在 YaRN 基础上进一步搜索最优插值因子

**与 ALiBi 的对比：**

| 维度 | RoPE | ALiBi |
|------|------|-------|
| 实现方式 | 旋转 Q/K 向量 | 在注意力分数上加线性偏置 |
| 参数量 | 无新增参数 | 无新增参数 |
| 外推性 | 需要插值调整，效果良好 | 线性偏置天然外推，但精度有损 |
| 训练开销 | 与标准注意力相当 | 略低（加法 vs 乘法） |
| 代表模型 | LLaMA、DeepSeek、Qwen | BLOOM、早期 MPT |
| 长序列性能 | 经 YaRN 后优秀 | 中等，超长时衰减明显 |

**为什么现代 LLM 几乎都用 RoPE？**

1. 相对位置信息自然编码，无需显式计算位置差
2. 与 Flash Attention 天然兼容（分块计算时旋转可局部施加）
3. 外推扩展方案成熟（YaRN、LongRoPE）
4. 实测效果优于 ALiBi，尤其是长序列推理

## 演进时间线

- **2021** — RoFormer 论文（Su et al.），提出 RoPE 原始方案
- **2023-02** — LLaMA 采用 RoPE，RoPE 成为开源 LLM 标配
- **2023-06** — 位置插值（Chen et al.）提出线性插值扩展上下文
- **2023-08** — YaRN（Peng et al.）分频段插值，LLaMA 2 上下文从 4k 扩到 128k
- **2023-09** — DeepSeek v1 采用 RoPE + YaRN
- **2024-02** — LongRoPE（Microsoft），自适应搜索最优插值因子
- **2024-05** — LLaMA 3 原生 8k 上下文，RoPE theta 从 10000 调整为 500000 以改善外推

## PM 决策视角

**何时选 RoPE：**
- 构建需要长上下文能力的 LLM（>4k token）
- 未来可能有上下文扩展需求（YaRN 微调成本低）
- 生态系统兼容性重要（HuggingFace、vLLM 均原生支持）

**何时考虑替代方案：**
- ALiBi：推理时零训练成本扩展，但长序列精度有损
- T5 相对偏置：用于 Encoder-Decoder 结构，但现已式微
- 无位置编码（NoPE）：某些 SSM 架构不需要显式位置编码

| 需求 | 推荐 | 理由 |
|------|------|------|
| 标准 LLM 预训练 | RoPE（theta=500000） | 外推余量大，生态成熟 |
| 零成本上下文扩展 | ALiBi | 无需微调，直接外推 |
| 超长上下文微调 | RoPE + YaRN | 精度最优 |
| 自适应多粒度 | LongRoPE | 自动搜索最优配置 |

## 补充:更严谨的机制与公式(源自 Alisa's Book of LLMs)

### 完整证明:内积只依赖相对位置

本页"数学实现"部分给出了目标式 `<f(q,m), f(k,n)> = g(q,k,m-n)`，这里补充完整的证明步骤。

对 `f(x,m) = R_{mθ}x`（R 为旋转矩阵），有：

```
⟨R_{mθ}q, R_{nθ}k⟩
  = (R_{mθ}q)^T R_{nθ}k
  = q^T R_{mθ}^T R_{nθ} k
  = q^T R_{-mθ} R_{nθ} k     ∵ 旋转矩阵的转置等于反向旋转 R_α^T = R_{-α}
  = q^T R_{(n-m)θ} k          ∵ 旋转矩阵可加性 R_α R_β = R_{α+β}
```

最终结果 `q^T R_{(n-m)θ} k` 只包含 `(n-m)`，不再包含 m、n 各自的绝对值——这就是"内积只依赖相对位置"的完整推导，只依赖旋转矩阵的两条基本性质（转置即反向旋转、旋转可叠加）。

### θ_i 频率设计的直觉

每一维度对 i 的旋转角频率为 `θ_i = Θ^{-2i/H}`，其中 Θ 通常取 10000（HF 中的 `rotary_base`），H 是每个注意力头的维度。这是一个指数衰减、对数均匀分布的频率设计：

- i 越小（高频）：θ_i 越大，相邻位置之间旋转角度差异大 → 擅长分辨局部、邻近的位置关系
- i 越大（低频）：θ_i 越小，旋转很慢，相邻位置几乎看不出区别 → 擅长承载长程、粗粒度的位置信息

这与 Transformer 原始论文里正弦位置编码的频率设计思路完全一致——都是用一组几何级数分布的频率，让不同维度对分别负责不同尺度的位置信息。最慢的一对（θ_i = Θ^{-1}）完成一整圈需要 m = Θπ 个位置，这个值代表了 RoPE 原生能够无歧义区分的最长距离量级。

### 用复数/欧拉公式重新表述旋转

把每一对维度 `[x_{2i}, x_{2i+1}]` 看成一个复数 `z = x_{2i} + i·x_{2i+1}`，旋转角度 θ 等价于乘以 `e^{iθ}`：

```
z·e^{iθ} = (a+bi)(cosθ + i sinθ)          [欧拉公式 e^{iθ} = cosθ + i sinθ]
         = (a·cosθ - b·sinθ) + i(a·sinθ + b·cosθ)
```

这和直接套用 2×2 旋转矩阵 `[[cosθ,-sinθ],[sinθ,cosθ]]·[a,b]^T` 是完全等价的运算，只是换了一套数学语言描述同一件事。

### 工程实现:不是真的构造矩阵做 matmul

数学上 RoPE 是"构造一个 H×H 的分块对角旋转矩阵，再做矩阵乘法"，但实际实现中不会真的构造这个大矩阵，而是把偶数维和奇数维拆开做逐元素运算再交错组合：

```
[x1]   [cos(mθ)]     [-x2]   [sin(mθ)]
[x2] ⊙ [cos(mθ)]  +  [ x1] ⊙ [sin(mθ)]
```

即：原向量与 cos 值逐元素相乘，加上"奇偶位置互换并对其中一路取负"之后的向量与 sin 值逐元素相乘。这种写法避免了显式构造和存储大型旋转矩阵，是主流实现里 `apply_rotary_pos_emb` 的标准写法。
