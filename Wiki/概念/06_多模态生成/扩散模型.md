# 扩散模型（Diffusion Models）

> **一句话定义**：扩散模型通过"加噪→去噪"的马尔可夫链学习数据分布，生成图像/音频/视频——前向过程逐步将数据破坏为纯噪声，反向过程训练神经网络从噪声中逐步重建样本。

---

## 寓言学习

### 寓言正文

老照片修复工作室接了一单委托：一张严重褪色、布满噪点的合影，几乎看不清人脸轮廓。修复师没有直接在这张照片上一笔画出清晰的人脸——那样风险太大，稍微画错一点，五官比例就会走形。她的做法是一遍一遍地来：先估计这张照片这一层大概混进了多少噪点，把这一层噪点淡淡地擦掉一点点，得到一张稍微清楚一丢丢的版本；再针对这个新版本，重新估计还剩多少噪点，再淡淡擦掉一点。如此反复上百遍，画面才一点点从模糊噪点中显出五官和衣服的轮廓。

这门手艺是她这些年练出来的：拿大量清晰的老照片，人工一层一层往上叠加噪点，直到完全变成雪花点，再反过来一遍遍练习"给定这张带噪点的图，估计这一步混入的噪点大概是什么样子"，练得多了，不管拿到多脏的照片，她都能一步步把噪点估计准。

委托人等得不耐烦，要求她跳过中间步骤，直接从原始的满屏噪点一次性擦成清晰照片。修复师试了一次，画面是变清楚了，可人脸五官扭曲得完全不对，明显是"一步到位"出的问题。后来她找到了折中办法：不必真的一步步擦满上百遍，只要把原本细碎的一百个小步骤，合并成二十个大一点的步骤，每一步的噪点估计算得更准一些，效果几乎和上百遍一样清晰，但时间省了大半。

### 概念解析

**概念名称**：扩散模型（Diffusion Models），属于生成式AI的图像/音频/视频生成问题域。

**学习卡片**
- 核心张力：直接学习"从随机噪声一步生成完整逼真样本"极其困难；但学习"给定一个被轻微污染的样本，估计这一步混入的噪声大概是什么"这种局部小任务却容易得多——用大量累积的小步骤，代替一步到位的整体生成。
- 关键不变量：训练目标始终是预测"当前这一步被加进去的噪声"，而不是直接预测最终干净样本；且这个"加噪"过程必须是可逐步逆转的，每加一步都能对应一步去掉。
- 触发条件：目标分布复杂、难以一步直接建模，但"给定被轻微破坏的样本，微调回稍微干净一点"这个局部小步骤是可学习、可累加的。
- 常见误解/失败模式：试图让模型一步到位直接输出最终结果，跳过逐步去噪的过程，画面质量通常明显下降、结构失真；或者去噪步长/幅度控制不当，步子迈太大导致细节被破坏。
- 非适用边界：如果目标不是"从模糊/随机状态里逐步精炼出结构"，而是有明确、可以直接一步映射得到答案的确定性任务，不需要这种多步去噪机制。

**一句话核心定义**：扩散模型通过反复练习"给定一个被轻微加噪的样本，估计并去掉这一步混入的噪声"，把一个从随机噪声逐步精炼出逼真样本的过程学出来，用大量累积的小步骤代替一步到位的直接生成。

**它试图解决的问题**：当目标数据分布（图像/音频/视频）复杂到无法一步直接生成时，如何把"生成"这件难事拆解成大量容易学习的局部小任务（逐步去噪），再累积起来完成整体生成。

**故事元素映射**：
- 修复师 = 反向去噪的神经网络，学习"给定含噪样本，估计这一步的噪声"。
- 人工给清晰照片一层层叠加噪点的练习过程 = 前向加噪过程（训练数据的构造方式）。
- 一遍遍小幅擦除噪点、逐步显出轮廓 = 反向去噪采样过程，多步累积生成最终样本。
- 委托人要求一步到位、结果五官扭曲 = 跳过逐步去噪、直接一步生成效果差的典型表现。
- 把上百个小步骤合并成二十个大步骤、效果相近但更快 = DDIM等跳步采样加速技术。

**比喻边界**：故事把去噪过程具象成了"擦除噪点"的物理动作，现实中的扩散模型是在高维向量空间里通过神经网络预测噪声分布，并非真的"擦掉"某种可见污渍；此外故事没有涉及文本条件控制（如根据委托人的具体要求引导修复方向）以及在压缩后的潜在空间（而非原始像素）做扩散以降低计算量这些关键工程优化，这些是让扩散模型能在消费级算力上实用化的重要部分，但不影响故事呈现的核心去噪机制。

**非适用例**：如果照片只是简单地整体调亮调暗，输入输出之间有明确直接的映射关系（比如固定的亮度公式），不需要经过"逐步去噪精炼"这套机制，直接一次运算就能得到结果。

**现实例子**：DDPM（2020）最早确立了"加噪-去噪"的标准训练框架，但采样需要上千步、极慢；DDIM（2021）通过去掉马尔可夫假设支持跳步采样，只需几十步就能生成质量相近的结果，将采样速度提升了一到两个数量级，这正是修复师后来找到的"合并步骤"技巧在现实中的对应。

### 检验问题

1. 理解检验：修复师练习"人工加噪再学去噪"这套手艺，为什么最后能让她面对任何一张脏照片都能一步步修复，而不只是记住了训练时用过的那几张照片？
2. 迁移检验：如果有人设计一个系统，直接训练一个模型"输入一张模糊照片，一步输出清晰照片"，不经过任何中间步骤的迭代，你觉得这个思路和扩散模型的核心机制是不是一回事？为什么委托人当初"一步到位"的要求会导致失真？

## 前向过程 vs. 反向过程

```
前向过程（Forward Process，固定，非可训练）：
  x_0（真实数据）
    → x_1（轻微加噪）
    → x_2（更多噪声）
    → ...
    → x_T（纯高斯噪声）

  每步加噪：q(x_t | x_{t-1}) = N(x_t; √(1-β_t)·x_{t-1}, β_t·I)
  
  β_t：噪声调度（noise schedule），从小到大
  关键性质：可以直接从 x_0 采样任意 t 步的 x_t（无需逐步计算）

反向过程（Reverse Process，训练目标）：
  从 x_T（纯噪声）出发
    → 神经网络预测每步的噪声 ε_θ(x_t, t)
    → 逐步去噪，最终还原 x_0

  训练损失：L = E[||ε - ε_θ(x_t, t)||²]
  直觉：网络学习"给定当前含噪样本，当前噪声是什么"

采样：训练完成后，从高斯噪声出发，T 步去噪 → 生成新样本
```

## 关键变体演进

```
DDPM（Denoising Diffusion Probabilistic Models，2020）：
  奠基论文，确立"加噪→去噪"的标准框架
  缺点：T=1000 步去噪，采样极慢（生成一张图需秒级到分钟）

DDIM（Denoising Diffusion Implicit Models，2021）：
  核心改进：去掉马尔可夫假设，允许跳步采样
  只需 50~100 步（甚至 10 步）即可生成高质量样本
  → 将图像生成速度提升 10-100x

潜在扩散（Latent Diffusion，LDM / Stable Diffusion，2022）：
  关键创新：不在像素空间做扩散，而在 VAE 的潜在空间
  
  架构：
    编码器（VAE Encoder）：图像 → 压缩潜在向量 z（约 8x 压缩）
    扩散模型（UNet/DiT）：在潜在空间 z 上做扩散
    解码器（VAE Decoder）：潜在向量 → 图像
  
  为什么有效：
    潜在空间维度远低于像素空间（512×512×3 → 64×64×4）
    → 计算量大幅减少，同时保留语义信息
    → Stable Diffusion 在消费级 GPU 上运行成为可能
```

## 文本条件控制：CFG

```
分类器自由引导（Classifier-Free Guidance，CFG）：
  核心功能：让扩散模型的生成受文本条件控制
  
  关键公式：
    ε̂_θ(x_t, c) = ε_θ(x_t, ∅) + w · (ε_θ(x_t, c) - ε_θ(x_t, ∅))
    
    c：文本条件（正向 prompt）
    ∅：空条件（无条件预测）
    w：引导强度（guidance scale），通常 7~15
  
  直觉：向着"有条件比无条件更好"的方向放大生成信号
  训练：同一模型随机以 p=0.1~0.2 丢弃条件（做无条件预测）
        → 推理时同时运行有条件和无条件两次，合并输出
  
  实践注意：w 过大→过饱和、细节失真；w 过小→不服从 prompt
```

## 在本 Vault 论文中的应用

### TTS：AudioDiT 波形扩散（论文 98，📅 2025）

```
应用场景：文本转语音（TTS）
传统路径（错误）：文本 → Mel 频谱图 → 声码器 → 波形
                           ↑ 两次误差累积

LongCat-AudioDiT 的创新：
  直接在 Wav-VAE 潜在空间做扩散
  文本 → Wav-VAE 潜在向量（扩散）→ 解码 → 波形
  
  关键：Wav-VAE 是专门为波形设计的 VAE，而非 Mel 频谱图
  效果：Seed-Hard 零样本声音克隆 SIM 0.776 → 0.797（+2.7%，超越闭源 Seed-TTS）
  
  工程细节：
    ① 修复训练-推理不匹配（长期存在的配置不一致）
    ② 自适应投影引导（APG）替代传统 CFG，提升生成质量
```

### 游戏视频：GameCraft-2 扩散渲染（论文 102，📅 2026）

```
应用场景：指令驱动的游戏世界视频实时生成
基础架构：视频扩散模型（14B MoE）

关键挑战：从图像帧到视频序列的时序一致扩散
控制信号：键盘 + 鼠标 + 自然语言指令 → 统一编码到扩散模型条件
实时化：KV-recache（多轮推理复用 KV 缓存）→ 16 FPS 实时生成

扩散模型在视频生成中的角色：
  不是逐帧独立生成，而是在时序潜在空间联合去噪
  → 保证帧间时序连贯性
```

### 图像奖励模型：Z-Reward 分布化（论文 30，📅 2026）

```
应用场景：文生图的后训练奖励信号
创新：不用标量奖励，而是建模"奖励分布"

核心洞察：视觉偏好是主观分布式的——不同人对同一图像给不同分
  标量奖励：丢失了偏好不确定性
  分布奖励：P(s) 描述不同评分的概率分布

教师（27B VLM）→ 生成 CoT + 分数分布
学生蒸馏 → 推理时无需 CoT，直接输出分布预测
准确率：27B 教师模型达到 89.6% 人类偏好准确率
```

### 扩散语言模型的 RL 训练：PAPO（论文 17，📅 2026）

```
应用场景：文本生成（扩散语言模型，dLLM）
代表：LLaDA、Dream（并行去噪生成文本，非自回归）

与图像扩散的区别：
  图像扩散：连续潜在空间，生成是确定性去噪
  文本扩散：离散 Token 空间，通过掩码预测迭代去噪

RL 挑战：
  传统 RLHF/GRPO 为自回归设计，不适用于扩散生成
  → PAPO 解决方案：步骤感知过程奖励（SPR）+ 熵引导历史重演（EHR）
  效果：规划任务 Countdown +42.2%（vs 先前 dLLM RL 基线）
```

## DiT / MMDiT 架构变体（论文145、149深化）

扩散模型的去噪骨干经历了 U-Net → DiT → MMDiT 的演进，本 Vault 中 Seedance 2.0（视频）和 HunyuanImage 3.0（图像）分别代表纯视觉时序建模和强跨模态条件对齐两条方向。

### DiT（Diffusion Transformer）—— Seedance 2.0（论文145，视频生成）

```
用 Transformer 替换 U-Net 作为扩散骨干，支持全时空注意力：
  每一帧与其他所有帧直接做注意力 → 消除滑动窗口注意力的帧间语义漂移
  （滑动窗口只建模邻近帧，远端帧信息逐帧衰减，导致物体在长视频中变形/消失）

代价：时空注意力计算量 O(T²×H×W) 爆炸
  → 视频超过 30 秒（~900 帧）时全帧注意力成本不可接受
```

配套训练策略（服务于 DiT 的运动一致性目标）：
- **分辨率渐进训练**：256p → 512p → 720p → 1080p 逐步微调，先学运动语义再学细节
- **运动一致性 RLHF 奖励**：专用光流一致性评分模型作为奖励信号，与美学质量、提示跟随联合优化
- **物理感知训练目标**：重力、布料、流体先验融入 loss，缓解纯数据驱动扩散在物理交互上的失真

### MMDiT（Multi-Modal DiT，双流Transformer）—— HunyuanImage 3.0（论文149，图像生成）

```
文本Token流 ──→ Cross-Attention（每层双向交互）──→ 图像Token流
```

与单流DiT（文本直接拼接进图像token序列）的区别：MMDiT让文本和图像各自独立通过专属参数处理，仅在每层通过交叉注意力交互——为强跨模态语义对齐（如中文成语、古诗的深层理解）保留更充分的文本侧建模能力。

- **双编码器搭配**：Hunyuan-T5（中文语料继续预训练的T5变体）+ CLIP-L（英文视觉语义）。T5负责中文深度理解——中文语义token的cosine距离在相关概念上比英文T5近35%；CLIP负责兼容SD/FLUX的英文视觉语义对齐生态
- **代价**：CLIP语义被T5"稀释"，英文prompt理解可能弱于纯英文系统（论文未给出英文GenEval分项数据佐证）
- **训练范式**：Flow Matching（ODE路径）——NFE（函数评估次数）从50压缩到20时FID仅上升0.3，说明ODE路径对采样步数压缩的鲁棒性支撑了MMDiT的实用化部署
- **角色一致性生成**：通过在人脸区域注入预训练人脸先验（ArcFace等提取的身份embedding）并送入cross-attention，在多图生成中保持同一人物身份——本质是给MMDiT的跨模态条件注入机制额外增加一路"身份条件"，而非依赖纯文本描述约束身份（"一个30岁亚洲男性"这类描述精度不够）；失效边界：侧脸/遮挡/非正面角度下ArcFace提取不稳定

### DiT vs MMDiT 选型

| 维度 | DiT（单流） | MMDiT（双流） |
|------|-----------|--------------|
| 适用模态 | 视频（时序建模为主） | 图像（强跨模态条件对齐为主） |
| 文本条件处理 | 拼接/简单注入 | 独立流+逐层交叉注意力 |
| 典型代表 | Sora、Seedance 2.0 | Stable Diffusion 3、HunyuanImage 3.0 |
| 优势场景 | 长程时序一致性 | 复杂/多语言文本语义精确对齐 |

## PM 决策：扩散模型 vs. 自回归生成

| 维度 | 扩散模型 | 自回归模型（LLM/AR-TTS）|
|------|---------|----------------------|
| **生成质量** | 极高（图像/视频/音频）| 高（文本、AR-TTS）|
| **生成速度** | 慢（需多步去噪，DDIM 加速后中等）| 快（逐 token，可流式输出）|
| **可控性** | 通过 CFG 控制（直观）| 通过 prompt 控制（灵活）|
| **时序输出** | 全局去噪，难以流式 | 天然流式（逐 token）|
| **文本生成** | 边缘场景（dLLM 仍实验阶段）| 绝对主流 |
| **图像/音频/视频** | 主流（Stable Diffusion / AudioDiT）| 替代（AR 图像生成兴起）|
| **RL 对齐** | 复杂（需特殊设计如 PAPO）| 成熟（GRPO/DPO/PPO）|

**选型原则**：
- 图像/音频/视频生成 → 扩散模型（默认选择）
- 文字/代码生成 → 自回归 LLM（默认选择）
- TTS → 两条路线均有竞争力：AR（GLM-TTS）vs NAR 扩散（AudioDiT）
- 生成式游戏 → 视频扩散模型（GameCraft 方向）
