# AI 科研 Agent

> **一句话定义**：AI 科研 Agent 指能自主完成"提出假说 → 设计实验 → 执行 → 分析 → 发现"闭环的 AI 系统——不只是搜索文献或写代码，而是像人类科学家一样推进知识边界。

---

## 寓言学习

### 寓言正文

农业试验站的巡田机器人,每天负责给几万株杂交苗拍照记录数据。

站长先让它做"验证":告诉它某个杂交组合按已知规律该长出什么性状,让它去田里核对记录是否吻合,它做得又快又准,比人工巡查省了大半时间。接着站长让它做"补全":给它一半田块的观测数据,让它按已知规律推算另一半缺失的数据,它也完成得不错,准确率能打八九成。

站长后来想更进一步,让机器人自己"看数据找规律,提出下一步该拿哪两个品种去杂交,才能突破现在的产量瓶颈"。机器人交上来的建议,翻来覆去都是历史记录里出现过的组合的变体——把已经试过的两个品种换个比例、换个种植密度,却从来没提出过一个数据库里完全没出现过的新方向。站长把近三年所有观测记录都喂给它,它给出的建议依然没有跳出这个圈子。

有一次,一个刚来的年轻育种员没查历史记录,随手把两个从没人配对过、按常规经验完全不搭的边缘品种拿去试种,结果那批苗子的亩产比现有最优组合还高出四成。机器人事后被要求分析这个结果,它能准确算出这个新组合各项性状的数据,却在被问"下次该往哪个方向再试"时,给出的建议又绕回了熟悉的老路子。

### 概念解析

**概念名称**：AI 科研 Agent(能力层次 Level 1–5),属于 AI Agent 系统/科学发现自动化问题域。

**学习卡片**
- 核心张力：在已知框架内可靠地验证、补全、证明(能力强、边界清楚) vs 提出训练数据里从未出现过的全新方向(能力弱、边界模糊)——越接近"发现"这一端,越依赖训练数据之外的东西。
- 关键不变量：系统能提出的"假说空间"始终是它见过的数据模式的函数,不会凭空跳出训练分布之外去产生真正原创的方向,这条边界不会因为喂更多同类数据而突破。
- 触发条件：验证、补全类任务在有明确规律、可核对答案的场景下能可靠触发;猜想、发现类任务需要"跳出已知模式"的能力,目前系统很难稳定触发。
- 常见误解/失败模式：把系统在验证/补全层面的高准确率,当作它已经具备"提出新方向"的创造力;或者以为喂更多历史数据就能让系统自己"想出"没见过的组合。
- 非适用边界：任何要求"提出人类此前完全没设想过的新范式"的任务(而不是在已知框架内做延伸组合),目前的系统能力边界都到不了那一步。

**一句话核心定义**：AI 科研 Agent 目前能可靠完成"验证已知规律、补全已知模式"这类任务,但它能想到的方向,边界正是训练数据/历史记录划出来的范围,尚不能像人类科学家一样提出训练分布之外的全新猜想或发现。

**它试图解决的问题**：科学研究里"验证假说、补全实验、推进证明"这些工作量巨大但模式相对固定,AI 科研 Agent 试图把这部分工作自动化,同时探索它能不能进一步承担"提出新猜想、做出新发现"这类更依赖创造力的环节。

**故事元素映射**：
- 机器人核对已知规律、推算缺失数据 = Level 1(验证)和 Level 2(补全),当前主流系统能可靠完成的层级。
- 机器人被要求"提出突破产量瓶颈的新方向"却只给历史组合的变体 = Level 4(猜想)的能力局限,假说空间被训练数据的边界限制住。
- 年轻育种员随手试出的边缘组合大获成功 = 人类跨越训练分布之外的创造性跳跃,恰好是当前系统最缺的能力。
- 机器人事后能分析新组合的数据,却仍给不出"下次该往哪试"的新建议 = 验证能力(Level 1/2)与猜想能力(Level 4)之间的鸿沟——能核实别人发现的东西,不代表能自己发现。

**比喻边界**：故事把 AI 科研 Agent 的能力边界具象成"巡田机器人给不出新配对建议",但现实中不同层级(验证/补全/证明/猜想/发现)之间的能力鸿沟远比"想不出新点子"复杂——比如 Level 3(证明)还依赖形式化验证工具链是否完善,Level 5(发现)还涉及能否设计并执行真实实验、能否被同行认可等一系列问题,不是单一维度的"创造力"就能概括的。

**非适用例**：如果任务是"把已经发表过的论文方法在新数据集上跑一遍、看能不能复现",这属于 Level 1/2 范畴,当前系统能可靠完成,不应该被算作"AI 已经能做原创科研发现"的证据——很多宣传里混淆了"复现已知方法"和"提出新发现"这两件事。

**现实例子**：NanoGPT-Bench 评测发现,AI 科研 Agent 能重现已知的模型改进方法(如批归一化、残差连接)成功率约 70%,但提出训练数据里没有的原创改进方法的成功率不到 5%;CUSP 评测里 AI 预测科学进展方向的 F1 约 0.40,低于领域专家的 0.55,说明"猜想"这一层的能力仍明显落后于人类。

### 检验问题

1. 理解检验：故事里机器人为什么在"验证"和"补全"任务上表现很好,却在"提出新杂交方向"上始终跳不出历史记录的框架?这两类任务对"训练数据覆盖范围"的依赖程度有什么本质区别?
2. 迁移检验：一家药企宣传"我们的 AI 科研 Agent 能自主发现新的候选药物靶点",你会追问哪些问题来判断这个系统究竟停留在 Level 1-3 还是真正达到了 Level 4-5?

## 能力层次：Level 1–5

```
Level 1 — 验证（Verification）
  给定假说，验证它是否正确（运行实验、检查结论）
  当前水平：主流 LLM 已达到，可靠

Level 2 — 补全（Completion）
  给定部分实验设计，补全缺失步骤
  当前水平：GPT-4/Claude 可完成标准流程，复杂设计仍有误差

Level 3 — 证明（Proof）
  从问题陈述出发，给出完整的形式化证明（数学）或实验路径
  当前水平：AI 协数学家工作台（论文138）部分达到，Lean 4 验证器辅助
  局限：只能证明现有工具库内的定理

Level 4 — 猜想（Conjecture）
  发现人类未注意到的规律，提出新猜想
  当前水平：CUSP（论文47）实现"预测下一个科学进展"，F1 约 40%
  局限：猜想质量偏保守，缺乏大胆跳跃

Level 5 — 发现（Discovery）
  全自主完成从问题到新知识的完整闭环，结果可发表
  当前水平：AutoScientists（论文43）在受限领域（合成生物学等）演示了雏形
  局限：研究质量低于顶级人类科学家，泛化能力弱
```

## 三条技术路线

### 路线一：工具使用 Agent（Tool-Using Agent）

```
架构：
  LLM 主控 → 调用外部工具 → 解析结果 → 迭代

典型工具集：
  ┌─────────────────────────────────┐
  │  代码执行    搜索论文    数据分析  │
  │  Python/R    Semantic    Pandas   │
  │               Scholar            │
  │  实验仪器    数据库      Web 搜索  │
  │  API 调用    SQL/NoSQL   Bing/EXA │
  └─────────────────────────────────┘

代表系统：
  AutoLab（论文35）— 超长视野工程研究任务
    评测设计：任务跨度 8-24h，要求多轮规划
    关键发现：Agent 在第 3-5 步后开始"漂移"，工具调用错误累积
    当前通过率：复杂任务 <15%

  NanoGPT-Bench（论文129）— 自主 ML 研究评测
    任务：在 NanoGPT 上自主发现改进方法
    发现：Agent 能重现已知改进（BN、残差），但原创改进极少
    评分标准：≥1% 验证集提升 = 成功
```

### 路线二：多 Agent 团队（Multi-Agent Team）

```
架构：
  专家 Agent × N（自组织分工）
  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │ 假说提出  │→ │ 实验设计  │→ │ 代码执行  │
  │  Agent   │  │  Agent   │  │  Agent   │
  └──────────┘  └──────────┘  └──────────┘
       ↑              ↑              ↓
  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │ 同行评审  │← │ 结果分析  │← │ 数据收集  │
  │  Agent   │  │  Agent   │  │  Agent   │
  └──────────┘  └──────────┘  └──────────┘

AutoScientists（论文43）：
  自组织：Agent 自行分配角色，不需人工预设分工
  实验领域：材料科学 + 生物信息学
  关键发现：团队协作比单 Agent 发现速度快 3-5x
  瓶颈：Agent 间"共识幻觉"——集体认同错误结论
```

### 路线三：形式化验证（Formal Verification）

```
架构：
  LLM 生成证明草稿 → 形式化验证器（Lean 4 / Coq）验证 → 反馈修正

AI 协数学家工作台（论文138）：
  目标：辅助数学家完成"证明搜索"中最耗时的部分
  能力：
    - 自动生成 Lean 4 证明代码
    - 自动搜索引理库（Mathlib4）
    - 交互式"建议下一步"
  当前状态：已辅助完成多个 AMC/AIME 级别题目
  局限：IMO 压轴题仍需大量人工干预

优势：形式化验证 = 零幻觉（证明要么对要么错，验证器说了算）
代价：需要将数学对象形式化，这本身就极耗人工
```

### 路线四：科研审查 Agent（Scientific Review Agent）

```
架构：
  分段 + 分层算力预算 + 并行深度审查 + 搜索落地校验
  （区别于前三条路线"做研究"，这条路线是"审查研究"）

四级角色分类法（161号论文提出）：
  Level A — 作者工具（Author Tool）
    帮作者自查论文（提交前发现错误），不参与他人评审
    当前水平：STOC/ICML 试点已验证有效

  Level B — 评审工具（Reviewer Tool）
    辅助人类评审者发现遗漏点，人类仍主导判断
    当前水平：可用，需要人类核实误报

  Level C — 支持性评审（Supporting Review）
    独立生成审查意见，作为人类评审的补充参考
    当前水平：早期试点阶段

  Level D — 全自动评审（Full Autonomous Review）
    完全替代人类评审流程
    当前水平：论文明确指出这不是短期目标，责任边界问题未解决

Google 论文助手工具（PAT，161号论文）：
  在 STOC/ICML 两大顶会做"论文提交前自查"试点（超4700篇）
  数学证明错误检出率：零样本 Gemini 3.1 Pro 55.2% → PAT 89.7%
  关键洞察：AI 审稿不是单一能力，而是需要先明确"扮演哪个角色"
  再决定投入多深——角色定位错误是"AI 审稿产品"最容易踩的坑
```

**这条路线对 PM 的特殊意义**：任何"AI 质检/AI 审稿/AI 合规检查"类产品，本质上都要先在这个四级分类法里给自己定位——把 Level A 的工具包装成 Level D 的承诺，是当前"AI 审稿"类产品最常见的责任边界模糊操作。

## 当前能力边界：实测数据

| 评测基准 | 测试内容 | 最佳 AI 表现 | 人类水平 |
|----------|---------|------------|---------|
| **NatureBench**（论文10）| 自然科学实验设计 | ~42% 正确率 | ~91%（专家）|
| **AutoLab**（论文35）| 长视野工程研究 | <15%（复杂任务）| ~85% |
| **NanoGPT-Bench**（论文129）| 自主 ML 改进 | 重现已知 70%，原创 <5% | 顶级研究者 |
| **CUSP**（论文47）| 预测科学进展 | F1 ≈ 0.40 | 领域专家 F1 ≈ 0.55 |

**共同瓶颈**：
1. 长时序规划崩溃（超过 ~20 步后错误累积）
2. 领域知识边界（无法超越训练数据涵盖的范围）
3. 实验设计的创造力不足（趋向模仿已有方法）

## 与人类科研的比较

```
AI 科研 Agent 的速度优势：
  文献检索：AI < 1分钟 vs 人类数小时
  代码实验：AI 24/7 不间断 vs 人类每天 8h
  参数扫描：AI 并行数百实验 vs 人类串行

AI 的创造力局限：
  "假说空间" = 训练数据的函数——AI 很难提出训练数据中从未出现的新方向
  类比推理弱：跨领域创造性迁移是人类独特优势
  风险偏好不足：AI 倾向"安全"但平庸的假说

最适合 AI 的科研任务类型：
  ✅ 大规模参数搜索（分子结构优化、超参数调优）
  ✅ 已知框架内的推理（定理证明、代码验证）
  ✅ 文献综合与交叉（跨百篇论文找关联）
  ❌ 颠覆性新范式（量子力学、相对论级别的跨越）
  ❌ 需要物理直觉的实验设计
  ❌ 理解社会/伦理背景的研究问题
```

## PM 机会地图

| 领域 | 机会 | 当前可行性 | 关键风险 |
|------|------|-----------|---------|
| **生命科学** | 药物靶点假说生成、基因功能预测 | ⚠️ 中等（需领域验证） | 幻觉导致错误假说 |
| **材料发现** | 新材料性质预测、合成路径设计 | ✅ 较高（结构化知识多）| 实验成本仍高 |
| **数学辅助** | 定理证明助手、猜想搜索 | ✅ 较高（形式化验证可靠）| 形式化工作量大 |
| **ML 自动化** | AutoML、架构搜索 | ✅ 可用（NanoGPT-Bench）| 原创性仍有限 |
| **文献综合** | 系统性综述自动化 | ✅ 成熟可用 | 幻觉引用问题 |
| **社会科学** | 问卷设计、数据分析 | ❌ 不推荐 | 语境/文化理解缺失 |

**最具 ROI 的 PM 切入点**：
1. 科研文献助手（综述/矛盾检测）——低风险，即时可用
2. 实验代码生成与调试——辅助角色，人类主导
3. 数学定理证明工具——高确定性，形式化验证兜底
