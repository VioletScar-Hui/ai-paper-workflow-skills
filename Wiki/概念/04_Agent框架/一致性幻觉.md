# 一致性幻觉（Consistency Illusion）

## 一句话定义
> 多个 Agent 通过辩论达成共识时，其表面一致性掩盖了底层推理不对齐的现象。

## 寓言学习

### 寓言正文

这批零件送来复检，班长把同一批里抽出的三件分别交到三位质检员手上，没让他们碰头。

第一位拿到零件，先用卡尺量了关键尺寸，读数复核了一遍，确认在公差范围内，判"合格"。

第二位那天要赶着交接下一批，拿起零件对着灯翻了两面，没看出明显磕碰，又想起前一班组昨天留下的检验单上写的也是"合格"，就照着那张单子抄了一份——自己其实没上手量过。

第三位刚接手这条线不久，他手边那份公差对照表其实是另一种零件的规格。他按那张表量出来的数字正好落在范围内，也判了"合格"——他自己并不知道那张表根本对不上这批零件。

三张"合格"单交到班长桌上，三个人写的结论一字不差。班长扫了一眼，三个人都判过了，直接放行装箱发货。

后来这批零件到了客户那边的装配线上，装不进去，被整批退了回来。班长把三张单子重新摊开，一个个去问当时是怎么判的，才发现：三个人写下的是同一句话，靠的却是三条完全不同的路子——一条是真量出来的，一条是照抄旧单子，一条是拿错了对照表蒙对的。

班长后来想，那天要是有一张单子写的是"不合格"，他反而会停下来，把三个人叫到一起，核对一遍到底谁量得对——正是因为三张单子写得一模一样，才没人再多看一眼。

### 概念解析

**概念名称**：一致性幻觉（Consistency Illusion），属于多智能体系统 / Agent 安全对齐问题域。

**学习卡片**
- 核心张力：多个独立判断者结论相同带来的"看似可靠"的信任感 vs 他们各自底层推理路径可能完全不对齐、甚至部分是错误路径的现实。
- 关键不变量：多个独立判断者给出同一结论，本身不携带"每个判断过程都有效"的信息——除非逐一核查每条推理路径，否则无法只凭"结论相同"推出"判断可靠"。
- 触发条件：多个独立主体各自给出判断，最终只看"结论是否一致"来决定是否采信，而不核查每个判断背后走的是什么路子。
- 常见误解/失败模式：把"结论一致"直接等同于"更可靠"，照搬"独立多方都同意=更可信"的直觉；实际上可能是强势一方带偏弱势一方、不同错误路径偶然凑到同一个错结论、或者只是改了说法没改判断依据。
- 非适用边界：如果每个判断者确实各自独立完成了有效、可验证的判断过程（方法对、也真的动手做了），那么结论相同就是真实可靠的信号，不属于此概念所指的幻觉。

**一句话核心定义**：一致性幻觉是指多个独立主体给出相同结论时，这种表面一致掩盖了他们底层推理路径互不对齐、甚至部分错误的现象，使"结论相同"被误当成"结论可靠"的证据。

**它试图解决的问题**：在依赖多方独立判断做决策（多票表决、多重审核）时，如何识别"结论相同"这件事本身能不能证明判断质量，避免把巧合当成可靠。

**故事元素映射**：
- 三位质检员各自拿到零件、互不通气 = 多个独立判断主体各自给出结论，不做过程间协商。
- 第一位真实测量、复核读数 = 有效、可验证的独立判断路径。
- 第二位照抄旧单子、没有真的动手判断 = 表面完成了判断，实际推理路径是空的或失真的。
- 第三位用错公差表、数字碰巧落在范围内 = 一条本身错误的路径，偶然导出和正确路径相同的结论。
- 三张"合格"单结论一字不差、班长直接放行 = 只看结论相同就判定可靠，跳过了对判断路径本身的核查。
- 退货后班长回查三份依据才发现三条路子完全不同 = 揭穿"结论相同"不等于"判断可靠"。
- 班长设想"如果当初有一张写不合格" = 不一致反而会触发对判断路径的深度审查。

**比喻边界**：故事里三位质检员的错误各自独立、互不影响，只体现了"不同错误路径偶然导出相同结论"这一种情况。现实中多主体判断失效的模式更丰富——比如强势一方在协商过程中把弱势一方的判断带偏，或者各方为了尽快达成一致只修改了措辞、并没有真正改变自己的判断依据，这两种情况在完全不通气的质检场景里体现不出来，需要在有互动、有协商的多方判断场景中才会出现。

**非适用例**：如果三位质检员当时确实都各自完整测量了尺寸、用的是同一份正确的公差标准，各自独立得出"合格"，那么三张单子写得一样就是真实可靠的信号，这是正常的独立多方验证，不是此概念所指的幻觉。

**现实例子**：多个大模型 Agent 各自独立生成一段推理再投票表决同一道题的答案，如果只看"多数模型选了同一个选项"就采信为正确答案，而不检查每个模型给出这个答案时走的推理链是否真的成立，就可能把几条不同的错误推理链偶然收敛到同一个错误答案，误当成"高置信度共识"。

### 检验问题

1. 理解检验：故事里班长一开始为什么放心把这批零件放行？后来复查发现的问题出在哪个环节——是"三个人手艺不行"，还是别的什么原因？
2. 迁移检验：如果一个企业审批系统要求同一笔报销单必须经过三位不同审核员分别签字确认才能通过，你觉得这类场景要不要担心类似的问题？为什么？

## 核心机制

```
Agent A  推理路径 X → 结论 C
Agent B  推理路径 Y → 结论 C  （表面一致！）
Agent C  推理路径 Z → 结论 C

但实际上：路径 X、Y、Z 互不兼容
   → 三个 Agent 脑子里的推理完全不同
   → 但结论碰巧一样 = "一致性幻觉"
```

### 为什么危险

正常的"多数投票"假设：多票同意 = 更可靠。
一致性幻觉打破这个假设：**多票同意 ≠ 更可靠，因为每个 Agent 的推理可以是错的但结论碰巧对**。

| 情景 | 结论 | 推理质量 | 危险 |
|------|------|---------|------|
| 真人多票 | 一致 | 每个都有独立有效推理 | ✅ 可靠 |
| Agent 辩论 | 一致 | 3 个 Agent 用了 3 条不同错误路径 | ❌ 幻觉 |
| Agent 辩论 | 不一致 | 至少有一个正确 | ⚠️ 需要深度审查 |

### 三种失效模式

1. **从众效应** — 强势 Agent 带偏弱势 Agent 的推理
2. **偶发一致** — 不同错误路径偶然导出相同错误结论
3. **表面妥协** — Agent 为了达成共识，修改措辞但不改变推理

## 防御策略

| 策略 | 做法 | 成本 |
|------|------|------|
| 推理链审计 | 不只看结论，还要检查推理路径一致性 | 低 |
| 对抗性审查 | 分配一个"质疑官"Agent 专门反驳共识 | 中 |
| 独立思考 | 在汇聚前不做 Agent 间通信 | 低 |
| 来源标注 | 每个结论附带完整的推理链来源 | 低 |

## 产品决策

- 单 Agent 任务：无此风险
- 多 Agent 投票：**必须**加推理审计步骤
- 多 Agent 辩论：风险最高，需要对抗性质疑
