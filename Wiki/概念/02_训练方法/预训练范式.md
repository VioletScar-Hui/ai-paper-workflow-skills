# 预训练范式

## 一句话定义

通过在海量无标注文本上进行自监督学习（下一词预测或掩码预测），使模型在微调前就习得语言的统计规律和世界知识。

## 寓言学习

### 寓言正文

一家做了二十年跨境贸易的公司，仓库角落堆着十几箱历年往来邮件、合同、报关单打印稿，没人特意整理过，什么品类都有。新来的文案助理小陈接到一个任务：不用专门的语法老师逐句教，自己把这十几箱材料通读一遍，练出公司惯用的措辞和语气。

小陈的练法很朴素：读一封邮件，读到一半就用手挡住后面几行，先猜下一句大概会怎么写，再挪开手对答案；读几段合同条款，故意跳过中间一段，先猜那段大概写的是什么内容，再翻回去核对。读得多了，遇到新客户询价，不用查模板，提笔就能写出跟老员工风格接近的回复。

主管后来又给小陈补了两百页的最新报关政策文件，小陈的用词明显更专业了；但主管也试过让小陈把那十几箱材料反复读十遍而不添新材料，小陈的写法却没什么长进，来来去去还是那几种句式，遇到没见过的品类合同依然接不住话。主管后来定了条规矩：新人练习材料的量要跟着种类一起加，只囤旧材料重复读，效果有上限。

### 概念解析

**概念名称**：预训练范式（Pre-training），属于大语言模型训练方法中的自监督学习问题域。

**学习卡片**
- 核心张力：靠专人逐句纠正语法规则来教（精确但覆盖面窄、成本高）vs 让学习者自己在海量未标注材料里，通过"猜下一段/猜被挡住的内容"总结规律（覆盖面广，但依赖材料的量和种类都足够）。
- 关键不变量：学习信号来自材料本身的上下文（挡住一部分、猜出被挡住的部分再核对），不需要人工专门标注"这句话对不对""这是什么意思"；材料的多样性和数量共同决定学习效果的上限。
- 触发条件：存在大量未标注但结构完整的素材（能自然地"挡住一部分、用其余部分预测"）时，这种自学习方式才能运转；素材过少或过于单一，学习效果会很快见顶。
- 常见误解/失败模式：以为"反复读同一批材料"和"读更多不同材料"效果一样——实际上材料数量和种类需要同步增长，只在旧材料上无限重复不会带来相应提升。
- 非适用边界：如果任务要求的是精确执行某条具体规则（比如严格按某份最新政策文件的措辞回复，一字不能错），泛读式自学效果有限，需要针对该份材料专门强化学习，而不是靠广度阅读。

**一句话核心定义**：预训练范式是指在海量未标注文本上，通过"预测被遮挡或后续的内容"这种自监督方式，让模型在专门微调之前就习得语言的统计规律和世界知识。

**它试图解决的问题**：如何在没有大规模人工标注"对错"的前提下，让模型从原始文本里自己学会语言的结构和常识，为后续针对具体任务的微调打好底子。

**故事元素映射**：
- 十几箱历年邮件、合同、报关单 = 海量未标注的预训练文本。
- 挡住后半句先猜再核对 = 因果语言建模（预测下一个词）。
- 跳过中间一段先猜内容再翻回核对 = 掩码语言建模（预测被遮盖的内容）。
- 材料种类和数量同步增加才有长进，只重复读旧材料效果见顶 = Scaling Law 揭示的参数量与训练数据量应共同增长，数据的质量和多样性比单纯堆量更关键。
- 补充最新报关政策文件后用词更专业 = 持续预训练：在通用基座上补充领域数据，进一步提升特定领域表现。

**比喻边界**：故事把预训练简化成"猜词游戏"，现实中的模型是在数十亿到数万亿 token 规模上做统计意义上的下一词/掩码预测，参数规模和数据规模需要按 Chinchilla 提出的比例关系（大致 N≈D）共同调节，而不是像小陈一个人凭直觉判断"该多读点什么"；此外现实里还需要做去重、质量过滤、污染检测等工程步骤，故事没有展开。

**非适用例**：如果小陈要做的是"严格按公司刚发布的最新一版合同模板，一字不差地照抄条款"，这种要求精确复现某份特定文件的任务，靠泛读积累语感效果有限，更适合针对这份材料单独训练或直接检索引用，而不是套用大规模自学这套逻辑。

**现实例子**：LLaMA 系列没有一味堆参数量，而是用远超同规模模型的 token 数（如 7B 参数配 1T tokens）训练，践行了 Chinchilla 提出的"参数量与数据量应同步增长"的原则，最终在多数任务上表现优于参数更大但训练数据相对不足的模型。

### 检验问题

1. 理解检验：主管让小陈把同一批旧材料反复读十遍却没有明显长进，这说明"读的量"和"读的种类"在预训练里分别扮演什么角色？
2. 迁移检验：如果一家公司想让新模型自学"内部工单处理"的语言风格，只给了过去半年的工单记录（种类单一但数量足够），你觉得这套自学思路能不能奏效？为什么？

## 核心原理

### 两种主流自监督目标

**因果语言建模（CLM / 下一词预测）**
- 给定上文 x₁...xₜ₋₁，预测下一个词 xₜ
- 目标函数：最大化 ∑ log P(xₜ | x₁...xₜ₋₁)
- 代表模型：GPT 系列、LLaMA 系列

**掩码语言建模（MLM / 掩码预测）**
- 随机遮盖 15% 的 token，让模型根据上下文还原被遮盖的词
- 目标函数：最大化被 MASK 位置的条件概率
- 代表模型：BERT、RoBERTa、DeBERTa

### 根本假设：分布即能力

预训练范式的哲学基础是**压缩即理解**：如果一个模型能对任意文本序列赋予高概率，它必须隐式掌握语法、语义、常识乃至推理能力。互联网文本分布的广度和密度，决定了预训练模型能力的上限。

这一假设意味着：**预训练数据的质量和多样性，比模型结构的精妙更为重要**。

### Scaling Law

Chinchilla 研究（Hoffmann et al., 2022）给出了计算最优的训练法则：
- 在固定计算预算 C 下，模型参数量 N 与训练 token 数 D 应满足 N ≈ D
- 即：若把参数量翻倍，训练数据也应翻倍，而不是继续在同量数据上训练
- GPT-3（175B 参数 / 300B tokens）在 Chinchilla 视角下属于"训练不足"
- 后续 LLaMA 系列（7B 参数 / 1T tokens）是对 Chinchilla 建议的实践

### 预训练数据质量的决定性作用

| 维度 | 影响 |
|------|------|
| 去重 | 减少记忆，提升泛化，C4/RedPajama 等数据集均做了严格去重 |
| 质量过滤 | 困惑度过滤（PPL 筛选）、语言识别、内容过滤 |
| 领域配比 | 代码、数学、书籍、学术文章的比例影响对应能力 |
| 数据污染 | 训练集混入测试题会虚高评估指标，需要 n-gram 去污 |

## PM 决策视角

### 选择基座模型时的判断框架

**不要只看参数量，要看预训练 token 数和数据质量**
- 7B 模型在 2T tokens 上训练，可能在多数任务上胜过 70B 模型在 300B tokens 上训练
- 查阅技术报告时，优先关注数据配方、去重方法、领域配比

**CLM vs MLM 的选型逻辑**
- 需要生成（对话、写作、代码）→ CLM（GPT 类）
- 需要理解和分类（情感分析、NLI、抽取）→ MLM（BERT 类）仍有竞争力
- 现代趋势是 CLM 基础上加指令微调覆盖理解任务

**预训练成本估算**
- 1B 参数模型，100B tokens，A100 × 128 卡约需 1 周
- 7B 模型，1T tokens，A100 × 1024 卡约需 3 周
- 绝大多数团队应选择在开源基座上做 SFT，而非从头预训练

### 持续预训练（Continual Pre-training）
当领域数据稀缺时（医疗、法律、金融），在通用基座上用领域文本继续预训练，再 SFT，是比直接 SFT 更稳健的路线。
