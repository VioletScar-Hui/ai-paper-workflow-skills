| **发表年份** | 2024 |
| **核心问题** | 长序列视频生成中，世界模型因上下文窗口有限而遗忘已见场景，导致场景不一致和重复错误——如何让视频世界模型"记住"已生成的空间场景？ |
| **方法概述** | 在 latent space 中维护一个可更新的空间记忆图（Spatial Memory Map）；每帧生成后将关键 latent 特征写入记忆；下一帧生成时通过空间位置检索相关记忆 token，作为额外条件输入扩散/自回归模型 |
| **关键创新** | ① 潜在空间记忆图：以 2D/3D 空间坐标为键、latent 特征为值的可更新外部记忆，不受 context window 长度限制；② 位置感知读写：写入时以相机姿态/光流估计位置，读取时按当前视角查询相关区域；③ 记忆衰减机制：对长时未访问的记忆区域施加衰减，防止记忆爆炸；④ 与生成模型解耦：记忆模块作为即插即用组件，可附加到现有视频扩散模型 |
| **实验结果** | 在 Habitat、Minecraft 等室内/游戏场景上，长序列（>100 帧）生成的场景一致性（SSIM、LPIPS）显著优于无记忆基线；遗忘率（revisit consistency）从基线 42% 提升至 81%；FVD 在长序列上降低 23% |
| **数据集** | Habitat-Sim 合成数据（室内场景导航序列）；Minecraft 游戏录像（NeurIPS 2022 Diamond 数据集）；自建长序列评测集（200帧+） |
| **局限性** | 记忆图的空间坐标依赖相机姿态估计，姿态误差累积导致记忆错位；大场景下记忆容量仍有上限；对动态物体（移动 NPC、变化场景）记忆策略待改进；计算开销随序列长度线性增长 |
| **相关工作** | DreamerV3（Hafner et al.）、UniSim、GAIA-1、GameNGen；外部记忆机制参考 Neural Turing Machine（NTM）、Differentiable Neural Computer（DNC） |

## 原子概念索引

- **潜在空间记忆图（Latent Spatial Memory Map）**：以空间坐标为索引的外部记忆结构，存储已生成帧的 latent 特征，用于跨帧条件化 → [[外部记忆机制]]
- **位置感知读写**：基于相机姿态或光流估计将记忆 token 映射到 2D/3D 空间位置，实现空间感知的选择性检索 → [[空间推理]]
- **记忆衰减**：对长时间未被读取的记忆条目施加权重衰减，类似遗忘曲线，防止过期信息干扰生成 → [[记忆管理]]
- **即插即用记忆模块**：记忆组件与生成模型解耦设计，无需重训生成主干即可附加记忆能力 → [[模块化设计]]
- **FVD（Fréchet Video Distance）**：视频生成质量评估指标，类比图像的 FID，基于 I3D 特征分布距离 → [[视频生成评估]]
- **revisit consistency**：自定义评估指标，衡量模型重新访问已生成场景区域时的外观一致性 → [[长序列一致性评估]]
- **Neural Turing Machine（NTM）**：经典可微外部记忆架构，本文记忆机制的理论基础 → [[可微记忆]]

## 核心思想图示

```
帧 t-1 生成 → latent z_(t-1)
       ↓ 写入（位置编码）
  [空间记忆图 M]  ←→ 记忆衰减
       ↓ 读取（当前视角查询）
帧 t 生成 → 条件: [z_noise, 文本, 读取的记忆 tokens]
       ↓
  latent z_t → 解码 → 帧 t
```
