# 一致性幻觉：多 Agent 辩论如何隐藏推理不对齐

📄 **原文 PDF**：[[RAW/29 - The Consistency Illusion.pdf]]

## PM 速判（3 分钟）

> **这篇论文给 PM 的一句话**：多 Agent 辩论系统中，多个 Agent 达成答案共识通常被视为可靠信号——但这是**幻觉**：标准辩论协议会让表面矛盾减少、同时让推理相似度下降（"表面更一致，实际更发散"）；论文提出 GDP（有依据辩论协议）用提示级干预修复这个问题，推理对齐度大幅提升（Cohen's d = +1.43 到 +1.99）。

| 项目 | 评估 |
|------|------|
| **核心发现** | 答案共识 ≠ 推理共识（一致性幻觉） |
| **度量工具** | CARA（跨 Agent 推理对齐度量）：矛盾率 CR + 语义相似度 SIM |
| **修复方案** | GDP（有依据辩论协议）：要求 Agent 提交具名事实 + 明确表态 |
| **效果** | Cohen's d = +1.43 到 +1.99（推理对齐提升），无额外 LLM 调用 |
| **领域** | 医疗 QA（MedQA-USMLE / MedThink-Bench）|
| **成熟度** | 🧪 实验阶段，Drexel University |

## 核心机制

```
什么是"一致性幻觉"？
  标准辩论 M3（三 Agent，1轮辩论）的后辩结果 vs 前辩：
    CR（矛盾率）：0.104 → 0.035 ↓（好事，矛盾减少）
    SIM（推理相似度）：0.801 → 0.787 ↓（坏事，推理发散）
    结论：矛盾消失了，但推理路径也不一致了
          = Agent 删除了矛盾步骤但没有建立共同推理锚点
          = 答案一致，但三个 Agent 各自有不同的医学根据
  
真实对齐应该是：CR↓ AND SIM↑（矛盾减少+推理趋同）
幻觉表现为：CR↓ AND SIM↓（矛盾减少+推理发散）

GDP（Grounded Debate Protocol）如何修复：
  要求每个 Agent 在回应中：
    - 明确提出具名医学事实（"肾功能保留因为..."）
    - 对其他 Agent 的每个声明明确表态（同意/不同意）
      例："我同意 Agent B 关于 X 的声明，因为..."
           "我不同意 Agent C 的 Y 论点，因为..."
  
  效果机制：
    ① 强制共享推理词汇（AGREE/DISAGREE 引用对方论点 → SIM↑）
    ② 有了具名事实承诺，矛盾更容易被识别和消除 → CR↓
    ③ 零额外 LLM 调用，只是提示词修改
  
  GDP 辩论后：
    CR：0.117 → 0.098 ↓
    SIM：0.835 → 0.912 ↑ ← 真实对齐
```

## 核心结论（带时间锚）

1. **答案共识不蕴含推理共识：多 Agent 投票/辩论的可靠性假设存在根本缺陷** 📅 2026
   在开放性诊断/治疗选择任务中，答案相同的多个 Agent 可以依赖三套互相排斥的医学机制——这在医疗等高风险场景是系统性风险。

2. **标准辩论会主动恶化推理对齐：不辩不如辩** 📅 2026
   独立投票（无辩论）的推理对齐度高于标准辩论后的推理对齐度——说明辩论本身在"磨平"推理差异而不是"收敛"它。

3. **GDP 是提示级无成本修复：推理对齐从"幻觉"到真实对齐** 📅 2026
   Cohen's d = +1.43 到 +1.99 是非常大的效果量；且无需额外 LLM 调用，只是提示词结构变化。

## 对 AI PM 的启示

| 场景 | 洞察 |
|------|------|
| **多 Agent 系统设计** | 不要用"多个 Agent 给出相同答案"作为可靠性信号——需要验证推理路径是否也对齐 |
| **高风险决策辅助** | 医疗/法律/金融等场景：答案共识是必要条件但远不充分，需要推理层面的一致性 |
| **辩论协议设计** | 要求 Agent 提交"具名声明 + 对他人的明确表态"是无成本的推理对齐改进 |
| **审计指标** | CARA 类指标（CR + SIM 双维度）比单纯"答案一致率"更能反映多 Agent 系统的真实质量 |
| **产品边界** | 开放性任务（而非选择题）的推理幻觉更严重——设计产品时应预先考虑推理层面的审计 |

## 论文精读卡片

**一句话**：标准多 Agent 辩论协议造成"一致性幻觉"（答案共识但推理发散，SIM 从 0.801 降至 0.787），提出的 GDP 协议仅通过提示级修改将推理对齐效果量提升至 Cohen's d = +1.43~+1.99。

**问题**：多 Agent 辩论被广泛用作提升 LLM 可靠性的机制，但其底层假设——"多 Agent 达成共识意味着推理也一致"——从未被严格验证。在医疗等高风险场景，答案一致但推理路径互斥是严重系统性风险。

**核心方法**：
- 提出 CARA 双维度度量：矛盾率（CR）+ 推理语义相似度（SIM），分别衡量推理对齐的两个正交维度
- 实证标准辩论（M3协议）的"幻觉"：辩论后 CR 从 0.104 降至 0.035（矛盾减少），但 SIM 从 0.801 降至 0.787（推理发散），揭示一致性幻觉
- 提出 GDP（Grounded Debate Protocol）：要求每个 Agent 提交具名医学事实，并对其他 Agent 每条声明明确表态（同意/不同意+理由），强制共享推理词汇，无需额外 LLM 调用

**关键图/公式**：CARA = {CR, SIM} 双维矩阵——真实对齐区间为 CR↓ AND SIM↑，幻觉表现为 CR↓ AND SIM↓；GDP 辩论后达到 CR: 0.117→0.098 且 SIM: 0.835→0.912，即真实对齐。

**实验设置**：
- 规模/数据：MedQA-USMLE 和 MedThink-Bench，医疗多选 QA 任务；三 Agent（M3），1轮辩论
- 对比：无辩论独立投票 vs 标准辩论（M3）vs GDP，以及 CARA 指标的人工标注验证

**最强证据**：GDP 的 Cohen's d = +1.43 到 +1.99（推理对齐提升），属于极大效果量；关键对照实验表明独立投票的推理对齐度高于标准辩论，说明辩论本身是推理发散的来源。

**最弱证据**：实验仅在医疗 QA（选择题格式）上验证，GDP 在开放生成任务（对话、写作、规划）中的适用性未测试；具名事实的"质量"本身未被评估，Agent 提供错误事实但仍收敛的情形未被分析。

**可复用点**：GDP 的提示结构直接可用——在任何多 Agent 辩论场景中，要求每个 Agent 回应时附上"我同意/不同意 Agent X 关于 [声明] 的观点，因为 [具名事实]"，零成本改善推理对齐；CARA 框架（CR+SIM）可作为内部多 Agent 系统质量监控指标。

**我能拿它做什么**：
