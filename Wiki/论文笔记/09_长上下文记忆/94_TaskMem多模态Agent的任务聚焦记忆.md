# TaskMem：多模态 Agent 的任务聚焦记忆

📄 **原文 PDF**：[[RAW/94 - Task-Focused Memorization for Multimodal Agents.pdf]]

## PM 速判（30秒）

> **解决 Agent 记忆的核心问题：不是"怎么记"，而是"记什么"。** TaskMem 用 RL 训练记忆策略，第一阶段学习高质量记忆（准确、无冗余、格式正确），第二阶段在部署后用当前任务分布动态调整"关注什么"，让记忆从通用变为任务聚焦。在 VideoMME/EgoLife/EgoTempo 上分别提升 +6.3%/+7.0%/+5.3%（任务仅凭记忆作答，不看原始视频）。

## 核心机制

```
核心洞察：
  传统记忆设计：关注"记忆模块如何存储" → 解决 How to recall
  TaskMem 关注："什么内容值得记忆" → 解决 What to memorize
  
  关键挑战：Agent 连续感知无限多模态观察流（视频/图像/文本）
             → 组合爆炸的信息量中，只有少量与未来任务相关

两阶段训练（RL-based）：

  Phase 1（预部署）：How to Memorize
    优化目标：基础记忆质量（准确性、无冗余、格式）
    方法：RL（直接优化奖励，不用 SFT 数据上限）
    奖励：格式 + 信息量 + 准确性
    
  Phase 2（部署后）：What to Memorize  
    触发时机：Agent 已在真实环境中运行了一段时间
    关键：用近期遇到的任务定义奖励模型
         → 哪些记忆内容对当前任务有帮助 → 调整记忆策略
    技巧：构建 pairwise preference 数据 → 引导策略聚焦任务相关内容

评估设置（严格版）：
  VideoMME / EgoLife / EgoTempo 重新构建为序列任务流
  Agent 先看视频生成记忆 → 之后只凭记忆回答问题（不看视频）
  
模型基础：Qwen3-VL-30B-A3B
```

## PM 结论

- 📅 2025 年，长期记忆成为 Agent 产品核心差异化能力
- **两阶段设计的关键洞察**：通用记忆（Phase 1）可离线训练；任务聚焦（Phase 2）需在线部署后适配
- Phase 2 是核心创新：用当前任务分布作为奖励信号，让模型自动学会"什么对用户当前需求重要"
- 对 PM：有实际用户场景（具体任务类型）后，Phase 2 才能发挥最大效果 → 冷启动用 Phase 1

## 论文精读卡片

**一句话**：用两阶段 RL 训练记忆策略，让 Agent 从"通用记忆"进化为"任务聚焦记忆"，VideoMME/EgoLife/EgoTempo 分别提升 +6.3%/+7.0%/+5.3%（仅凭记忆作答，不看原始视频）。

**问题**：多模态 Agent 连续感知无限观察流（视频/图像/文本），组合爆炸的信息量中只有少量与未来任务相关；现有记忆设计关注"如何存储"，忽略了"该记什么"这个核心问题。

**核心方法**：
- Phase 1（预部署）：RL 优化基础记忆质量——准确性、无冗余、格式正确；奖励函数覆盖格式+信息量+准确性
- Phase 2（部署后）：用近期遇到的任务定义奖励信号，构建 pairwise preference 数据引导策略聚焦任务相关内容
- 评估严格化：先看视频生成记忆，之后只凭记忆回答问题（不回看视频），测量纯记忆质量

**关键图/公式**：两阶段解耦的核心洞察——Phase 1 可离线完成（通用记忆），Phase 2 需在部署后用真实用户任务分布驱动，且 Phase 2 才是真正差异化的来源。

**实验设置**：
- 规模/数据：Qwen3-VL-30B-A3B 基础模型；VideoMME、EgoLife、EgoTempo 三个基准重构为序列任务流
- 对比：Phase1-only vs Phase1+Phase2，以及与直接看视频回答的 upperbound 对比

**最强证据**：EgoLife 提升 +7.0%，仅凭记忆回答的精度接近直接观看视频，说明任务聚焦后记忆的信息保留效率大幅提升。

**最弱证据**：实验仅在视频理解类任务上验证，任务分布较窄；Phase 2 训练依赖足够多的真实用户任务，冷启动期效果未量化；Qwen3-VL-30B 本身能力很强，不清楚方法在小模型上是否稳健。

**可复用点**：Phase 2 "用当前任务分布作为奖励信号" 的在线自适应策略——任何长期运行 Agent 系统都可借鉴：部署后收集用户任务样本 → 构建偏好数据 → 微调记忆策略。
