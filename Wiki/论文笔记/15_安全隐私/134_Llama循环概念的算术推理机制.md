# Llama 用十进制加法处理循环概念的推理

📄 **原文 PDF**：[[RAW/134 - Arithmetic in the Wild - Llama uses Base-10 Addition to Reason About Cyclic Concepts.pdf]]

## PM 速判（3 分钟）

> **这篇论文给 PM 的一句话**：Llama-3.1-8B 在"8月后6个月是哪个月"这类问题上，**先做十进制加法（6+8=14），再映射回概念（14→二月）**——而非直接计算模运算；28个 MLP 神经元（层18，占 0.2%）被复用于月份、星期、小时的所有任务。

| 项目 | 评估 |
|------|------|
| **研究方向** | 机制可解释性（Mechanistic Interpretability）|
| **关键发现** | 循环概念推理 = 十进制加法 + 概念映射（两步，非一步模运算） |
| **实验规模** | 62 页深度分析，涵盖月份/星期/小时三类任务 |
| **成熟度** | 🔬 基础研究，无直接产品应用 |

---

## 核心发现

```
直觉假设（错的）：
  "六月后6个月" → 模型直接在月份循环空间（周期12）做计算
  
实际机制（Llama 的做法）：
  步骤1：把输入转为数字 (六月=6, 8月=8)
         使用同一套28个MLP神经元
         在 Layer 18 做十进制加法：6+8=14
  步骤2：在后期层把数字14映射回概念空间：14→二月

关键：
  表示层：输入概念（月份）确实有循环几何结构（圆形分布）
  计算层：但计算机制不是利用这个圆形结构，而是先"数字化"再做加法
```

## 论文精读卡片

**一句话**：Llama-3.1-8B 在"8月后6个月是哪个月"这类问题上并非直接做模运算，而是先用 Layer 18 的 28 个 MLP 神经元（占 0.2%）执行十进制加法（6+8=14），再在后期层把数字 14 映射回概念（二月）——28个神经元被跨月份/星期/小时三类任务完全复用。

**问题**：LLM 在处理循环概念（月份/星期/小时）的推理时，内部机制是什么？是利用表示层的循环几何结构（圆形分布）做模运算，还是通过其他路径？

**核心方法**：
- 因果干预实验：消融 Layer 18 的 28个 MLP 神经元，验证其对循环算术任务的因果贡献
- 表示层分析：用探针（probe）验证输入概念的表示是否有循环几何结构（圆形分布）
- 对比 Base vs Instruct：确认同一批神经元在两种模型中的作用差异
- 三任务跨验证：月份/星期/小时三类任务共享同一套 28 个神经元的复用分析

**关键图/公式**：两步机制：步骤1（Layer 18，28个MLP神经元）= 十进制加法（6+8=14）；步骤2（后期层）= 数字→概念映射（14→二月）。表示层有圆形结构但计算不利用该结构——"表示什么"和"怎么算"解耦。

**实验设置**：
- 规模/数据：62页深度分析；Llama-3.1-8B-Instruct；月份/星期/小时三类循环推理任务
- 对比：理论假设（模运算/直接循环几何计算）vs 实测机制（十进制加法+概念映射）

**最强证据**：28个 MLP 神经元（Layer 18，0.2%）在消融后导致三类循环算术任务全部失败，证明其因果必要性；同一套神经元被月份/星期/小时完全复用，证明通用化计算机制。

**最弱证据**：只分析了 Llama-3.1-8B-Instruct，结论是否推广到其他模型系列（Qwen/Gemini/Claude）未验证；"十进制加法+映射"机制是否适用于减法/乘法类循环推理（如"6个月前"）未分析。

**可复用点**："表示层几何结构 ≠ 计算机制"的认知——LLM 可能有环形表示但不做环形计算；神经元专业化稀疏复用（0.2% 神经元负责跨域通用计算）作为理解 LLM 泛化能力的框架。

**和哪些论文相关**：
- [[Wiki/论文笔记/08_效率量化/131_CNA对比神经元归因行为引导]] — 共同主题：极少数 MLP 神经元（0.1-0.2%）负责特定功能，神经元稀疏专业化是机制可解释性的共同发现

**我能拿它做什么**：
- 在解释 LLM 为什么在特定范围的算术（如月份加法跨年边界）上出错时，用"十进制中间值超出映射范围"作为机制解释
- 向团队解释"LLM 通用化能力来自少数神经元的复用"这个机制，帮助理解 fine-tuning 为何有时会破坏跨域能力
- 这是基础研究，不影响产品决策但丰富对 LLM 内部机制的直觉
