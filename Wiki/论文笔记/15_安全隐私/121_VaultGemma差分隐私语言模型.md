# VaultGemma：差分隐私 Gemma 模型

📄 **原文 PDF**：[[RAW/121 - VaultGemma - A Differentially Private Gemma Model.pdf]]

## PM 速判（3 分钟）

> **这篇论文给 PM 的一句话**：Google 开源的 VaultGemma 1B 是首个**完整预训练阶段**应用差分隐私（DP）的 Gemma 模型，记忆率降至 0，代价是能力相当于5年前的 GPT-2——但这是合规性优先场景（医疗、金融、法律）下企业自建 AI 的关键基础设施选项。

| 项目 | 评估 |
|------|------|
| **模型规模** | 1B 参数 |
| **隐私保证** | (ε ≤ 2.0, δ ≤ 1.1×10⁻¹⁰)-序列级 DP |
| **开放状态** | 🔧 开源权重 |
| **训练数据** | 与 Gemma 2 27B 相同（13T tokens） |
| **能力对比** | ≈ GPT-2 级别（非 DP 的 Gemma 3 1B 远超它） |

## 核心概念：什么是差分隐私（DP）？

```
普通 LLM 训练：
  数据 → 梯度更新 → 模型参数
  问题：模型可能"记住"训练数据，被提示词攻击提取

差分隐私训练（DP-SGD）：
  数据 → 计算每个样本梯度 → 裁剪梯度 → 加入校准高斯噪声
        → 汇总带噪梯度 → 模型参数
        
  保证：即使攻击者有完整模型权重，也无法区分
        "数据集含某条记录" 和 "不含该记录" 训练出来的模型
  
  (ε, δ)-DP：
    ε ≤ 2.0 是强隐私（ε 越小越好）
    δ ≤ 1.1×10⁻¹⁰ 是极小的失败概率
```

---

## 关键发现：为什么"只在微调时用 DP"不够

```
常见错误做法：
  预训练（无DP）→ 微调（有DP）
  
  问题：
  1. 预训练时模型已经"记住"了 PII（个人信息）
  2. DP 微调不能"擦掉"预训练时的记忆
  3. 对开源模型：攻击者有完整权重，可以探测预训练记忆
  
VaultGemma 的做法：
  预训练 + 微调 = 全程 DP
  → 记忆率降至 0（vs 所有非 DP Gemma 版本都有可检测记忆率）
```

## 能力代价

| 模型 | ARC-C | ARC-E | HellaSwag | 备注 |
|------|-------|-------|-----------|------|
| **VaultGemma 1B（DP）** | 26.45 | 51.78 | 39.09 | 本文 |
| Gemma 3 1B（非DP） | 38.31 | 71.34 | 61.04 | 差距明显 |
| GPT-2 1.5B（2020，非DP） | 39.78 | 51.10 | 47.91 | 能力相当 |

**结论**：当前全程 DP 训练的模型能力 ≈ 5年前的非隐私模型。

---

## 核心结论（带时间锚）

1. **全程 DP 训练是合规 AI 的唯一可靠路径** 📅 2025.09
   "微调时加 DP"无法防止预训练记忆被提取——这对处理医疗/金融/法律私人数据的 AI 产品是关键架构结论。

2. **能力-隐私 trade-off 仍然显著** 📅 2025.09
   DP 模型能力相当于5年前的非隐私模型——但这个差距在缩小（VaultGemma 是第一步），企业需要权衡"合规必须"vs"产品竞争力"。

3. **记忆率 = 0 是可验证的隐私目标** 📅 2025.09
   用"可提取训练数据比率"作为模型隐私的量化指标——这是监管机构和企业合规部门可以接受的实测数据格式。

## 论文精读卡片

**一句话**：VaultGemma 1B 是首个全程预训练阶段应用差分隐私（ε≤2.0, δ≤1.1×10⁻¹⁰）的 Gemma 开源模型，记忆率降至 0，代价是能力仅相当于 2020 年的 GPT-2（ARC-C 26.45 vs. 非 DP 的 Gemma 3 1B 的 38.31）。

**问题**：企业在医疗/金融/法律场景中使用 LLM 时，模型可能"记忆"训练数据中的 PII（个人信息），被提示词攻击提取；常见的"只在微调阶段加差分隐私"做法无法消除预训练阶段的记忆，开源模型的全量权重使攻击更容易。

**核心方法**：
- 全程差分隐私训练（DP-SGD）：预训练 + 微调全阶段均使用 DP-SGD（每个样本梯度裁剪 → 加入校准高斯噪声 → 汇总带噪梯度），而非仅在微调阶段加 DP
- 隐私预算：(ε≤2.0, δ≤1.1×10⁻¹⁰)-序列级 DP，ε=2.0 是当前实践中的强隐私标准
- 训练数据与 Gemma 2 27B 相同（13T tokens），确保隐私代价来自 DP 机制而非数据差异

**关键图/公式**：(ε, δ)-DP 保证：`即使攻击者有完整模型权重，也无法区分"数据集含某条记录"和"不含该记录"训练出来的模型`。记忆率：VaultGemma = 0；所有非 DP Gemma 版本均有可检测的记忆率。

**实验设置**：
- 规模/数据：1B 参数，13T tokens 训练数据（与 Gemma 2 27B 相同）
- 对比：Gemma 3 1B（非 DP）、GPT-2 1.5B（非 DP，2020 年）；评测集 ARC-C、ARC-E、HellaSwag；记忆率测试

**最强证据**：记忆率降至 0（vs. 所有非 DP 版本均有可检测记忆率），这是最直接的隐私保证实测证据；能力基准 ARC-E 51.78 与 GPT-2 1.5B（51.10）相当，证明代价明确且可量化。

**最弱证据**：ARC-C（26.45）远低于非 DP 的 Gemma 3 1B（38.31），实际产品中这个能力差距对用户体验的影响较大；ε=2.0 作为"强隐私"标准仍有争议，学术界部分人认为 ε=1.0 才是充分强隐私。

**可复用点**：全程 DP 训练的必要性论据——"微调时加 DP 不能擦掉预训练记忆"这个论点可直接用于与合规团队/监管机构的沟通，说明为什么需要从预训练开始就应用 DP；"记忆率=0"是可量化的合规指标格式。
