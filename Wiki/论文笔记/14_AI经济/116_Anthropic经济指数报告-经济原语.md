# Anthropic 经济指数报告：经济原语（Economic Primitives）

📄 **原文 PDF**：[[RAW/116 - Anthropic Economic Index report - Economic primitives.pdf]]

## PM 速判（3 分钟）

> **这篇论文给 PM 的一句话**：Anthropic 推出了衡量 AI 使用质量的 5 个"经济原语"——任务复杂度、人/AI技能、使用场景、AI自主度、任务成功率——并用这套框架得出关键结论：**调整模型可靠性后，AI 对劳动生产率的影响从 1.8 pp/年降至约 1.0 pp/年**，但当前最强模型在约 3.5小时任务处的成功率已达 50%，且仍在快速提升。

## 核心框架：5 个经济原语

```
经济原语（Economic Primitives）= AI 使用的基础测量维度

之前只测：做什么任务 + 自动化/辅助模式
本报告新增 5 维：

1. 任务复杂度     人工独立完成需要多长时间？
2. 人/AI技能水平  理解对话需要的受教育年数
3. 使用场景       工作 / 学业 / 个人
4. AI自主度       用户给Claude多少决策权？
5. 任务成功率     Claude 是否成功完成了任务？
```

**为什么叫"原语"（Primitives）**：它们是简单、基础、可组合的——就像编程中的原子操作，不完美但可以叠加组合产生更丰富的分析信号。

## 主要发现：Nov 2025 数据快照

### 1. 使用集中度：编程仍主导

```
Claude.ai TOP 10 任务 = 24% 的对话量（Aug: 23%）
API TOP 10 任务 = 32% 的对话量（Aug: 28%）

最大单任务：修复软件错误 = Claude.ai 6%，API 10%
编程类任务总占比：Claude.ai 34% / API 46%
```

### 2. 辅助模式重新超越自动化

```
Jan 2025: 辅助56% / 自动化41%
Aug 2025: 辅助低于自动化（异常峰值）
Nov 2025: 辅助52% / 自动化45%（回归正常）

→ Directive模式（完全委托）从 39% 回落至 32%
→ 但仍高于一年前，底层趋势仍向自动化发展
```

### 3. 美国内部收敛速度超预期

```
历史上技术扩散达到全美均等：约50年
Claude 预计达到各州人均使用均等：2-5年（10倍加速）
驱动因素：数学/计算机类职业占比高的州使用率更高
```

## 关键发现：任务视野（Task Horizon）

```
任务视野 = AI成功率降至50%时对应的任务耗时

实测结果（Nov 2025 数据，Sonnet 4.5 级别）：
  API 数据: 50%成功率对应 3.5 小时任务
  Claude.ai 数据: 50%成功率对应约 19 小时任务

METR基准参照：
  Sonnet 4.5: ~2小时  
  Opus 4.5: ~5小时
```

**为什么 Claude.ai 比 API 高这么多？**
- 多轮对话把复杂任务拆解成小步骤
- 用户实时反馈纠正错误（人在回路）
- 选择偏差：用户倾向于把"容易通过迭代解决"的任务带给 Claude

**PM 含义**：对话式（Claude.ai）产品的实际任务处理上限远高于 API 产品——因为用户参与本身是 AI 能力的放大器。

---

## 关键发现：有效AI覆盖率 vs. 任务覆盖率

```
任务覆盖率 = AI 能做的任务占总任务数的比例（表面数据）
有效AI覆盖率 = AI 能成功完成的任务 × 该任务在工作日中的时间占比

对比案例：
  数据录入员：任务覆盖率低（9个任务中只有2个被AI覆盖）
              但有效AI覆盖率高——因为被覆盖的恰好是最耗时的核心任务
              
  微生物学家：任务覆盖率 50%，但有效AI覆盖率低
              因为最耗时的核心任务（实验室手操作）不被AI覆盖
```

**PM 含义**：选择 AI 切入的职业/场景，应优先看"有效AI覆盖率"而非"任务数量覆盖"——覆盖最耗时的核心工作才有实质商业价值。

---

## 关键发现：AI 正在"去技能化"大多数职业

```
整体经济任务平均需教育年数：13.2年
Claude 覆盖到的任务平均需教育年数：14.4年（高出1年）

→ AI 倾向于覆盖更高技能的任务
→ AI 接手高技能任务后，剩余给人做的是较低技能任务
→ 净效果：多数职业经历"去技能化"

去技能化职业举例：
  旅行代理：AI 负责"规划行程/计算成本"（高技能）
            人负责"打印票/收款"（低技能）
  技术写作：AI 负责"分析领域发展/审查出版物"（高技能）
            人负责"绘制草图/观察生产"（低技能）

反例（技能提升）：
  房产经理：AI 接手行政记录工作，
            人专注于贷款谈判、建筑公司协商（高技能）
```

## 生产率修正：1.8pp → ~1.0pp

```
之前预测：AI 可带来 1.8 pp/年 美国劳动生产率增长（未来10年）

本报告修正：
  如果把任务成功率纳入——有35%的任务需验证/返工
  → 生产率估算下降约 45%，约为 ~1.0 pp/年
  
关键假设：任务互补性（CES弹性σ）
  σ<1：任务互补 → 短板任务成为瓶颈 → 更低
  σ>1：任务可替换 → 优先用AI做的时间 → 更高
  σ=1：还原原始 1.8pp 估算
```

**PM 含义**：当你向客户/老板汇报"AI 提升生产率 X 倍"时，必须说明"这是理论上限，实际成功率打折后 ~50%"——否则会失去信任。

## 核心结论（带时间锚）

1. **"量"已够，缺的是"质"的测量** 📅 2026.01
   任务数量覆盖指标已知不足，5个经济原语框架提供了更丰富的质量维度——包括成功率、自主度、技能要求等，这些才是真正影响商业价值的核心参数。

2. **AI 任务视野 3.5h（API）→19h（对话）** 📅 2025.11
   对话式产品的任务时间上限远超 API 纯自动化——人在回路是一种能力放大器，产品设计应最大化这种协作效应。

3. **AI 去技能化主导，少数职业反向** 📅 2025.11
   因为 AI 优先接管高技能任务（14.4 vs 13.2年教育），净效果是大多数职业的剩余工作更低技能。政策和产品都需要应对这种技能替换格局。

4. **实际生产率影响：1.0 pp/年（纳入成功率后）** 📅 2026.01
   扣除任务失败导致的重做开销后，生产率增长从 1.8 降至约 1.0 pp/年——仍是显著增长，但要正确设定用户预期。

## 论文精读卡片

**一句话**：Anthropic 推出 5 维"经济原语"框架（任务复杂度/技能水平/使用场景/AI自主度/成功率），发现 AI 任务视野在实际对话中达 19 小时，纳入成功率后 AI 劳动生产率贡献从 1.8 pp/年修正为约 1.0 pp/年。

**问题**：现有 AI 使用数据只测量"做什么任务"和"自动化/辅助模式"，无法评估 AI 使用的质量和商业价值，导致 AI 对劳动生产率影响的估算过于乐观。

**核心方法**：
- 定义 5 个经济原语：①任务复杂度（独立完成所需时间）②人/AI技能（理解对话需要的受教育年数）③使用场景（工作/学业/个人）④AI自主度（用户给 Claude 多少决策权）⑤任务成功率
- 引入"有效 AI 覆盖率"：不只看任务数量覆盖，而是看"被覆盖的任务占工作时间的比例"
- 引入"任务视野（Task Horizon）"：AI 成功率降至 50% 时对应的任务耗时

**关键图/公式**：任务视野公式——API 数据 50% 成功率对应 3.5 小时任务；Claude.ai 对话数据对应约 19 小时（因多轮对话+人在回路放大效应）。生产率修正：`1.8 pp/年 × (1 - 0.35 返工开销) ≈ 1.0 pp/年`。

**实验设置**：
- 规模/数据：Anthropic Economic Index Nov 2025 数据快照，Claude.ai + API 全平台；对照 METR 基准（Sonnet 4.5 约 2 小时，Opus 4.5 约 5 小时）
- 对比：任务覆盖率 vs. 有效 AI 覆盖率（数据录入员 vs. 微生物学家案例对比）；修正前后的劳动生产率估算

**最强证据**：Claude.ai 任务视野 19 小时远超 API 的 3.5 小时，证明"人在回路"是 AI 能力的真实放大器；数据录入员有效 AI 覆盖率高（覆盖了最耗时核心任务），微生物学家低（核心手工实验未被覆盖）——两个案例清晰区分了"表面覆盖"和"有效覆盖"。

**最弱证据**：1.0 pp/年的修正依赖 CES 弹性参数 σ 的假设（任务互补性），σ 的实际值目前无法精确估计；Nov 2025 快照数据，距今已有变化。

**可复用点**：有效 AI 覆盖率框架——评估 AI 产品在某个职业/场景的真实价值时，不看"能做的任务数量"，而看"被覆盖的任务是否是该职业最耗时的核心工作"；这是产品选型和市场进入策略的核心判断工具。
