# Anthropic 经济指数报告：学习曲线（Learning Curves）

📄 **原文 PDF**：[[RAW/115 - Anthropic Economic Index report - Learning curves.pdf]]

## PM 速判（3 分钟）

> **这篇论文给 PM 的一句话**：Anthropic 发现使用 Claude 6 个月以上的老用户成功率比新用户高 10%，且不能用任务难度或背景差异解释——**边学边用（Learning-by-doing）是真实存在的**，意味着 AI 工具有自强化的用户粘性，但也会加剧 AI 使用技能的贫富分化。

| 项目 | 评估 |
|------|------|
| **数据时间** | 2026.02 Claude 使用数据（Claude Opus 4.6 发布期） |
| **核心发现** | 老用户（6个月+）成功率高 10%；模型选择与任务复杂度精准匹配 |
| **时间序列** | 本报告是系列第4篇：Aug2025→Nov2025→Mar2026→Jun2026(Cadences) |

## 主要发现

### 1. 学习曲线效应（核心）

```
使用 Claude 6 个月以上的用户：
  ✓ 个人对话比例少 10%（更工作化）
  ✓ 输入问题的教育水平高 6%（更专业）
  ✓ 会话成功率高 10%（排除任务类型、国家等因素后仍显著）
  
→ 使用时间越长，用户越懂得"如何用好 AI"
→ 这是 Learning-by-doing 的实证证据
```

**PM 含义**：用户粘性不只来自功能习惯，还来自"AI 使用技能"的积累——留住老用户更有价值，因为他们能获得更好的产品体验。

### 2. 模型选择的精准匹配

```
Opus（最强模型）使用场景：
  编程任务：比平均多 12-15 个百分点
  辅导任务：比平均少 7 个百分点
  
→ 用户自发学会"用正确的模型做正确的事"
→ API 用户的这种差异是 Claude.ai 用户的 2 倍
```

### 3. 采用曲线（早期 → 普及）

```
早期用户（技术类）：高价值任务（编程、复杂分析）
后期用户（大众化）：多样化任务（体育、产品比较、家居维护）
→ 任务平均价值（以工资衡量）在 Claude.ai 上略有下降
  但在 API 上上升（API 用户专业化程度高）
```

### 4. 全球不平等持续

- Top 20 国家 = 48% 的人均使用量（上升）
- 美国内部：高使用量州的占比从 40% 下降到 38%（内部平等化）
- 国家间差距扩大，国家内差距缩小

---

## 核心结论（带时间锚）

1. **AI 使用技能是可习得的真实技能** 📅 2026.02
   10% 的成功率差异不能被任务类型或背景解释，说明"懂得如何与 AI 交互"本身是有价值的能力——这个能力在早期采用者中正在积累。

2. **早期采用者的双重优势** 📅 2026.02
   技术类早期用户：既是 AI 影响最大的群体（高 AI 曝光度），又是从 AI 中获益最多的群体（高成功率）——这可能加剧技术精英与普通工作者的能力分化。

3. **Claude.ai 用户多样化 vs. API 用户专业化** 📅 2026.02
   两个产品面向不同市场：Claude.ai 走大众普及路线，API 走专业深度路线——产品策略差异正在数据中显现。

## 论文精读卡片

**一句话**：分析 2026.02 Claude 使用数据发现，使用 6 个月以上的老用户会话成功率比新用户高 10%，且控制任务类型后仍显著，证明"AI 使用技能"是通过边学边用（Learning-by-doing）习得的真实可积累技能。

**问题**：AI 工具的用户成功率提升是否来自"使用技能积累"，还是仅仅因为任务变得更容易或用户筛选效应？学习曲线效应的存在对产品设计和用户保留策略有何影响？

**核心方法**：
- 对 2026.02 Claude 使用数据按用户使用时长分层（新用户 vs. 6 个月+ 老用户）
- 控制任务类型、国家、任务难度后，比较成功率差异
- 同时分析模型选择行为（用户是否自发学会"用正确模型做正确任务"）

**关键图/公式**：学习曲线效应——老用户（6个月+）：个人对话比例少 10%（更工作化）、输入问题教育水平高 6%、会话成功率高 10%（排除混淆因素后仍显著）。Opus 用于编程比平均多 12-15pp，用于辅导少 7pp。

**实验设置**：
- 规模/数据：2026.02 Claude 全平台数据（Claude.ai + API），按用户使用时长（<1个月到 6个月+）分层分析
- 对比：新用户 vs. 老用户的成功率、任务类型分布、模型选择精准度；Claude.ai vs. API 用户的模型选择差异（API 用户差异是 Claude.ai 的 2 倍）

**最强证据**：成功率 +10% 在控制任务类型、国家后仍显著——排除了"老用户只是做更简单任务"的解释，证明是真实的技能积累效应。

**最弱证据**：10% 的成功率差异可能部分来自用户自选择（坚持使用 6 个月的用户本就更有技能和动力）；报告基于单一时间点（2026.02）横截面数据，非追踪同一批用户的纵向研究。

**可复用点**：学习曲线效应意味着用户留存带来质量提升（不只是增加使用量）——"老用户成功率更高"是用户保留的经济论据；产品设计应有意加速学习曲线（新手引导、任务分级、Best Practice 分享）。
