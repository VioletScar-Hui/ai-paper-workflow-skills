# AI Agent 如何重塑知识工作：Perplexity 的实证研究

📄 **原文 PDF**：[[RAW/24 - How AI Agents Reshape Knowledge Work.pdf]]

## PM 速判（5 分钟）

> **这篇论文给 PM 的一句话**：Perplexity 用真实产品数据（Search vs Computer）研究 AI Agent 对知识工作的经济影响——结论惊人：Computer 每次会话完成 **26 分钟**自主工作（Search 只有 33 秒）；在匹配任务上减少 **87% 时间、94% 成本**；用户用 Computer 完成的任务认知复杂度更高、跨越更多职业边界；3 个月内查询量增长 **84×**。

| 关键发现 | 数值 |
|---------|------|
| 自主工作时间/会话 | Computer: 26分钟 vs Search: 33秒（**48×**）|
| 任务完成时间 | 269分钟 → 36分钟（**87%** 下降）|
| 成本估算 | vs 人工+Search：**94%** 成本降低 |
| 用户不满意率 | Computer 比 Search **低 55%** |
| 查询量增长 | 3 个月内 **84×**（Feb-May 2026） |
| 抽象非例行任务比例 | Computer: 71% vs Search: 53% |

---

## 理论框架

```
任务经济学模型（固定成本 vs 边际成本的转换）：

传统工具（Search）：
  固定成本：低（只需输入查询）
  边际成本：高（每一步都需用户手动执行）
  → 用户只做"低步数 = 低价值"的任务（因为高步数任务太贵）

Agent（Computer）：
  固定成本：高（委托 + 验证成本，需要提供完整上下文）
  边际成本：极低（后续每步由 AI 自主完成）
  → 扩展了"可负担的任务边界"：以前不值得做的复杂任务现在可以做了

模型预测（均获实证验证）：
  ✓ Agent 使用时任务质量更高（固定成本筛选掉低价值任务）
  ✓ Agent 用户完成更高认知层次的任务
  ✓ Agent 解锁以前未被尝试的工作活动
  ✓ 前置预算约束时，总剩余和价值成本比均提升
```

## 核心实证发现

### 发现 1：自主程度（Autonomy）

```
研究方法：匹配会话（近乎相同初始查询，相似度 >0.99 的 10,000 对会话）
→ 同一用户、同一任务，用两个产品完成

Computer 后续操作分布 vs Search：
  搜索/信息获取 减少（已由 Computer 自动完成）
  核实/验证 增加（用户从"执行者"变成"检查者"）
  扩展/迭代 增加（用户能处理更高阶的跟进工作）
  
→ Computer 自动化了"分解 + 执行"，用户聚焦于"验证 + 扩展"
```

### 发现 2：效率提升

```
在匹配任务上（最大对比）：
  完成时间：269分钟（人工+Search）→ 36分钟（Computer），-87%
  成本估算：-94%（按时薪计算）

用户访谈报告的实际加速（25个用户，6企业+19消费者）：
  中位值：~25×
  范围：5× ~ 300×+
  外包成本：降低 2-3 个数量级（120-750×更便宜）

具体案例：
  - 72小时窗口内 6× 人力杠杆的报告/分析任务
  - 课程内容：1-3周 → ~1天（5-15×）
  - 完整网站从零重建：~2.5天
```

### 发现 3：任务范围变化

```
Computer 查询 vs Search 查询（5,000 双产品用户对比）：

认知复杂度：
  抽象非例行任务：71% vs 53%（+18pp）
  高阶认知（Bloom）：76% vs 55%（+21pp）
  创造级工作："Create"占 50% vs 26%（+24pp）

知识广度：
  跨职业边界任务：Computer 更多（+9pp 平均，所有8个职业集群均如此）
  需要的 O*NET 知识域数：2.40 vs 1.74（+38%）
  需要 3+ 知识域的比例：51% vs 17%

任务组合度：
  O*NET 通用工作活动/查询：2.95 vs 2.24（+32%）
  详细工作活动/查询：3.64 vs 2.29（+59%）
  
解锁新任务：
  23% 的 Computer 任务是该用户从未在 Search 中尝试过的
  → Computer 解锁了以前"不会尝试"而非"被 AI 取代"的工作
```

## 核心结论（带时间锚）

1. **AI Agent 不只是更快的助手，而是扩展了用户愿意尝试的任务范围** 📅 2026
   "解锁新任务"（23%）比"加速已有任务"更重要——这是 AI Agent 的增量价值主张，而不只是效率提升。

2. **固定委托成本导致 Agent 用于更高价值任务** 📅 2026
   写清楚"让 Computer 做"的成本促使用户只委托值得做的复杂任务；这筛选出了高价值使用场景，解释了更高的满意度。

3. **知识工作者从执行者转变为验证者和编排者** 📅 2026
   Computer 后续查询更多是"验证/扩展"而非"执行"——这是 AI Agent 对人类工作角色最实质性的改变信号。

4. **成本降低达到"数量级"级别，使以前不可能的工作成为可能** 📅 2026
   外包成本降低 120-750×；这意味着以前只有大企业才能负担的专业服务（法律/财务/技术）开始对个体可用。

## 论文精读卡片

**一句话**：Perplexity 真实数据显示 Computer（AI Agent）每次会话完成 26 分钟自主工作（Search 只有 33 秒，48× 差距），匹配任务上减少 87% 时间和 94% 成本，23% 的 Computer 任务是用户从未在 Search 中尝试过的新任务类型，3 个月内使用量增长 84×。

**问题**：AI Agent 的经济影响是"替代已有工作"还是"解锁新工作"？现有研究缺乏来自真实产品用户数据（而非实验室设置）的大规模实证分析；同时缺乏解释"为什么 Agent 比工具更适合复杂任务"的经济学理论框架。

**核心方法**：
- 固定成本/边际成本经济模型：Agent 的固定委托成本高但边际成本低（每步自主完成），导致用户自然筛选出"值得委托的高价值任务"；这解释了 Computer 用户满意度更高的机制
- 匹配会话分析：10,000 对近乎相同初始查询的会话（相似度 >0.99），控制任务类型，对比 Search vs Computer 的完成效果
- O*NET/SOC 职业分类框架：量化分析任务认知复杂度、跨职业边界程度、所需知识域数量

**关键图/公式**：固定/边际成本转换模型图——Search 低固定成本但高边际成本，导致只有低步数任务被执行；Computer 高固定成本但极低边际成本，扩大了"可负担任务边界"，使以前不值得做的复杂任务变得可行；这是理解为什么 Computer 用户做更复杂任务的核心机制。

**实验设置**：
- 规模/数据：Perplexity 真实用户数据 2026.02-05（5,000 双产品用户，10,000 匹配会话对），O*NET 职业分类框架，25 用户深度访谈（6 企业+19 消费者）
- 对比：Search（33 秒/会话）vs Computer（26 分钟/会话），以及匹配任务中完成时间（269分钟 vs 36分钟）

**最强证据**：23% 的 Computer 任务是用户从未在 Search 中尝试过的新任务类型——这直接否定了"AI Agent 只是替代已有任务"的叙事，证明 Agent 主要在"解锁新工作"而非"取代旧工作"；且这来自真实产品数据，不是实验室构造。

**最弱证据**：Perplexity 用户群体可能本身偏向技术早期采用者（不代表普通知识工作者）；87% 时间节省来自"匹配任务"（即两个产品都能做的任务），但 Computer 的真实优势可能主要来自"新解锁任务"，而这类任务没有 Search 对比基准；访谈只有 25 个用户，定量访谈结果置信度低。

**可复用点**：用"固定委托成本 vs 边际执行成本"框架设计 Agent 产品的用户教育策略——帮助用户理解"委托前的设置成本"是一次性的，之后每个步骤的成本趋近于零，从而引导用户提出更复杂、更高价值的任务而不是简单查询。
