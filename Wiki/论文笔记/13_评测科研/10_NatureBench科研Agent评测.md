## NatureGym Pipeline（Benchmark 构建方式）

```
Nature 系列论文（约5500篇，2022-2025）
    ↓ 三阶段筛选
Paper Filtering（可提取性、可自动评估性、数据完整性）
    ↓
Dataset Acquisition（获取数据集，隐藏测试集）
    ↓
Task Package Construction（信息防火墙：隐藏原论文方法）
    ↓
容器化 Task Package：
    ├── README（任务说明）
    ├── data/（输入数据）
    ├── evaluator.py（自动评估脚本）
    └── ground_truth/（隐藏，Agent 不可见）
```

关键设计：**信息防火墙** — Agent 只能看到数据集 + 任务说明，不能看到论文的解法，必须自己发现方法。

## 主要实验结果

### 各 Agent 超越 SOTA 的比例（g > 0.1 标准）

| Agent | 超越 SOTA % | 每任务成本 |
|-------|-----------|---------|
| Claude Opus 4.7 | **17.8%** | $21.65 |
| Gemini 3.5 Flash | 15.6% | $4.49 |
| GPT-5.5 | 14.4% | $6.01 |
| Claude Opus 4.6 | 12.2% | $16.56 |
| Qwen 3.7 Max | 10.0% | ~$10.19 |
| Kimi K2.6 | 8.9% | ~$12.99 |
| GPT-5.4 | 8.9% | $4.14 |
| GLM-5.1 | 7.8% | ~$4.12 |
| DeepSeek-V4-Pro | 4.4% | **$0.15** |
| MiniMax-M2.7 | 1.1% | $1.35 |

**最强结论：当前 AI 只能在 ~18% 真实科研任务上达到或超过发表 SOTA**

## Agent 成功与失败模式

### 成功路径：方法论翻译，非真正发明

```
Agent 成功的主要方式：
"这个科研任务 → 我知道的监督学习问题"
把 Nature 论文的专业方法转化为标准 ML 训练循环

例：反应产物预测任务
  论文方法：基于反应中心的模板方法（达到 0.908 Top-1 精度）
  Agent 方法：Seq2Seq Transformer 模型（达到 0.585，低于 SOTA）
  → Agent 没有发明新方法，只是用熟悉的工具近似
```

### 失败原因分布

| 失败类型 | 比例 | 说明 |
|---------|------|------|
| **方法选择错误** | 主要 | 选了不适合这个问题的 ML 方法 |
| **计算预算不足** | 次要 | 找到了正确方向但时间/算力不够 |
| 任务理解错误 | 较少 | 误解任务目标 |

**关键发现**：不是"理解不了任务"，而是"知道该做什么但做不到"（方法选择 + 执行深度）。

## 核心结论（带时间锚）

1. **当前最强 Agent 只有 17.8% 的科研任务超越 SOTA** 📅 2026.06
   这是当前最严格的 AI-for-Science 评测。17.8% 不是小数字（考虑到任务难度），但也远不是"AI 可以做科研"的水平。

2. **AI 靠"翻译"而非"发明"** 📅 2026.06
   成功的 Agent 把科研任务转化为熟悉的 ML 任务，而非真正理解问题并提出新的科学方法。这区分了"知识复用"和"知识创造"。

3. **失败不在理解，在执行深度** 📅 2026.06
   大多数失败是因为计算预算有限或方法选择次优，而不是任务不理解。这意味着：给 Agent 更多 compute + 更好的方法库，成功率可能显著提升。

4. **成本差异悬殊**：DeepSeek $0.15/任务 vs. Claude Opus 4.7 $21.65/任务，性能差距约 4x，价格差距 144x。

## 对 AI-for-Science 产品的启示

| 产品场景 | 洞察 |
|---------|------|
| 科研加速工具 | 最适合辅助，而非完全替代科研人员；17.8% 成功率意味着大多数任务仍需专家参与 |
| 方法推荐系统 | AI 擅长"从已知方法库中选适合方法"，适合做方法推荐，不适合创造全新方法 |
| 垂直科研平台 | 重要的是解决"方法选择"和"计算预算"两个失败原因，可以大幅提升成功率 |
| AI 科学家产品宣传 | 不要声称"AI 能独立做科研"；更诚实的定位是"AI 能覆盖 10-20% 的科研任务" |

## 论文精读卡片

**一句话**：90 个 Nature 系列真实科研任务的严格评测显示，当前最强 AI Agent（Claude Opus 4.7）只在 17.8% 任务上超越发表 SOTA，且主要靠"把科研翻译成监督学习"而非真正科学发明；成本差异悬殊（$0.15 vs $21.65/任务，性能差约 4x，价格差 144x）。

**问题**：业界对"AI 科学家"的能力缺乏客观标准——现有 AI 编程 Benchmark（HumanEval/SWE-bench）与真实科研任务的差距巨大（真实科研需要选择正确方法 + 理解领域知识 + 超越已知最优）。需要一个同时满足"真实科研任务、信息防火墙、自动评估"的 Benchmark。

**核心方法**：
- NatureGym Pipeline：从 5500 篇 Nature 系列论文（2022-2025）经三阶段筛选（可提取性/可自动评估性/数据完整性）提炼 90 个任务
- 信息防火墙：Agent 只能看到数据集 + 任务说明，不能看到原论文的解法，必须自行发现方法
- 容器化 Task Package：README + data/ + evaluator.py + 隐藏 ground_truth/，evaluator.py 输出标准化数值分数

**关键图/公式**：超越 SOTA 标准 g > 0.1（即至少超出 10% 的相对提升）的设计核心洞察：过窄的标准（g > 0）会计入随机波动，过宽的标准（g > 0.5）没有实际意义。10% 的阈值对应"真实科研领域可发表的改进幅度"。

**实验设置**：
- 规模/数据：90 个任务，6 个领域（细胞组学 31/蛋白质 16/生物医学 14/物理建模 13/分子设计 11/关系推理 5）
- 对比：10 个主流 AI Agent（Claude Opus 4.7/4.6、Gemini 3.5 Flash、GPT-5.5/5.4、Qwen 3.7 Max、Kimi K2.6、GLM-5.1、DeepSeek-V4-Pro、MiniMax-M2.7）

**最强证据**：DeepSeek-V4-Pro 以 $0.15/任务 达到 4.4%，Claude Opus 4.7 以 $21.65/任务 达到 17.8%——价格差 144x 换来性能差 4x，直接证明当前 AI 科研能力的边际收益递减，且成本效率差异极大。这对资源配置决策有直接指导。

**最弱证据**：90 个任务中细胞组学占 34%，领域分布不均衡，结论对物理/化学领域的代表性不足；"信息防火墙"依赖于论文方法未被训练数据包含，但前沿模型的训练截止与 Nature 论文发表的时间差可能导致信息泄露；g > 0.1 阈值的合理性未经消融。

**可复用点**：NatureGym 的 Task Package 设计模式（README + data + evaluator.py + hidden GT）可以直接用于构建内部垂直业务的 AI 能力评测——将"能否超过当前最优业务方案"作为 Agent 的评测标准，而非通用 Benchmark 分数。
