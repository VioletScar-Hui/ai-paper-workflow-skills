# Agents' Last Exam（ALE）：AI Agent 的专业任务终极考试

📄 **原文 PDF**：[[RAW/23 - Agents' Last Exam.pdf]]

## PM 速判（3 分钟）

> **这篇论文给 PM 的一句话**：现有基准（MATH、SWE-bench）成绩与 GDP 贡献没有相关性——ALE 用 250+ 行业专家开发 1000+ 个需要专业人员数天到数周才能完成的真实任务，测量 AI Agent 的实际经济价值；结果严峻：**最强配置（Codex+GPT-5.5）在最难层级的通过率也低于 10%，多数主流 Agent（含 Claude Code）接近零**。

| 项目 | 评估 |
|------|------|
| **任务规模** | 1,490 任务（公开 150 + 私有 1,017），持续增长 |
| **行业覆盖** | 13 个行业集群，55 个细分领域（工程/医疗/金融/生命科学等）|
| **评测对象** | Generalist Computer-Use Agent（GCUA，如 Claude Code / Codex）|
| **当前 SOTA** | Codex/GPT-5.5：最难层级 <10%，平均 Full Pass Rate <1% |
| **成熟度** | 🔬 能力评测，"Living benchmark"持续扩展 |

## 基准设计要点

```
什么样的任务进入 ALE：
  ✓ 代表性：真实专业实践使用的实际软件（SolidWorks/Rhino，非 AutoCAD）
  ✓ 复杂度：单一 Agent 无法在 10 分钟内完成；需要多步推理/工具使用/规划
  ✓ 可验证：结构化交付物检查（无需人类评判）
  ✓ 经济价值：有实际商业意义的任务（不是学术习题）

与其他基准的定位差异：
  MATH/IMO → 数学推理（已接近饱和）
  SWE-bench → 软件工程（代码层面）
  OSWorld → GUI 操作
  Terminal-Bench → 终端命令
  ALE → 真实专业工作流（综合以上所有能力）

任务来源：
  外部提交（960 变体）：行业专家上传过去数天/数周的真实项目
  委托构建（530 变体）：内部专家编写
  五关审核：专家提交 → 初审 → 工程实现 → 质量控制 → 公开/私有
```

## 核心结论（带时间锚）

1. **2026 年中，AI Agent 在真实 GDP 价值任务上几乎无法工作** 📅 2026
   即使最强 Agent 在最容易层级 <50%，最难层级 <10%——这与基准测试的"AI 已经超越专家"叙事形成鲜明反差。

2. **基准饱和≠经济价值：需要区分"AI 能做到的"和"GDP 相关的"** 📅 2026
   MATH/SWE-bench 成绩高 ≠ 专业工作自动化；ALE 的存在是为了找到这个真实的差距。

3. **ALE 是持续测量仪器，不是静态快照** 📅 2026
   作为"Living benchmark"，随着 AI Agent 能力演进，ALE 会持续增加新的行业任务，使其不被饱和。

## 论文精读卡片

**一句话**：ALE（Agents' Last Exam）用 250+ 行业专家设计 1,490 个需要专业人员数天到数周的真实任务，测量 AI Agent 的实际经济价值——2026 年中结果：最强配置 Codex+GPT-5.5 在最难层级通过率 <10%，多数主流 Agent（含 Claude Code）接近零，学术基准高分与专业工作能力严重脱节。

**问题**：现有 AI 基准（MATH/SWE-bench/OSWorld）成绩与实际 GDP 贡献没有相关性——AI 已能解数学竞赛题，但在需要多步专业判断的真实任务上几乎无法工作；缺乏一个真实测量"AI 能否接管人类专业工作"的基准。

**核心方法**：
- 任务设计四标准：真实专业软件使用（SolidWorks/Rhino，非简化工具）、复杂度（Agent 10 分钟内无法完成）、可验证性（结构化交付物自动检查）、经济价值（有实际商业意义）
- 双轨任务来源：行业专家上传历史真实项目（960 变体）+ 内部专家编写（530 变体），五关审核流程保证质量
- Living benchmark：持续由行业专家添加新任务，使基准不被快速饱和

**关键图/公式**：行业热力图——13 个行业集群 × 55 个细分领域的 Agent 通过率分布；核心洞察是"哪些领域 AI 最接近可用"可以从热力图直接读出，这是选择 AI 落地场景的决策工具。

**实验设置**：
- 规模/数据：1,490 任务（公开 150 + 私有 1,017 + 持续增加），13 行业集群，55 细分领域
- 对比：Codex/GPT-5.5、Claude Code/Sonnet 4.6、多数主流 Agent 配置，以及 Terminal-Bench-2.0（参照上限：Codex 达 82%，ALE 远比 TBench 难）

**最强证据**：Terminal-Bench-2.0 上 Codex 达 82%，但在 ALE 最难层级 <10%——同一模型在合成基准和真实专业任务上的巨大差距，直接证明了"基准饱和≠经济价值"的核心论点，数据说服力极强。

**最弱证据**：公开任务只有 150 个（私有 1,017 个），公开结果可能受到任务选择偏差影响；任务"可验证性"要求可能导致偏向有结构化输出的工程类任务，排除了大量软技能类专业工作（管理决策/创意写作）；五关审核流程没有报告审核通过率和失败原因分析。

**可复用点**：用 ALE 的行业热力图做 AI Agent 产品落地场景选择——相对高分领域（如代码工程类）是当前可立即部署的区域，低分领域（医疗/法律复杂判断）是近期产品应定位"辅助而非替代"的区域；这比"AI 已超越专家"的泛泛叙事更有操作价值。
