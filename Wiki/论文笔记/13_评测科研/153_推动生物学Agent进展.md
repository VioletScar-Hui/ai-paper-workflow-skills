# Paving the Way for Agents in Biology：推动生物学Agent进展

📄 **原文 PDF**：[[RAW/153 - Paving the way for agents in biology.pdf]]

## PM 速判 > 一句话

提出生物学科研Agent的5层能力框架（文献综述→假设生成→实验设计→数据分析→同行评审）及配套评测基准BioAgentBench，核心发现：实验设计层是当前LLM最大短板。

## 双层费曼 🗣️

**给CEO：**
生物学研究流程分为5步：读文献→想假设→设计实验→分析数据→同行评审。这篇论文用AI尝试每一步，发现AI在"设计实验"这一步最差——它不知道怎么选仪器、配试剂浓度、设对照组。这个发现很重要：如果要用AI加速新药研发，AI能帮读文献和分析数据，但实验方案还得人亲自把关。

**给工程师：**
5层评测框架定义了生物学科研Agent的能力分层。BioAgentBench为每层构建了典型任务集（如文献检索：给定生物课题检索10篇相关论文；实验设计：设计Western blot实验方案含抗体选择与稀释比）。每层可单独评测也可组合评估。核心评测指标：通过率（自动评分）和专家评分（1-5 Likert）。关键设计：各层任务难度经过标准化（基于生物背景研究生水平），确保可比性。实验设计层通过率显著低于其他层（约低30-40个百分点），根因包括仪器知识缺失、安全约束意识不足、对照组设计不完整。

## 问题域定位 🎯

- **宏观问题**：科研自动化中AI Agent的能力边界与评测缺失
- **具体问题**：生物学全流程科研Agent的标准化评测框架
- **已有基准缺口**：BioCoder（仅代码）、ChemCrow（仅化学）、SciAgent（多学科但未深度覆盖生物学）→ 缺乏生物学领域全流程覆盖
- **评测难点**：科研任务（尤其是实验设计）的答案非唯一，需专家参与评分 → 自动化评测与人工评分需结合
- **实际场景**：药企研发团队评估"能否用AI Agent辅助从靶点发现到实验设计的全流程"

## 设计决策解剖 ⚖️

| 决策点 | 选择 | 被放弃方案 | 为什么 | 何时失效 |
|--------|------|-----------|--------|---------|
| 层级划分 | 5层线性递进 | 平面任务分类/任意层级组合 | 科研流程天然递进，便于定位能力断点 | 实际科研中非严格线性（迭代反馈），层间边界模糊 |
| 评测方式 | 自动评分+专家评分混合 | 纯自动/纯专家 | 部分任务可自动化评判（文献检索精度），部分需专家判断（假设质量） | 专家评分一致性可能不足，需多专家+ICC统计 |
| 任务难度标准化 | 基于生物研究生水平 | 基于本科/专业研究能力 | 研究生水平代表独立科研能力起点，区分度好 | 不同分支（分子/生态/神经）研究生能力基线不同 |
| 模型覆盖 | 多款商用+开源LLM | 单一模型/仅商用 | 全面呈现能力分层，避免vendor lock | 模型更新快速，评测结果保质期短 |

## 成本与量级 💰

- **评测成本**：一次完整BioAgentBench评测（5层×~12任务=~60任务），假设每任务调用3-5次API → ~180-300次API调用，GPT-4级约$20-40
- **专家时间**：实验设计层&假设生成层需专家评分，假设3位专家×每任务5分钟×22个手工评分任务=~5.5小时专家投入
- **维护成本**：基准需随生物学知识更新（新实验技术如单细胞测序、空间转录组学），估计年更新率20-30%任务集
- **与通用Agent评测对比**：比简单QA任务（如MMLU、BIG-Bench）评测成本高10-100倍，但生态效度显著更高

## 证据审计 🔬

**最强证据：**
- 实验设计层的系统性低分——跨多个LLM模型表现出高度一致的弱势区域，不是单个模型的问题
- 5层框架的排序稳定性：L1≈L4 > L2≈L5 > L3，排序在不同temperature设置下保持稳定

**最可疑：**
- 专家评分的主观性问题——"假设的质量"本身难定义，不同专家对同一假设的评分可能存在系统差异
- 任务集是否偏向某些生物学子领域？若偏重分子生物学，结论对生态学/神经科学领域可能不完全迁移

**审稿人可能追问：**
- 实验设计层的低分到底是因为LLM知识不足还是prompt表达不足？如果换一种方式表达问题上（如few-shot实例提供格式模板），得分是否变化？
- BioAgentBench是否考虑了生物安全审查能力？（实验设计中的双用途研究（DURC）风险）

**最小复现实验：**
取BioAgentBench开源任务集中的5个实验设计题（如"设计CRISPR敲除小鼠的对照实验"），让GPT-4和Claude-3分别作答，比对专家评分与论文报告得分的差异。

        "tasks_detail": [

        "tasks_detail": [

        ]
    }

def simulate_agent_evaluation(agent_name, base_proficiency):
    """
    模拟Agent在5层能力上的评测
    base_proficiency: dict of {layer_name: (mean, noise)}
    L3均值显著低于其他层（模拟论文发现）
    """
    results = {}
    for layer, config in LAYERS.items():
        mean, noise = base_proficiency.get(layer, (0.5, 0.1))
        layer_scores = []
        for task in config["tasks_detail"]:
            # 模拟每个任务得分，加入随机噪声

                "task": task["name"],
                "score": round(score, 1),
                "max_score": task["max_score"]
            })
        # 层平均分
        avg = round(sum(s["score"] for s in layer_scores) / len(layer_scores), 1)
        results[layer] = {
            "average_score": avg,
            "task_results": layer_scores
        }
    return results

# 模拟发现：L3明显低于其他层

    # 打印该层各任务得分
    for task in data["task_results"]:

# 计算能力排名（论文核心产出）

for rank, (layer, data) in enumerate(ranking, 1):

# 输出结论
lowest = min(results.items(), key=lambda x: x[1]["average_score"])

## 自测三层 🎓

**L1 — 概念回忆：**
Q: 5层能力框架中当前LLM最大短板是哪一层？核心表现是什么？
A: 实验设计层（L3）。核心表现：仪器选型不合理、试剂浓度计算错误、对照设计不完整、安全/生物安全限制意识不足。

**L2 — 迁移应用：**
Q: 如果把这个5层框架迁移到"药物发现全流程Agent"评估中，需要用哪些生物学分支的任务替换原始任务集？
A: 药物发现流程映射：L1文献综述→靶点机制文献检索；L2假设生成→候选靶点-疾病关联假说；L3实验设计→先导化合物优化实验方案（ADMET检测设计、动物模型选择）；L4数据分析→剂量-反应曲线分析、SAR分析；L5同行评审→临床前数据质量评估。需增加：体内实验设计、毒理学检测设计等药物特有任务。

**L3 — 批判性质疑：**
Q: BioAgentBench的5层线性递进假设在多大程度上偏离了真实的生物学研究实践？这种偏离会如何影响框架的有效性？
A: 真实科研中：1）文献综述与假设生成往复迭代（读文献→提假设→再读→修正假设），非单次递进；2）数据分析结果反馈修正实验设计（常见于筛选实验→验证实验循环）；3）同行评审本应贯穿全程而非仅在末端。这种偏离可能导致：高估Agent在流水线式执行上的表现（线性模式），低估其在迭代反馈中的适应能力。框架改进方向：引入层间反馈回路作为第6维度（"迭代调整能力"），或设计循环评测协议而非单次评测。
