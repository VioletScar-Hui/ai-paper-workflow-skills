# PAPO：扩散语言模型推理的过程对齐 RL

📄 **原文 PDF**：[[RAW/17 - Back on Track - Aligning Rewards and States for Reasoning in Diffusion Large Language Models.pdf]]

## PM 速判（1 分钟）

> **这篇论文给 PM 的一句话**：扩散 LLM（并行去噪生成而非逐词生成）中的 RL 训练存在两类对齐问题，PAPO 通过"每步奖励 + 熵引导历史重演"修复——规划任务上比现有方案提升 42.2%；但对 PM 的直接影响有限，这是基础 ML 研究。

| 项目 | 评估 |
|------|------|
| **对象** | 扩散 LLM（dLLM，如 LLaDA——并行去噪生成文本） |
| **问题** | 将 RL 适配到非自回归生成结构的两类对齐失败 |
| **方案** | PAPO = SPR（步骤感知过程奖励）+ EHR（熵引导历史重演） |
| **效果** | Countdown +42.2%, Sudoku +16.1%（vs 先前 dLLM RL 基线） |
| **成熟度** | 🧪 实验阶段，dLLM 本身仍在早期发展 |

---

## 核心结论（带时间锚）

1. **扩散 LLM + RL 可以大幅提升推理能力，但需解决步骤奖励对齐问题** 📅 2026
   标准 GRPO 直接应用于 dLLM 效果受限；PAPO 在规划任务上的提升幅度（40%+）表明过程奖励对非自回归架构尤为关键。

2. **扩散 LLM 的 RL 训练需要真实轨迹而非人工构建状态** 📅 2026
   现有 dLLM RL 方法使用随机掩码的"人工状态"——这在真实推理中从不出现，导致梯度浪费；PAPO 用历史轨迹中的真实状态做更新。

## 论文精读卡片

**一句话**：扩散 LLM（并行去噪生成）的 RL 训练存在"步骤奖励对齐"和"伪历史状态"两类失败，PAPO 通过步骤感知过程奖励（SPR）+ 熵引导历史重演（EHR）修复，在规划任务 Countdown 上比先前 dLLM RL 基线提升 +42.2%，Sudoku 提升 +16.1%。

**问题**：扩散 LLM（如 LLaDA）并行去噪生成文本，无法直接套用为自回归 LLM 设计的 RLVR/GRPO——原因有二：每步去噪无独立奖励信号导致奖励稀疏，以及现有方法使用随机掩码的"人工状态"（真实推理中从不出现）导致梯度浪费。

**核心方法**：
- SPR（步骤感知过程奖励）：在扩散的每个去噪时间步计算独立奖励信号，而非只用最终结果奖励，解决奖励稀疏问题
- EHR（熵引导历史重演）：从历史生成轨迹中选择高熵（高不确定性）的真实状态做 RL 更新，替代随机掩码人工状态，确保梯度对应真实推理场景

**关键图/公式**：dLLM RL 对比图——左侧标准 GRPO 只有终态奖励且用随机掩码状态；右侧 PAPO 在每步去噪有 SPR 信号，用历史真实状态做 EHR 更新；关键洞察是扩散生成的时序结构决定了 RL 信号必须跟步骤对齐。

**实验设置**：
- 规模/数据：Countdown（数字推理规划）、Sudoku（约束满足推理）；骨干模型 LLaDA 和 Dream
- 对比：先前 dLLM RL 基线（RLVR 直接适配）、标准 GRPO 适配版本

**最强证据**：Countdown 任务 +42.2% 的提升幅度，远超标准 GRPO 适配；两个独立任务和两个骨干 dLLM 上都验证，说明 PAPO 不是针对单一数据集的过拟合。

**最弱证据**：实验仅在结构化推理任务（规划/数独）上测试，这类任务的步骤边界清晰，SPR 比较容易实现；对于开放式生成任务（创作/对话），步骤奖励如何定义完全未涉及。dLLM 本身在 2026 年仍是边缘架构，应用场景很窄。

**可复用点**：对任何非自回归生成模型做 RL 时，核心原则是"用真实推理状态训练，不用人工构造状态"——这个原则可以推广到其他非标准生成架构（如 masked LM、energy-based model）的 RL 适配。
