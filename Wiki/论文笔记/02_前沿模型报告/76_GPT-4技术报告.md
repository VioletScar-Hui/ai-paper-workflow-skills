# GPT-4 技术报告

📄 **原文 PDF**：[[RAW/76 - GPT-4 Technical Report.pdf]]

## PM 速判
> 当前整个 AI 产品时代的起点。GPT-4 律师资格考试前 10%、MMLU 86.4%、多模态视觉输入——但报告刻意隐藏了参数量、架构和训练数据，是史上最"不透明"的技术报告。真正可复用的遗产是"可预测扩展"（predictable scaling）方法论——用小模型 loss 外推大模型性能，避免百亿美金级训练翻车。

## 双层费曼 🗣️
> **给CEO**：OpenAI 在 2023 年发布 GPT-4 时做了一个聪明的决定——不公开模型的具体大小和训练方法，但公开了"怎么预测模型还没训练好之前的表现"。这套预测方法的价值在于：当你准备花几千万美金训练一个大模型时，先用小模型跑一遍，就能比较准确地估算最终效果——像盖楼前先做结构模拟，避免盖到一半发现承重不够。GPT-4 在专业考试上超过 90% 的人类考生，但报告里没说的是：这些考试题很可能在训练数据里出现过。
> **给工程师**：GPT-4 技术报告的核心技术贡献（非产品贡献）是 predictable scaling 方法论：在计算量 C 下，final loss L(C) 可用小规模实验外推。具体做法是训练多个小模型（不同参数量和 token 数组合），对每个组合拟合 power law L(C) = a·C^{-b} + L_∞，然后用此定律预测 GPT-4 规模下的 loss。除 scaling 外，报告还描述了多阶段 RLHF 流程（SFT → RM → PPO）和可预测的风险评估（通过小模型预测大模型在有害问题上的行为）。报告明确拒绝公开参数量、训练数据组成、MoE 架构信息，引用了竞争格局和安全考量——这是"技术报告"而非"学术论文"。

## 问题域定位 🎯
- **回应什么根本约束？** 训练 GPT-4 级别模型的核心风险不是"能不能训出来"，而是"训出来之前不知道行不行"——数十亿美金的训练预算让 trial-and-error 不可接受。同时也回应了"强大的模型是否可控"的安全焦虑：需要证明即使在最大规模下，对齐技术（RLHF）仍然有效且可预测。
- **之前卡在哪？** GPT-3 证明了 scaling 有效，但没有系统性的方法论来"预测 scaling 的效果"——每家大厂都在赌。安全方面，RLHF 在小模型上已验证，但没人知道在 GPT-4 级别规模下是否仍然有效、是否会出现 emergent misalignment。
- **开启/关闭了哪条路线？** **开启了**：predictable scaling 作为大模型训练的标准化风险管理工具（后续 Gemini、Claude 3 均延续此方法论）。**明确关闭了**：技术透明作为前沿模型报告的规范——GPT-4 报告开创了"不公开核心技术细节"的先例，引发行业关于安全与透明平衡的持续争论。

## 设计决策解剖 ⚖️

| 决策点 | 选择 | 被放弃方案 | 为什么 | 何时失效 |
|--------|------|-----------|--------|---------|
| 技术透明度 | 不公开参数量/架构/训练数据 | 像 GPT-3 论文一样公开所有技术细节 | 竞争格局（不想给对手提供路线图）+ 安全考量（防止滥用者针对性攻击）。OpenAI 从"研究实验室"转型为"产品公司"的战略信号 | 当监管要求（如 EU AI Act）强制公开时，此策略被迫改变；同时阻碍独立安全审计，长期可能损害信任 |
| 多模态集成策略 | 文本+图像多模态，视觉编码器整合进 decoder | 纯文本（如 GPT-3）、或文本+图像+音频全能（如 Gemini） | 视觉是最迫切的多模态需求（文档分析、图表理解），音频和视频的需求优先级较低且更难 | 当用户期望原生视频理解时（如分析监控录像），需重新设计多模态架构 |
| Scaling Law 方法论 | 用 isoFLOP 曲线拟合 power law，从 ~10^18 外推到 ~10^25 FLOPs（约 7 个数量级外推） | 直接训练最大模型并观察（"trust fall"策略） | 单个 GPT-4 训练成本数千万至数亿美元，外推是风险管理的必需品 | 当 scaling law 的 functional form 在更大规模改变时（如出现 phase transition），外推失效；目前尚无此证据 |
| 对齐流程 | SFT → RM → PPO 三步（标准 RLHF） | SFT 后直接用 DPO（跳过显式 RM 训练）、或 Constitutional AI without RL | PPO 在当时是 OpenAI 最成熟的对齐管线；RL-based 方法在 GPT-3.5 上已验证有效 | 当 DPO 在更大规模上被证明等价或更优时（Anthropic 后续工作已挑战 RLHF 的必要性） |
| 安全评估策略 | 内部红队 + 可预测的风险外推（小模型上的有害行为预测大模型） | 独立第三方安全审计（如 METR/ARC 评估） | 保护未发布模型的商业机密；内部团队对模型理解更深 | 当公众对自我评估的可信度质疑加剧时——"自己评自己"的利益冲突无法避免 |

## 成本与量级 💰
- **训练成本**：普遍估计 GPT-4 训练成本约 $63M-$100M+（含多次失败训练和消融实验），使用 ~25,000 A100 GPU 训练约 90-100 天。这包括预训练 + SFT + RM 训练 + PPO RL 四阶段。实际的"一次成功训练"成本可能更低，但探索性失败将总预算推高。
- **推理成本**：GPT-4 推理成本显著高于 GPT-3.5（估计 10-20x），报告未公开原因是 MoE 架构的可能使用——即使总参数量大，每次推理可能仅激活部分专家。按 API 定价反推：每 1M input tokens 约 $30（2023 定价）。
- **最小可行配置**：从 scaling law 外推角度，最小复现是：用 LLaMA-7B 系列在不同 FLOPs 训练多个 checkpoint → 拟合 power law → 外推到 10x 计算量并与实际训练的 LLaMA-13B 对比验证——约 4×A100 一周可完成验证实验。
- **环境成本**：~25,000 GPU 运行 3 个月，按每个 A100 400W 计算，总电力约 7,200 MWh（相当于 ~650 个美国家庭一年用电），碳排放估计约 3,000-4,000 吨 CO2e（取决于电网碳强度）。

## 证据审计 🔬
- **实验公平性**：GPT-4 在 MMLU 等基准上与 GPT-3.5 的对比是有效的（同公司、同训练框架、不同规模），但与 Claude、PaLM 的对比存在不公平——这些模型使用了不同的训练数据和评估策略。特别地，OpenAI 在 GPT-4 报告中首次使用了"用 GPT-4 生成评估准则"的内部评估方法，这可能对 GPT-4 自身有利。
- **最强证据**：MMLU 86.4%（GPT-4）vs 70.0%（GPT-3.5），提升 16.4 个百分点——这是最大的跨版本跳跃；Bar Exam 前 10% 分位数——将语言模型从"通过考试"提升到"超越大多数人类考生"的叙事转折点；predictable scaling 外推与实际训练结果的高度吻合——这是报告中唯一有方法论深度且可复用的贡献。
- **最可疑数字及原因**：(1) 所有专业考试成绩——训练数据中极可能包含考题或高度相似的练习题，这不是"推理能力"而是"记忆检索"的混合。OpenAI 尝试用 withheld test sets 排除数据污染，但方法细节不足。(2) 与人类评估者的对比——"超越人类专家"的说法忽略了 speed 和 consistency 维度：人类考试有时间压力和疲劳，GPT-4 没有。(3) 安全评估的数字——由 OpenAI 内部红队生成，无独立验证，可能存在 selective reporting 的幸存者偏差。
- **审稿补充实验**: (1) 公开 scaling law 原始数据点和拟合曲线供独立复现；(2) 在严格确认无污染的 withheld 考试题上重新测试；(3) 独立第三方安全审计的对比数据（而非仅内部评估）；(4) 消融实验：去除 SFT 数据中可能的 benchmark 污染后性能下降量。
- **最小复现设计**：由于 GPT-4 本身不可复现，最小设计聚焦 scaling law 验证：用 GPT-2 系列（124M/355M/774M/1.5B）或 LLaMA 系列在不同 FLOPs 下训练并拟合 power law，外推到更大规模并与实际训练结果对比。1 周内可在 4×A100 完成。

## 可复用点
- **何时采用**：predictable scaling 方法论是 GPT-4 报告中唯一可以无保留采用的资产。当你有训练大模型的需求和预算（>$1M），必须在启动前做小规模 scaling law 外推——这是风险管理的必需品而非可选项。多阶段 RLHF 流程（SFT→RM→PPO）是可靠的对齐基线，适用于任何大规模语言模型训练。
- **何时规避**：不要模仿 GPT-4 的技术不透明策略——除非你是市值千亿的公司且面临真实的竞争安全威胁。对于学术界和中小企业，技术透明度是建立信任和促进生态的基础。不要把 GPT-4 的专业考试成绩不当做"推理能力"来向客户承诺——始终考虑数据污染的可能性。
- **供应商拷问清单**：
  1. "你们模型的技术报告中是否公开了 scaling law 的原始数据点？你们的 predictable scaling 方法论用了哪种 functional form（power law / broken power law / Chinchilla 式）？外推了多少个数量级？"
  2. "你们的安全评估是否由独立第三方（如 METR、ARC）进行过审计？在 withheld test sets 上的污染检测方法是什么？"

## 动手练习 💻
**练习目标**：用小模型在不同 FLOPs 下的 loss 数据拟合 scaling law（power law），外推大模型性能，理解 GPT-4 报告中 predictable scaling 的核心方法。

```python
"""
Scaling Law 拟合：用小模型 loss 外推大模型性能
方法：对多组 (FLOPs, loss) 数据拟合 L(C) = a * C^{-b} + L_inf
运行: python scaling_law_fit.py
"""

import numpy as np
from scipy.optimize import curve_fit
import matplotlib.pyplot as plt

# ====== 模拟数据：不同规模模型的训练 loss ======
# 格式: (训练总 FLOPs, 最终 loss)
# 模拟 GPT-2 系列 checkpoint：124M → 355M → 774M → 1.5B
np.random.seed(42)
data = np.array([
    [1.0e17,  3.20],   # ~GPT-2 Small (124M)
    [3.5e17,  2.85],   # ~GPT-2 Medium (355M)
    [8.5e17,  2.55],   # ~GPT-2 Large (774M)
    [1.9e18,  2.35],   # ~GPT-2 XL (1.5B)
    [4.5e18,  2.10],   # 虚构的中间规模点
    [1.0e19,  1.95],   # ~LLaMA-7B 级别
])
# 添加少量噪声模拟真实测量误差
data[:, 1] += np.random.normal(0, 0.03, len(data))

C_obs = data[:, 0]   # 计算量 FLOPs
L_obs = data[:, 1]   # 观测 loss

# ====== Power Law 模型：L(C) = a * C^{-b} + L_inf ======
def scaling_law(C, a, b, L_inf):
    """
    C: 计算量 (FLOPs)
    a: 可约误差的系数（越大表示初始 loss 越高）
    b: 衰减指数（~0.05-0.1，越小衰减越慢）
    L_inf: 不可约 loss（即使无限计算也无法低于此值）
    """
    return a * C**(-b) + L_inf

# ====== 拟合 ======
# 初始猜测: a≈10, b≈0.08, L_inf≈1.5
popt, pcov = curve_fit(scaling_law, C_obs, L_obs,
                       p0=[10.0, 0.08, 1.5],
                       bounds=([0.1, 0.01, 0.5], [100, 0.5, 2.5]))
a_fit, b_fit, L_inf_fit = popt
print(f"拟合结果:")
print(f"  a     = {a_fit:.3f}  (可约误差系数)")
print(f"  b     = {b_fit:.4f}  (衰减指数 — 越小越'难学')")
print(f"  L_inf = {L_inf_fit:.3f} (不可约 loss — 理论下限)")
print(f"  R²    = {1 - np.sum((L_obs - scaling_law(C_obs, *popt))**2) / np.sum((L_obs - np.mean(L_obs))**2):.4f}")

# ====== 外推到更大规模 ======
C_extrapolate = np.logspace(17, 25, 50)  # 10^17 → 10^25 FLOPs
L_extrapolate = scaling_law(C_extrapolate, *popt)

# 关键外推点
extrap_points = {
    "GPT-3 (175B)":      3.1e23,
    "GPT-4 (估计)":      1.0e25,
    "GPT-5 推测 (10x)":  1.0e26,
}
print(f"\n外推预测:")
for name, flops in extrap_points.items():
    pred_loss = scaling_law(flops, *popt)
    # 估计困惑度 PPL ≈ exp(loss)
    pred_ppl = np.exp(pred_loss)
    print(f"  {name:20s}: FLOPs={flops:.1e} → loss={pred_loss:.3f}, PPL≈{pred_ppl:.1f}")

# ====== 可视化 ======
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

# 左图: 对数坐标下的拟合曲线
ax1.loglog(C_obs, L_obs, 'bo', markersize=8, label='Observed (small models)')
ax1.loglog(C_extrapolate, L_extrapolate, 'r-', linewidth=2,
           label=f'Fit: L(C)={a_fit:.2f}*C^(-{b_fit:.4f})+{L_inf_fit:.3f}')
ax1.axhline(y=L_inf_fit, color='gray', linestyle='--', alpha=0.5,
            label=f'L_inf = {L_inf_fit:.3f} (irreducible)')
for name, flops in extrap_points.items():
    pred = scaling_law(flops, *popt)
    ax1.plot(flops, pred, 'g^', markersize=10)
    ax1.annotate(name, (flops, pred),
                 textcoords="offset points", xytext=(10, -10),
                 fontsize=8, color='green')
ax1.set_xlabel('Compute (FLOPs)')
ax1.set_ylabel('Loss')
ax1.set_title('Scaling Law Fit (log-log)')
ax1.legend(fontsize=8)
ax1.grid(True, alpha=0.3)

# 右图: 外推区间的置信带
ax2.semilogx(C_obs, L_obs, 'bo', markersize=8, label='Observed')
# 生成多条拟合曲线（参数采样法估计不确定性）
n_samples = 200
param_samples = np.random.multivariate_normal(popt, pcov, n_samples)
extrap_samples = np.array([scaling_law(C_extrapolate, *p) for p in param_samples])
lower = np.percentile(extrap_samples, 5, axis=0)
upper = np.percentile(extrap_samples, 95, axis=0)
ax2.semilogx(C_extrapolate, L_extrapolate, 'r-', linewidth=2, label='Best fit')
ax2.fill_between(C_extrapolate, lower, upper, alpha=0.3, color='red',
                 label='90% CI (parametric bootstrap)')
ax2.set_xlabel('Compute (FLOPs)')
ax2.set_ylabel('Loss')
ax2.set_title('Extrapolation with Uncertainty')
ax2.legend(fontsize=8)
ax2.grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('scaling_law_fit.png', dpi=150)
print(f"\n图表已保存为 scaling_law_fit.png")
```
