# GLM-TTS：生产级语音合成技术报告

📄 **原文 PDF**：[[RAW/90 - GLM-TTS Technical Report.pdf]]

## PM 速判（30秒）

> **生产可用的高保真 TTS 系统，用 GRPO 多维度 RL 优化发音/音质/韵律。** ZhipuAI 发布 GLM-TTS：文本→Token（AR 模型）+ Token→波形（扩散模型）两阶段架构，仅 10 万小时训练数据即达到多个开源基准 SOTA。引入 GRPO 多奖励 RL 框架同时优化发音准确性、说话人相似度和表现力韵律；LoRA 支持高效音色定制；混合音素-文本输入精确控制发音。

## 核心机制

```
两阶段架构：
  Stage 1（文本→音频 Token）：自回归模型（类 GPT）
    输入：文本序列
    输出：离散语音 Token（通过优化的语音 tokenizer）
    
  Stage 2（音频 Token→波形）：FLOW 扩散模型
    输入：离散语音 Token
    输出：Mel 频谱图 → 波形
    
语音 Tokenizer 优化：
  加入基频（F0）约束 → 更准确捕捉音调/情感
  减少 Token 中基频信息丢失

GRPO 多奖励 RL（联合优化三个维度）：
  奖励 1：发音准确性（CER/WER）
  奖励 2：说话人相似度（声纹比对）
  奖励 3：表现力韵律（MOS-style 评分）
  
生产部署特性：
  ① LoRA 音色定制（参数高效，快速适配新音色）
  ② 混合音素-文本输入（精确控制多音字发音）
  ③ 实时合成（z.ai/audio.ai 在线 Demo）
```

## PM 结论

- 📅 2025 年，TTS 进入 RL 优化时代（类似 LLM 的 RLHF），音质显著提升
- GRPO 多奖励框架是 TTS 的关键进展：单一优化目标无法平衡所有语音质量维度
- 对 PM：10 万小时训练数据 → 多基准 SOTA，数据效率很高；数据成本可控
- LoRA 音色定制是商业化关键：品牌语音、明星音色授权等场景

## 论文精读卡片

**一句话**：GLM-TTS 用 GRPO 多奖励 RL 同时优化发音准确性/说话人相似度/韵律表现力三个维度，仅 10 万小时训练数据就在多基准达到 SOTA，并支持 LoRA 高效音色定制。

**问题**：传统 TTS 系统对多音字/外来词发音不准、克隆音色相似度低、韵律生硬——单一损失函数无法同时优化这三个正交的语音质量维度，如何统一建模？

**核心方法**：
- GRPO 多奖励 RL 框架——同时训练三个奖励信号：① 发音准确性（CER/WER 反向）；② 说话人相似度（声纹 embedding 余弦相似度）；③ 韵律表现力（MOS-style 评分模型）
- 两阶段架构——Stage 1（AR）：文本→离散语音 Token；Stage 2（扩散 FLOW 模型）：Token→波形
- F0 约束 Tokenizer——在语音 tokenizer 中显式加入基频（F0）信息，减少音调/情感在离散化时的损失

**关键图/公式**：GRPO 多维度奖励设计是核心：三个奖励函数 r₁（发音）+ r₂（音色）+ r₃（韵律）的加权组合，类似 RLHF 用多目标替代单一 reward model，解决了 TTS 的"三角约束"问题。

**实验设置**：
- 规模/数据：10 万小时语音训练数据（中英文为主）
- 对比：多个 TTS 开源基准（不含具体竞品数字在笔记中），z.ai/audio.ai 在线 demo 评估

**最强证据**：在文档解析、公式转录、表格结构等任务上达到 SOTA 或竞争水平；10 万小时数据即达到 SOTA（数据效率高）；LoRA 音色定制可快速适配新音色（商业化价值高）。

**最弱证据**：具体 MOS（Mean Opinion Score）数值未在笔记中列出；GRPO 三个奖励的权重调整策略未公开，实际工程可复现性存疑；10 万小时的数据质量标准未详述（高质量录音 vs 网络音频差异很大）。

**可复用点**：GRPO 多奖励框架移植——TTS 的"发音+音色+韵律"三奖励设计，可直接移植到其他多目标生成任务（如多维度图像质量优化：清晰度+色彩准确度+构图合理性）。
