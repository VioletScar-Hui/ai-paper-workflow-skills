# 187 从基础到应用：VLA 模型的实践改进（LingBot-VLA 2.0）

📄 **原文 PDF**：[[RAW/187 - From Foundation to Application - Improving VLA Models in Practice.pdf]]

> arXiv:2607.06403v1 (cs.RO)，2026-07-07。技术报告（非学术论文）。开源：github.com/robbyant/lingbot-vla-v2；权重在 HuggingFace。与 184 号（LingBot-World）同属蚂蚁 Robbyant 灵波团队。

## PM 速判（30秒）

> 一份"把 VLA 基础模型推向真实机器人落地"的工程报告，三条改进主线：① **数据**——重构管线，攒了 60,000 小时预训练数据（50,000 小时机器人轨迹跨 **20 种机器人形态** + 10,000 小时第一人称人类视频）；② **动作空间**——从双臂扩到头/腰/移动底盘/灵巧手的全身自由度，用一个 **55 维统一动作向量**兼容所有形态；③ **时序推理**——把"预测未来"当代理任务，用深度模型给几何线索、视频模型给语义线索双老师蒸馏。在 GM-100 双臂基准和两个长视野移动操作任务上超过 π0.5 和 GR00T N1.7。PM 必须知道：这代表 VLA 的竞争焦点正从"模型架构"转向"数据工程 + 全身控制 + 未来预测"三位一体；但它是技术报告，所有结论无统计显著性检验、每任务仅 10-15 次试验，采购要按"厂商自评"折价看。

## 双层费曼 🗣️

> **给 CEO 的一句话**：这是给机器人装"能看懂场景、能预判下一步、还能同时指挥手脚腰头一起动"的通用大脑第二代——靠喂进 6 万小时、20 种机器人和真人第一视角的操作录像，让同一个模型能开冰箱、擦灶台、分拣零食，换个机器人身体也能用；实测比业界两个主流对手（英伟达 GR00T、Physical Intelligence 的 π0.5）都强一截。

> **给工程师的一段话**：架构是 MoE-based VLA——理解专家（VLM）+ 动作专家，动作专家的 FFN 换成 token 级稀疏 MoE，用 sigmoid 路由 + DeepSeek-V3 式辅助损失无关（auxiliary-loss-free）负载均衡（靠路由修正偏置而非往主目标里塞均衡损失），一个共享专家保通用先验 + 若干路由专家给专精容量。核心创新是 **Dual-Query Distillation**：在视觉/文本 token 后接两个可学习查询 [Q_t, Q_{t+T}]，Q_t 盯当前观测、Q_{t+T} 盯未来 T 步（= action chunk 大小）后的观测；两个查询各从两个老师蒸馏——LingBot-Depth 给几何监督（预测当前/未来深度）、DINO-Video 给因果时序监督（预测当前/未来的运动感知特征）。DINO-Video 是他们基于 DINOv3 加块级因果时间注意力 + 3D-RoPE 自制的机器人感知视频表征模型，在 5M 视频片段上自蒸馏训练。数据侧：55 维规范向量（14 臂关节 + 14 末端执行器位姿 + 2 夹爪 + 12 手关节 + 4 腰 + 2 头 + 3 移动 + 4 保留），缺失部件维度补零；第一人称视频用 egocentric SLAM 估相机内外参 + MANO 手姿态估计，把手轨迹抬到世界坐标系统一存储、训练时再变换回当前相机系（解耦手部运动与相机运动）。标注用 Qwen3.6-27B 自动切子任务 + 18 类闭词表原子动作。

## 问题域定位 🎯

- **根本约束**：VLA 基础模型在实验室 benchmark 和真实部署之间有巨大鸿沟——真实机器人有更多样的形态、更丰富的动作空间、更动态的环境。三个具体缺口：泛化不只是跨任务还要跨异构机器人配置和数据源；真实平台自由度远超标准双臂（头/腰/底盘/灵巧手）；真实执行需要预判场景演化和动作后果而非只对当前观测反应。
- **之前的方案卡在哪里**：各家只攻单点——有的堆机器人数据（跨形态鲁棒），有的做形态感知架构，有的加潜动作模型改进动态决策。没人把数据、形态、预测能力协同处理。VLA-1.0 自身在数据规模、动作空间覆盖、时序理解上都不够。
- **它开启/走的路线**：把"应用可用性"当第一目标（而非刷 benchmark 分），主张实用 VLA 要同时在模型/数据规模 + 全身形态支持 + 动态场景预测三方面对齐真实机器人需求。这是"基础能力→应用可用"的工程化转向。
- **它没解决的**：progress score 高但 success rate 低——模型常做到部分进度却在最后精确放置/释放步失败；跨形态差异（运动学、相机视角、动作空间对齐）仍是硬骨头（同任务 Agilex 平台 66.2 分 vs Galaxea 平台仅 34.6 分）。

## 核心机制（ASCII 图）

```text
LingBot-VLA 2.0 = MoE-VLA 骨架 + Dual-Query 未来预测蒸馏

┌─────────────────── 输入 ───────────────────┐
│ 多视角图像 + 语言指令("把花插进花瓶")        │
│ + 机器人当前状态(55维统一向量)               │
└──────────────────┬─────────────────────────┘
                   ↓
        ┌──────────────────────┐
        │ 理解专家 (VLM)         │  ← 场景理解、grounding
        └──────────┬───────────┘
                   ↓
        ┌──────────────────────┐
        │ 动作专家 (MoE 层)      │  token级稀疏MoE替代FFN:
        │  1 共享专家(通用先验)   │  - sigmoid路由(非softmax,避免专家恶性竞争)
        │  + N 路由专家(top-K)   │  - 辅助损失无关负载均衡(路由修正偏置)
        └──────────┬───────────┘  匹配激活参数下 MoE<Dense 的训练损失&验证误差
                   ↓
          去噪连续动作 → 全身控制(臂/末端/夹爪/腰/头/手/移动)

╔═══ Dual-Query Distillation (关键: 把"预测未来"当代理任务) ═══╗
║  在token序列后附加两个可学习查询:                            ║
║    Q_t     ─盯→ 当前观测                                     ║
║    Q_{t+T} ─盯→ 未来T步观测 (T = action chunk 大小)          ║
║                                                             ║
║  每个查询从两个互补老师蒸馏:                                  ║
║    ┌─ LingBot-Depth (深度老师) → 几何监督(预测当前/未来深度) ║
║    └─ DINO-Video (因果视频老师) → 时序监督(运动感知特征)     ║
║       DINO-Video = DINOv3 + 块级因果时间注意力 + 3D-RoPE     ║
║                    在5M视频片段上自蒸馏                       ║
║  → 让VLA既有几何空间感,又有因果时序预判                       ║
╚═════════════════════════════════════════════════════════════╝

数据管线: 90,000h机器人原始 ─过滤(jerk/Z-score/静止>95%/URDF重投影核对)→ 50,000h
          20,000h第一人称 ─VLM预筛+SLAM+MANO手姿态→ 10,000h  合计60,000h
          Qwen3.6-27B自动标注: 切子任务 + 18类原子动作闭词表
```

## 设计决策解剖 ⚖️

| 决策点 | 他们的选择 | 被放弃的方案 | 为什么 | 这个选择何时失效 |
|--------|----------|------------|--------|---------------|
| 未来监督形式 | Dual-Query 蒸馏（当前+未来双查询，深度+视频双老师） | 直接回归未来 RGB / 只用当前观测 | 预测未来的**表征**（深度+语义特征）比预测像素更省且更抓因果；几何与时序互补 | 老师模型本身有误差会传导；T 固定=chunk 大小，任务时间尺度差异大时未来查询失准 |
| 动作专家扩容 | token 级稀疏 MoE + 辅助损失无关均衡 | 稠密 FFN / token 级 MoE 带辅助均衡损失 | 匹配激活参数下 MoE 训练损失和验证误差都更低（非靠总参数量）；辅助损失无关避免污染动作学习主目标 | 路由偏置调节速度 γ 需调参；专家语义不由单一变量决定，可解释性差；小规模下 MoE 优势可能消失 |
| 跨形态统一 | 55 维规范向量，缺失维度补零 | 每形态单独动作头 | 一个模型吃 20 种形态，补零对齐最简单 | 补零维度占比高的简单形态（单臂 8 维填进 55 维）浪费容量；形态运动学差异大时补零掩盖不了本质不同（Galaxea vs Agilex 差 32 分） |
| 第一人称数据 | SLAM+MANO 抬到世界系存储，训练时变换回相机系 | 直接用相机系手轨迹 | 解耦手部运动与相机运动，统一开源/自采格式 | SLAM 不稳/手姿态估计错误直接污染标签；有效手帧<20% 的片段被丢（召回损失未量化） |
| 动作目标（消融） | 相对关节动作 | 绝对关节动作 | 相对动作标准差仅绝对的 31-37%，把全局位形回归变成局部运动回归，目标更集中低方差；成功率 33.7→55.0 | 长程累积漂移风险（相对动作误差会累加）；需要可靠的当前状态估计做基准 |
| 标注 | Qwen3.6-27B 全自动 + 18 类闭词表 | 人工标注 / 开放词表 | 规模化必需；闭词表保证粒度一致 | VLM 标注错误无人工兜底（与数据过滤时的人工核对不对称）；18 类之外的动作归入 other 丢信息 |

## 成本与量级 💰

- **数据规模**：原始 90,000h 机器人 + 20,000h 第一人称 → 过滤后 50,000h + 10,000h = 60,000h 预训练。机器人数据过滤淘汰率约 44%，第一人称约 50%——数据工程是主要成本项，含大量人工核对（URDF 重投影比对、视频质量标注）。
- **形态覆盖**：20 种机器人形态，DoF 从单臂 8 维到人形 Fourier GR-2 的 32 维，策略频率 15-30Hz（第一人称 30-60Hz）。
- **模型规模**：报告只给了消融用的 Dense 0.6B vs MoE 1.6B-A-0.6B（1.6B 总参 / 0.6B 激活）对比，**正式部署模型的参数量未在正文明确披露**——这是评估推理成本的盲区。
- **工程复杂度**：极高。数据管线（SLAM/MANO/URDF 核对）+ 两个老师模型（LingBot-Depth、自制 DINO-Video）+ MoE 训练 + 20 形态适配，是"数据+模型+机器人硬件+软件"的全栈重工程，作者致谢名单跨蚂蚁数科 Phecda 实验室、Genrobot.ai 等多家。
- **我的产品最小可行配置**：若做单一形态双臂应用，直接微调开源权重；Dual-Query 蒸馏和 55 维统一表示对单形态是过度设计，可裁剪。想复用的是"未来预测当代理任务"这个训练目标思路。

## 证据审计 🔬

- **这是技术报告不是论文**：无统计显著性检验、无误差棒、无消融的方差报告。GM-100 每任务、长视野每设定各仅 10-15 次试验——4.4 分、6.7 分这类"提升"在十几次试验的噪声下极可能不显著。所有结论应按"厂商自评 demo 级证据"折价。
- **基线对比公平吗**：对手是 π0.5（Physical Intelligence）和 GR00T N1.7（NVIDIA），但都用作者自己的评测协议在作者的机器人上跑——跨实现的 VLA 对比高度依赖硬件标定、相机视角、动作空间对齐，主场优势无法排除。GR00T/π0.5 是否为各自最优配置未说明。
- **最强证据**：相对 vs 绝对动作的消融（成功率 33.7→55.0，附动作统计：relQpos 标准差仅 absQpos 的 31-37%）。这条有机制解释（局部运动回归 vs 全局位形回归）、有数据支撑、可迁移，是全文最扎实的发现，且不依赖与竞品的主观比较。
- **最可疑的数字**：Galaxea R1 Pro 的 "Take bowl out of microwave" 任务，VLA-2.0 progress 97.5 但 success 只有对应行错位——表格排版严重错乱（多行数字与任务名错位，如 Agilex overall 34.4 下方悬着 "0.0"），部分单元格数字无法可靠对应任务。这类关键结果表的排版混乱本身降低了可信度，读者无法逐格复核。整体 66.2/34.4 的 progress-success 巨大落差（进度做到六成六、成功只三成四）说明模型在"最后一厘米"普遍失败。
- **另一处软肋**：MoE>Dense 的证据只有一张 0.6B 规模的训练/验证曲线图（Fig 7），单点规模、无多 seed，"更有效的容量分配"这一因果 claim 支撑偏弱。
- **如果我是审稿人，会要求补充**：(1) 每个数字的 15 次试验方差/置信区间；(2) 竞品在其官方最优配置下的复现，或第三方裁判；(3) 正式部署模型的参数量、推理延迟、算力需求；(4) Dual-Query 蒸馏、DINO-Video、MoE 三者各自的独立消融（现在混在一起无法归因增益来源）；(5) 数据过滤淘汰的 40k+50k 小时里有多少是有用数据被误杀。
- **最小复现实验**：拿开源权重在单一双臂形态上复现相对 vs 绝对动作消融（不需要竞品对比），验证"相对动作提升成功率"这一最可迁移的核心 claim；预算取决于机器人硬件可得性。

## 可复用点（PM 决策）

- **何时采用**：① 做多形态机器人产品、需要一个模型跨平台复用——55 维统一表示 + 跨形态预训练是当前可行路径；② 长视野移动操作（开冰箱、擦灶台这类需要底盘+双臂+关节物体交互协同）；③ 想给现有 VLA 加时序预判能力——"未来预测当代理任务 + 表征蒸馏"是可移植的训练技巧。
- **何时规避**：① 单一固定形态的简单抓放——本文的全身统一表示和双查询蒸馏是过度工程，π0/GR00T 或更轻的模型够用；② 需要高成功率保证的生产场景——progress 高 success 低说明"最后一步精确操作"不可靠，别用在容错低的任务；③ 把技术报告的对比数字当采购依据——要求供应商在你的硬件上用统一协议重测。
- **供应商拷问清单**：
  1. 报的成功率是多少次试验的？有置信区间吗？progress score 和 success rate 差多少（暴露"最后一厘米"失败率）？
  2. 与 π0.5/GR00T 的对比是在谁的硬件、谁的评测协议下跑的？竞品用的是官方最优配置吗？
  3. 换一个没在训练集里的机器人形态，性能掉多少？（跨形态泛化是卖点也是软肋）
  4. 正式模型多少参数？单步推理延迟多少？机器人上实时跑需要什么算力？
  5. OOD（未见物体+扰动初始位姿）下成功率掉多少？（本文冰箱任务 ID 60% → OOD 13.3%，掉得很惨）
  6. 数据管线里第一人称数据的 SLAM/手姿态估计错误率是多少？污染了多少标签？

## 动手练习 💻（约 30 分钟）

练习目标：亲手验证本文最扎实的消融——"相对动作比绝对动作方差低、更易学"，理解为什么把预测目标从全局位形改成局部增量能把成功率从 33.7 提到 55.0。

```python
import numpy as np

rng = np.random.default_rng(0)

# ── 模拟一段双臂关节轨迹: 14个关节, 200个时间步 ──
T, J = 200, 14
# 绝对关节角: 各关节在不同工作区间缓慢移动(全局位形, 量程大、彼此偏置不同)
base = rng.uniform(-2.0, 2.0, J)                      # 每个关节的中心位置(差异大)
drift = np.cumsum(rng.normal(0, 0.05, (T, J)), axis=0)  # 缓慢漂移的动作
abs_q = base + drift                                  # 绝对关节角轨迹

# ── 两种预测目标 ──
abs_target = abs_q[1:]                                # 绝对目标: 直接预测下一时刻的全局关节角
rel_target = abs_q[1:] - abs_q[:-1]                   # 相对目标: 预测关节角的增量(局部运动)

# ── 论文核心观察: 相对动作的标准差远小于绝对动作 ──
print("绝对动作 std (逐关节):", np.round(abs_target.std(axis=0), 3))
print("相对动作 std (逐关节):", np.round(rel_target.std(axis=0), 3))
abs_pooled_std = abs_target.std()                     # 池化(所有关节所有步)标准差
rel_pooled_std = rel_target.std()
print(f"\n池化标准差  绝对={abs_pooled_std:.3f}  相对={rel_pooled_std:.3f}")
print(f"相对/绝对 比值 = {rel_pooled_std/abs_pooled_std:.1%}  (论文报告 31-37%)")

# ── 为什么低方差目标更易学: 模拟一个简单回归器在同样容量下的拟合误差 ──
def toy_regression_error(target, noise=0.1):
    # 预测器只能输出"目标均值 + 小扰动", 模拟有限容量模型
    pred = target.mean(axis=0) + rng.normal(0, noise, target.shape)
    return np.abs(pred - target).mean()               # 平均绝对误差

# 归一化到同尺度后比较(消除量纲, 只看"相对于自身方差的可学习性")
err_abs = toy_regression_error((abs_target - abs_target.mean(0)) / abs_pooled_std)
err_rel = toy_regression_error((rel_target - rel_target.mean(0)) / rel_pooled_std)
print(f"\n归一化后拟合误差  绝对={err_abs:.3f}  相对={err_rel:.3f}")
# 关键洞见: 相对动作把"回归每个关节的绝对位置(量程大、偏置各异)"
#          变成"回归局部小增量(集中在0附近、低方差)"
#          有限容量的模型在低方差、居中的目标上学得更好 —— 这就是 33.7→55.0 的来源
```

预期收获：亲眼看到相对动作的标准差是绝对的约 1/3（复现论文 31-37% 的数字），并理解"预测目标的统计形态"直接决定有限容量模型的可学习性——这是 VLA 动作表示设计里最实用、最可迁移的一条经验。
