# AutoTTS：LLM 自动发现测试时扩展策略

📄 **原文 PDF**：[[RAW/137 - LLMs Improving LLMs - Agentic Discovery for Test-Time Scaling.pdf]]

## PM 速判（3 分钟）

> **这篇论文给 PM 的一句话**：让 LLM Agent（Claude Code）自动发现最优的测试时计算分配策略——**$39.9 + 160分钟**的搜索成本，发现的策略在准确率-成本曲线上超越了所有手工设计的 TTS 基线；关键设计是用"离线回放环境"把每次候选策略的评估成本从"调用 LLM"变成"查表"。

## 核心机制

```
问题：
  测试时扩展（TTS）策略（何时分支/剪枝/深化/停止）都是人工设计的
  搜索这个策略空间需要反复调用 LLM，成本极高
  
AutoTTS 的解法：
  步骤1（离线）：预收集每道题的 128 条推理轨迹
  步骤2（搜索）：Agent 写代码定义控制器（何时 branch/probe/prune/stop）
  步骤3（评估）：用预收集轨迹回放评估控制器——无需调用 LLM
  步骤4（选择）：选最优准确率-成本帕累托前沿上的控制器
  
关键创新：
  ① 离线回放：把评估从"随机调 LLM"变为"确定性查表"
  ② Beta 参数化：控制器只暴露一个 β 参数（避免高维过拟合）
  ③ 执行追踪反馈：告诉 Agent "策略哪一步失败了"（而非只给成功/失败）
```

## 发现的控制策略（核心逻辑）

```python
# AutoTTS 发现的策略关键特征：
# EMA 置信度动量门（动态停止条件）
gate_fires = (
    ema_conf >= conf_thresh           # 置信度够高
    and ema_delta >= -delta_slack     # 置信度没在下降
)
# → 置信度高且稳定时提前停止

# 置信度趋势宽化（动态扩展条件）
want_widen = (
    total_spawned < max_branch_use    # 预算未耗尽
    and trend_weak                    # 置信度趋势弱（平台期/下降）
    and ema_conf < conf_thresh        # 还没达到停止阈值
)
# → 置信度增长停滞时添加新推理分支
```

这是 Agent 从数据中学到的"自适应推理分配"策略，而非人工设计的规则。

## 核心结论（带时间锚）

1. **"设计 TTS 环境"比"设计 TTS 策略"更有杠杆效应** 📅 2026
   把人类工程师的工作从"设计启发式规则"转移到"设计评估环境"——前者需要反复实验，后者一次性建好后可以支持无限次 Agent 搜索。

2. **$39.9 的搜索成本发现了超越手工基线的策略** 📅 2026
   Claude Code 在 5 轮搜索中探索了宽度-深度控制空间，发现了基于 EMA 动量的自适应分支策略——这种策略在人类直觉上不显然但在数据上有效。

3. **离线回放是元级别 TTS 发现的关键基础设施** 📅 2026
   没有离线回放，每次策略评估都需要调 LLM，成本不可接受；有了离线回放，评估成本接近零，Agent 可以在 160 分钟内完成上百次策略评估。

## 论文精读卡片

**一句话**：AutoTTS用$39.9+160分钟让Claude Code自动发现测试时计算分配策略，在AIME数学推理上发现的基于EMA动量的自适应分支策略超越所有手工设计的TTS基线。

**问题**：测试时扩展（TTS）策略（何时分支/剪枝/停止）全部依赖人工设计，搜索策略空间需要反复调用LLM，成本极高（每次评估都要跑推理）；而不同场景的最优TTS策略差异巨大，人工调优不可扩展。

**核心方法**：
- 离线预收集：每道题预采样128条推理轨迹（一次性成本）
- Agent搜索控制器：Claude Code写代码定义"何时branch/probe/prune/stop"的控制器，暴露单一Beta参数避免高维过拟合
- 离线回放评估：用预收集轨迹确定性查表评估控制器，无需再调用LLM

**关键图/公式**：发现的EMA门控策略——`gate_fires = (ema_conf >= conf_thresh) and (ema_delta >= -delta_slack)`（置信度高且稳定时提前停止）+ `want_widen = trend_weak and ema_conf < conf_thresh`（置信度增长停滞时扩展分支）；这种基于动量的自适应策略在人类直觉上不显然，但从数据中涌现出来。

**实验设置**：
- 规模/数据：AIME数学推理基准，Qwen3系列0.6B-8B模型，每题128条预采样轨迹
- 对比：5个手工设计TTS基线（固定分支、固定深度、Best-of-N等变体）

**最强证据**：仅用$39.9搜索成本发现的策略在准确率-成本帕累托前沿上超越所有手工基线；发现的控制器跨模型规模（0.6B-8B）泛化，无需为每个模型单独调优。

**最弱证据**：仅在AIME数学推理场景验证，泛化到其他领域（代码/写作/科学推理）未验证；离线回放的前提是128条预采样轨迹覆盖了足够多的执行路径，对分布外问题可能失效。

**可复用点**：离线回放环境设计——将"调用LLM评估"转化为"确定性查表"是降低元级别优化成本的通用工程模式，可用于任何需要反复评估策略的自动化优化场景。
