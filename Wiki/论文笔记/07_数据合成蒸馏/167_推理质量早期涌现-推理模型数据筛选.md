# 推理质量早期涌现：推理模型的数据筛选（TEMP）

📄 **原文 PDF**：[[RAW/167 - Reasoning Quality Emerges Early - Data Curation for Reasoning Models.pdf]]

> 发表：ICML 2026（第43届国际机器学习大会，Seoul, South Korea，PMLR 306）；arXiv:2606.26797v1 [cs.LG]，2026-06-25。代码/项目页：bigml-cs-ucla.github.io/TEMP-project-page/

## PM 速判（30秒）
> 一句话：论文证明"一条推理轨迹难不难、和其他样本像不像"这两个数据质量核心信号，只看**前100个token**和**前1k个token**（而不是完整的、可能长达91k token的推理链）就能可靠判断——用这个洞察设计出的TEMP方法，在两个模型架构、两个领域数据集上都超过现有基线（最高+1.7%准确率），同时把数据筛选阶段要处理的token量砍掉67%~91%。PM必须关注：这是把"用GPT-4o-mini给每条数据打分"这种当前主流、烧钱又慢的推理数据筛选范式，替换成"只用目标模型自己的loss做几次前向"的廉价方案——直接影响任何要蒸馏/精选长CoT SFT数据的团队的预算和迭代速度。

## 双层费曼 🗣️
> **给CEO**：训练一个会"深度思考"的AI模型，常见做法是找几千条高质量的解题过程给它学，但从海量候选题里挑出"够难、够多样"的好题，目前只能靠再请一个更贵的AI模型来一条条打分——慢且贵。这篇论文发现一个反直觉的事实：AI模型解题时，读题目、动笔算之前的"前几句话"就已经暴露了这道题有多难、这套解法有多独特，不需要看完整个解题过程再判断。基于这个发现，作者做出一套筛选方法，选出来的题目训练效果比现有方法更好，而且筛选过程省了七到九成的计算量。
>
> **给工程师**：核心方法TEMP分两步：①难度筛选——给预训练权重θ0加一次随机高斯扰动得到θ_rnd（约束扰动后loss/扰动前loss落在2~3倍区间），只算每条样本前100个token（"问题理解阶段"）在θ_rnd上的loss，此loss与LLM判定的难度的Pearson相关性显著优于全轨迹loss和response-length启发式，因为扰动会破坏预训练模型对复杂样本的后期记忆化，暴露出简单样本处于平坦宽谷、难样本处于陡峭尖谷的loss landscape几何；②多样性采样——沿"微调方向"v=θf−θ0（θf为任一同任务微调/开源模型）外插生成n个方向扰动checkpoint（而非用真实SFT轨迹的checkpoint，因为后者loss太平、样本分不开），只算每条难样本前1k token在这n个checkpoint上的loss向量，Theorem 3.1证明该loss向量的样本间差异可证明地上界微调期间的梯度差异，因此可据此聚类并在每簇挑选"脆性"（loss随扰动上升最快）的样本。

## 问题域定位 🎯
- **回应什么根本约束**：高质量长CoT SFT数据（如DeepSeek-R1蒸馏出的推理轨迹）的筛选，此前几乎全部依赖"用更强的LLM当裁判"（LLM-based difficulty/diversity filtering，如GPT-4o-mini打分、按response length代理难度）。这类方法既要为每条候选数据烧一次LLM API调用，又因为推理轨迹极长（论文数据集里最长91k token）导致loss/embedding/gradient类信号被token级噪声和文风差异淹没，实际效果常常不如预期（论文在实验中复现验证：S2L等基于真实微调loss的方法能在Llama3.1上排第二，却在Qwen2.5上几乎退化到随机水平，说明这类信号不稳健）。
- **之前卡在哪**：难度和多样性信号要么依赖昂贵的外部LLM打分，要么依赖真实微调过程中的loss/embedding/gradient——但SFT阶段模型参数变化小、loss landscape平坦，样本在loss空间里挤在一起分不开（论文Fig.4/5实证）；而如果用完整的长推理轨迹算平均loss，又被冗长文本的表面风格变化主导，掩盖了真正反映推理难度的信号。
- **开启/关闭了哪条技术路线**：开启了"早期token信号即可代理数据质量"的低成本数据筛选路线——本质上是把"数据筛选"的复杂度从"O(完整轨迹长度)+LLM调用"降到"O(100~1k token)+纯前向计算"。关闭/削弱了"必须靠强模型当裁判才能定义难度"这一假设——论文直接用ablation证明，仅靠预训练模型自身在扰动后的loss，就足以替代GPT-4o-mini式的难度判官。

## 核心机制

```
                     数据源 V = {V1, V2, ..., Vm}（如M23k的4个医学题库 / OpenThoughts-Math的4个数学题库）
                                            │
        ┌───────────────────────────────────┴────────────────────────────────────┐
        │ 阶段① 难度筛选（Sec 3.1）— 只读每条样本前 100 个 token                      │
        │                                                                          │
        │   预训练权重 θ0 ──随机高斯噪声扰动──▶ θ_rnd                               │
        │   约束扰动幅度：L(θ_rnd)/L(θ0) ∈ [2, 3]（校准依据见 Fig.3 相关性曲线）        │
        │                                                                          │
        │   对每条样本，只算"问题理解阶段"(前h≈100 token)在 θ_rnd 上的负对数似然loss    │
        │        L^i_pr(θ_rnd) = -Σ_j log p(x_j | x_<j, θ_rnd),  j=1..h            │
        │   （该loss与Gemini-2.5-flash-lite打的难度分相关性 > 全轨迹loss / 回答长度）   │
        │                                                                          │
        │   每个来源内部：按 L^i_pr(θ_rnd) 二分聚类                                   │
        │        低loss簇 → Vse（简单，丢弃）｜ 高loss簇 → Vsd（难，保留）              │
        │   来源难度打分：inherent d_in（Vsd内均值）、brittle d_br（扰动后-扰动前loss差） │
        │   预算分配：N_s = N · softmax(√(d_in·d_br))  —— 越难/越脆的来源分到越多预算   │
        └───────────────────────────────────┬────────────────────────────────────┘
                                            │  仅剩 Vsd（难题池）
        ┌───────────────────────────────────┴────────────────────────────────────┐
        │ 阶段② 多样性采样（Sec 3.2）— 只读每条样本前 1000 个 token                    │
        │                                                                          │
        │   参考方向 v = θf − θ0（θf：同任务已微调模型，可以是本任务或别处训练的模型）    │
        │   沿 v 方向外插生成 n 个"方向扰动"checkpoint：                              │
        │        θ_j = θ_{j-1} + η·(1+ε_j)⊙v   （θ1≈1.05×loss，θn≈3×loss）          │
        │   （注意：直接用真实SFT轨迹上的checkpoint效果差——loss landscape太平坦，       │
        │    样本互相分不开，Fig.4/5实证；外插扰动能保持优化几何但放大曲率/可分性）        │
        │                                                                          │
        │   对每条难样本，计算前1k token在n个θ_j上的loss，拼成"扰动loss向量" L_i        │
        │   Theorem 3.1：‖L_i − L_j‖ 有界 ⇒ 微调全程两样本梯度差有界（可证明的代理）    │
        │                                                                          │
        │   每个来源内部：按 L_i 聚类成 Ns/k 簇 → 每簇挑 L(θn)-L(θ1) 最大的k个"脆性"样本 │
        │   （脆性样本 = 模糊/边界任务、靠记忆走捷径的题、反常识题、OOD文风题）           │
        └───────────────────────────────────┬────────────────────────────────────┘
                                            │
                              汇总各来源 Ss → 最终难而多样的 SFT 数据集 S
```

## 设计决策解剖 ⚖️
| 决策点 | 他们的选择 | 被放弃的方案 | 为什么 | 这个选择何时失效 |
|---|---|---|---|---|
| 难度信号来源 | 在**随机扰动**的预训练checkpoint θ_rnd上，评估前100 token的loss | (1) 用GPT-4o-mini等LLM直接打分；(2) 用response length代理难度；(3) 用未扰动的原始loss | 扰动破坏了预训练模型对复杂样本的"后期记忆化"，暴露出简单样本处于平坦宽谷（扰动下loss稳定）、难样本处于陡峭尖谷（扰动下loss陡增）的真实几何；实测该信号与LLM难度标注的相关性优于全轨迹loss和response-length（Fig.3） | 扰动幅度必须校准在loss比值2~3倍区间，偏离该区间相关性明显下降（Fig.3曲线）；且该方法假设预训练模型已学到较好的通用特征——若目标领域与预训练分布差异极大（如全新符号体系），所有样本loss可能同样平坦，无法分辨难度 |
| 多样性/相似度信号来源 | 沿"参考微调方向"v=θf−θ0**外插**生成扰动checkpoint，在其上聚类前1k token的loss向量 | (1) 直接用真实SFT训练过程中的实际checkpoint做loss聚类（S2L做法）；(2) 用微调模型embedding做k-medoids聚类（Embedding Diversity）；(3) 梯度聚类 | 真实微调阶段loss landscape平坦、曲率低，样本在loss空间里挤在一起分不开（Fig.4/5实证）；外插扰动能保持相同优化几何但放大曲率，从而放大样本间loss差异；Theorem 3.1从理论上证明该loss向量差异可证明地上界微调期间的梯度差异 | 当参考checkpoint θf严重偏离真实最优微调方向时（如仅训练1/10迭代的严重欠训练checkpoint），近似失效、性能明显下降（Fig.11）；该理论还假设微调过程是"局部、低曲率、近线性"的——若目标任务需要模型学习与预训练完全不同的新表示，这一前提本身会被打破 |
| 簇内样本挑选标准 | 挑选 L(θn)-L(θ1) 差值最大（扰动过程中loss上升最陡）的"脆性"样本 | 簇内随机采样 / 簇中心点(medoid) | 脆性样本对应"模型靠记忆而非真正理解解出的模糊/边界任务"，是信息量最高的难例，能进一步区分同一loss簇内的样本质量差异 | 当数据源本身存在高比例标注错误/分布外噪声时，"loss随扰动剧增"可能只是标注错误而非真实推理难度——论文未做专门的噪声鲁棒性实验来排除这种误选可能 |
| 来源间预算分配 | 按√(d_in·d_br)几何平均做softmax分配，难/脆的来源分更多预算 | 均匀分配 / 仅按来源原始数据量比例分配 | Ablation显示去掉该权重导致准确率降0.26%，证明"把更多预算给更难来源"确有增益 | 当某来源实际难题数量不足以满足按权重算出的预算时（如M23k中PubMedQA仅29条），需要额外的预算再分配启发式（Algorithm 2），边界情况处理增加了工程复杂度 |

## 成本与量级 💰
- **SFT训练本身**：Qwen2.5-7B-Instruct / Llama3.1-8B-Instruct，5 epoch，batch size 16，lr 1e-5（前5%线性warmup+余弦退火），AdamW(β1=0.9, β2=0.95)，序列长度上限8k（M23k）/32k（OpenThoughts-Math，Qwen2.5-7B最大上下文）；用LLaMA-Factory框架。数据规模仅250~7340条（M23k全量），属于典型的小样本SFT，单机可行。论文**未披露** GPU型号、训练时长、美元成本。
- **数据筛选阶段的核心卖点——token效率**：基线方法需要处理完整推理轨迹（M23k平均较短，OpenThoughts-Math部分轨迹长达91k token）；TEMP只需处理每条样本前100 token（难度）+前1k token（多样性）。实测：M23k上基线约处理37.3M token，TEMP约12.1M token（约3倍节省）；OpenThoughts-Math上基线约处理352.9M token，TEMP约30.3M token（约11.6倍节省，这正是摘要里"91%更高效"这个数字的来源）。
- **隐藏成本**：多样性采样需要一个参考微调checkpoint θf（用于确定微调方向v）。Ablation（Fig.11）显示，即使θf不是在目标数据上专门训练的（如直接用开源的SynLogic-7B作为数学任务的θf），效果依然可用，只有"严重欠训练"（如仅2k iters，约为完整训练1/10）的θf才会明显拖累性能——这意味着最小可行配置不需要为筛选专门训练一个模型，借用任意同任务的开源微调模型即可。
- **最小可行配置**：1个预训练checkpoint θ0 + 1个同任务的开源/已有微调checkpoint θf + 每个来源1~2个随机扰动checkpoint（difficulty，Fig.12显示1~2个已足够）+ 8个方向扰动checkpoint（diversity，Fig.12显示8个最优）。对每条候选样本只需2次前向传播（100 token + 1k token loss评估），无需调用任何外部LLM API，无需真实执行一次完整微调训练。

**两个实验数据集的真实规模对比**（论文Sec 4.1）：

| 项目 | M23k（医学推理） | OpenThoughts-Math（数学推理） |
|---|---|---|
| 原始数据量 | 23,493条医学多选题，来自4个来源 | 56,370条数学题，来自4个来源 |
| 清洗方式 | 去重+去污染；剔除Qwen2.5-7B/32B-Instruct已能答对的简单题；剔除最终答案错误的蒸馏轨迹 | 沿用OpenThoughts-114k的启发式LLM难度/多样性过滤 |
| 推理轨迹来源 | 蒸馏自DeepSeek-R1 | 蒸馏自DeepSeek-R1 |
| 训练序列长度上限 | 8k token | 32k token（Qwen2.5-7B最大上下文） |

**六个基线方法一览**（论文Sec 4.2 / B.2，均为原本为指令微调或推理数据设计的代表性方法）：
- **Learnability**（Zhou et al., 2025，DavIR）：选微调前后loss下降最大的样本。
- **Middle Perplexity**（Marion et al., 2023）：按微调模型困惑度排序，选取中位数附近的样本（剔除最难/最易两端）。
- **Embedding Diversity**（Bhatt et al., 2024a）：用微调模型最后一层隐状态的平均embedding做k-medoids聚类，选中心点。
- **S2L**（Yang et al., 2024）：在真实微调过程中用一个代理小模型（本文用Qwen2.5-0.5B-Instruct）记录的loss轨迹上聚类，每簇等量采样。
- **M1K**（Huang et al., 2025）：论文对标的LLM-based难度+多样性过滤方法。
- **Random**：均匀随机采样。

## 证据审计 🔬
- **实验设计公平吗**：基线和TEMP用了同一套SFT超参数、同一批评测集，比较基础是公平的；但用于验证Fig.3相关性的"ground truth难度标注"用的是Gemini-2.5-flash-lite打分——这本质上也是一种"LLM-based difficulty"，论文用它来证明"我们的方法不需要LLM"多少有自我验证的味道（不过这仅用于离线相关性验证，不参与实际数据选择流程，性质上还算可以接受）。
- **最强证据**：Fig.7/8/9显示，在两个模型架构（Qwen2.5-7B / Llama3.1-8B）、两个领域（医学M23k / 数学OpenThoughts-Math）、多种预算规模（250~7340条）下，TEMP均排名第一；Table 1的序贯消融显示四个组件（难度筛选、来源预算加权、多样性采样、脆性选择）依次去掉后准确率从57.69%单调降到54.09%，每个组件都有独立贡献。这构成较完整的证据链，成立条件是：医学多选题+数学竞赛题两个领域、7B-8B规模模型。

**核心结果数字（选1k条数据时，Qwen2.5-7B-Instruct，10个医学benchmark平均准确率）**：Fig.7显示TEMP领先次优基线1.1个百分点（Llama3.1-8B上领先1.7个百分点）；S2L在Llama3.1上是第二名，但在Qwen2.5上"几乎退化到随机水平"（论文原话），说明真实微调loss轨迹这一信号本身不稳健、依赖具体模型架构。

**OpenThoughts-Math上的4个数学benchmark细分（Table 8，1k条数据，Qwen2.5-7B）**：TEMP平均43.91%±2.05%排名第一（次于它的是Embedding Diversity 43.50%±2.05%），但拆开看：AMC23上TEMP 59.17%明显领先；AIME24上Embedding Diversity（22.38%）反而略高于TEMP（21.11%）；AIME25上S2L（26.67%）明显高于TEMP（18.15%）；MATH500上多个方法接近（76~78%区间，TEMP 77.20%）。即"平均分第一"掩盖了在个别高方差、小样本benchmark（AIME系列每次仅约15题）上并不稳定领先的事实。
- **最可疑的数字**：摘要里"91%更token高效"取的是OpenThoughts-Math这个最有利domain的数字（352.9M→30.3M），而M23k上的实际节省只有约3倍（约67.6%）——headline用最favorable的domain数字，容易造成"全面91%高效"的错觉。另外Table 8显示，在AIME24上Embedding Diversity（22.38%）实际略高于TEMP（21.11%），在AIME25上S2L（26.67%）明显高于TEMP（18.15%），TEMP只是在4个数学benchmark的**平均分**上领先；AIME类竞赛题库题量很少（每次约15题），3个随机种子下标准差普遍在3~5%，个位数题目的对错就能造成好几个百分点的波动，"平均准确率最高"这个结论在数学榜单上的统计显著性其实并不牢固。
- **审稿人会要求补充**：①θf本身的训练成本/敏感性的完整实验（目前只做了"欠训练vs全量训练"两档粗粒度对比）；②在完全域外（非医学非数学，如代码/安全对齐）任务上的泛化验证；③标注噪声/脏数据鲁棒性——brittle selection是否会把标注错误误判为"脆性难例"选进训练集；④更大参数量模型（>10B）上的验证，目前只测了7B/8B。
- **最小复现实验**：不需要完整SFT训练，只需复现Fig.3的核心相关性证据——即"前100 token在随机扰动checkpoint上的loss，与LLM难度标注的Pearson相关系数"。做法：拿1个开源7B模型 + 几百条候选样本做前向loss评估（几十分钟单卡即可）+ 一次LLM API调用做难度标注（预算几美元），即可验证该信号是否在自己的目标领域也成立——这是性价比最高的验证起点，成立了再决定要不要搭建完整的TEMP两阶段筛选管线。

**超参数敏感性一览（Fig.12，M23k）**：论文对6个关键超参数做了敏感性分析，结论是方法整体鲁棒，但仍有明确的最优点——

| 超参数 | 候选范围 | 最优取值 | 敏感性 |
|---|---|---|---|
| 难度筛选用扰动checkpoint数 | 1~3 | 1或2（效果相近） | 低 |
| 多样性聚类用的token窗口 | Summary / 500 / 1k / 2k / Full | 前1k token | 低（与用完整回答几乎一样） |
| 每簇挑选的样本数k | 2/4/8/16 | k=4 | 低 |
| 难度筛选用的token数h | 50/100/200 | 100（h∈[100,120]区间均可） | 中（200 token时相关性下降） |
| 多样性聚类用的方向扰动checkpoint数 | 2/4/6/8 | 8 | 中 |
| 脆性样本采样用的token数 | Random / 100 / 500 / 1000 | 1000 | 中 |

## 可复用点（PM决策）
- **何时采用**：团队需要为推理模型蒸馏/构建长CoT SFT数据集（每条轨迹数千至数万token），且候选数据源规模较大（几万条以上）、需要反复迭代筛选标准，同时不想为每条候选数据都跑一次昂贵的LLM-judge打分或完整微调loss计算——这种场景下"early-token信号"思路能显著降低筛选成本，且论文验证了跨模型架构（Qwen/Llama）和跨领域（医学/数学）的迁移性。
- **何时规避**：①候选数据规模本身很小（几百条）时，人工或直接LLM判断难度/多样性可能比搭建"扰动checkpoint+聚类"的工程管线更简单可靠；②目标领域与模型预训练分布差异极大（如全新语言、全新符号体系）时，预训练模型本身可能对所有样本都学不出区分度，该方法的理论前提不成立；③没有任何同任务的参考微调模型θf可借用，且没有预算/时间自己先训一个像样的θf时，多样性采样阶段的效果会打折扣。
- **供应商拷问清单**（如果有团队/工具声称用了类似"早期信号数据筛选"技术）：
  1. 你们的难度/多样性信号是在哪个checkpoint、哪个token窗口上计算的loss？有没有像论文Fig.3那样做过"扰动幅度—与人工/LLM标注相关性"的敏感性验证，还是随手取了个经验值？
  2. 你们用来外插"微调方向"的参考模型θf是怎么获得的？如果是专门为这次筛选从零训练的，这个成本有没有算进"数据筛选降本"的对比账里？
  3. 有没有在你们自己的目标领域上，用留出的人工难度标注做过"信号—标注"相关性验证，还是完全照搬了论文里的超参数（比如h=100 token、8个方向扰动checkpoint）？

## 动手练习 💻
> 练习目标：用一个不依赖真实LLM的toy模拟，复现论文最核心的机制假设——"困难/脆性样本在扰动条件下loss上升更陡"，并验证这个"扰动后loss"信号比"扰动前loss"和"response length"这两个基线代理更能反映真实难度（对应论文Fig.3的核心论证逻辑）。

```python
import numpy as np

rng = np.random.default_rng(42)
N = 500  # 模拟500条候选样本

# 1. 每条样本的"真实难度" true_difficulty ~ U(0,1)（现实中来自人工/LLM标注，这里当作ground truth）
true_difficulty = rng.uniform(0, 1, N)

# 2. 模拟"response length"：难题通常答案更长，但加入较大噪声（论文指出这是个弱代理）
response_length = 50 + 300 * true_difficulty + rng.normal(0, 80, N)

# 3. 模拟"预训练checkpoint上的原始loss"：
#    论文的关键论点——预训练模型对复杂样本可能已经"记忆/过拟合"，
#    导致原始loss对难度的区分度很弱（简单和困难样本的loss都被压得很低）
base_loss = 0.3 + 0.1 * true_difficulty + rng.normal(0, 0.15, N)

# 4. 模拟"扰动敏感度"：这是论文的核心假设——
#    困难/脆性样本对权重扰动更敏感（处于陡峭尖谷），简单样本更鲁棒（处于平坦宽谷）
#    扰动敏感度与真实难度强相关，但仍保留一部分随机性模拟现实的不完美信号
perturb_sensitivity = 2.0 * true_difficulty + rng.normal(0, 0.3, N)
perturb_sensitivity = np.clip(perturb_sensitivity, 0, None)  # 敏感度不能为负

# 5. 模拟"扰动后checkpoint上的loss" = 原始loss + 扰动带来的额外loss（由敏感度决定）
#    这对应论文里 L^i_pr(θ_rnd)，只在"前100 token"这个窗口上评估
perturbed_loss = base_loss + perturb_sensitivity + rng.normal(0, 0.1, N)


def pearson(x, y):
    """计算Pearson相关系数，对应论文Fig.3衡量各代理指标与真实难度的相关性"""
    x, y = np.asarray(x), np.asarray(y)
    return np.corrcoef(x, y)[0, 1]


corr_response_length = pearson(response_length, true_difficulty)
corr_base_loss = pearson(base_loss, true_difficulty)
corr_perturbed_loss = pearson(perturbed_loss, true_difficulty)

print("=== 三种难度代理指标 与 真实难度 的相关系数（对应论文Fig.3）===")
print(f"Response Length 基线   : {corr_response_length:.3f}")
print(f"扰动前 loss（预训练ckpt）: {corr_base_loss:.3f}")
print(f"扰动后 loss（θ_rnd）    : {corr_perturbed_loss:.3f}   <- 论文核心结论：这个最高")

# 6. 模拟论文的难度筛选步骤：用扰动后loss把样本二分为"简单/丢弃" vs "困难/保留"
median_loss = np.median(perturbed_loss)
kept_mask = perturbed_loss >= median_loss
print(f"\n保留（困难组）样本的平均真实难度: {true_difficulty[kept_mask].mean():.3f}")
print(f"丢弃（简单组）样本的平均真实难度: {true_difficulty[~kept_mask].mean():.3f}")
print("（两组差距越大，说明扰动loss筛出的'困难组'确实更接近真实难题，机制生效）")
```

预期输出趋势：`扰动后loss`与`true_difficulty`的相关系数应明显高于`扰动前loss`和`response_length`（因为扰动敏感度被显式设计为与真实难度强相关），且"保留组"的平均真实难度应明显高于"丢弃组"——这正是论文Fig.3和Sec.3.1难度筛选逻辑的简化复现。实际LLM上验证时，把`true_difficulty`换成人工/LLM标注分数，把`base_loss`/`perturbed_loss`换成真实模型在两个checkpoint上的前向loss即可。
