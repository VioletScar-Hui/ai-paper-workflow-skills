# 🔄 复习队列（间隔重复）

> **基于遗忘曲线的自动复习调度。** 依赖 Dataview 插件自动计算今日应复习的笔记。

---

## 今日待复习

> 复习规则：根据笔记的 `复核日期` 字段，超过 1/3/7/14/30 天未复核的笔记依次出现。

```dataview
TABLE 
  file.folder AS 分类,
  choice(复核日期 != null, (date(today) -复核日期).days, 999) AS 距今天数,
  成熟度 AS 状态
FROM "Wiki/论文笔记"
WHERE 
  复核日期 != null AND
  (date(today) - 复核日期).days >= 
    choose(成熟度 = "✅", 30,
           choose(成熟度 = "🔧", 14,
                  choose(成熟度 = "🧪", 7, 3)))
SORT (date(today) - 复核日期).days DESC
```

---

## 从未复核的笔记

```dataview
TABLE 
  file.folder AS 分类,
  file.cday AS 创建日期
FROM "Wiki/论文笔记"
WHERE 复核日期 = null AND 笔记层级 != null
SORT file.cday ASC
```

---

## 复习统计

```dataview
TABLE 
  length(rows.file.link) AS 笔记数
FROM "Wiki/论文笔记"
GROUP BY choice(复核日期 != null AND (date(today) - 复核日期).days <= 1, "今日已复习",
                choice(复核日期 != null AND (date(today) - 复核日期).days <= 7, "本周内复习",
                       choice(复核日期 != null, "已复核（过期）", "从未复核")))
SORT rows.file.link DESC
```

## 概念复习队列

```dataview
TABLE 
  file.folder AS 分类,
  成熟度 AS 状态,
  length(file.inlinks) AS 论文引用数
FROM "Wiki/概念"
WHERE 成熟度 != "✅" OR length(file.inlinks) < 3
SORT 成熟度 ASC, length(file.inlinks) ASC
```

## 使用说明

### 复习层级（基于间隔重复原理）

| 成熟度 | 复习间隔 | 说明 |
|--------|---------|------|
| 🧪 实验性 | 3 天 | 新概念/论文，频繁复习建立记忆 |
| 🔧 发展中 | 7 天 | 已理解但未内化 |
| ⚪ 待补充 | 3 天 | 内容不全，需尽快补完 |
| ✅ 成熟 | 30 天 | 已内化，低频维持 |

### 工作流

1. 每天打开 `复习队列.md`
2. 从"今日待复习"列表中选择笔记
3. 快速浏览（3-5 分钟/篇）
4. 更新 `复核日期` 为当天
5. 如发现笔记过时或错误，更新内容

> 💡 **前置条件**：论文笔记需包含 `复核日期` 字段（格式：`复核日期: 2026-07-04`）。
