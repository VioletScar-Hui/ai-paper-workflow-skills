# AI Paper Workflow Skills

AI paper workflow repository for agent skills and research-paper operations.

This repository collects an AI paper library, paper notes, workflow rules, and the future skill suite for end-to-end AI research paper workflows: search, discovery, PDF acquisition, verification, metadata normalization, organization, reading, deep analysis, comparison, synthesis, literature review, and knowledge-base construction.

## What This Repository Is For

Use this repository when you need agent workflows for:

- AI paper search and discovery
- arXiv, DOI, GitHub report, model card, and technical report lookup
- Paper PDF downloading, validation, renaming, and organization
- Chinese and English paper-title normalization
- Screenshot or copied-list paper intake
- DAIR Academy weekly paper list processing
- Latest model-company paper audits
- Paper reading, summarization, deep-dive analysis, and comparison
- Literature review, survey writing, research maps, and knowledge-base building
- Obsidian, Markdown, CSV, and manifest-based research workflows

## Current Contents

- `RAW/`: downloaded AI research paper PDFs and download manifests.
- `Wiki/`: structured paper notes, concept notes, topic indexes, and research maps.
- `digest_rule.md`: paper digestion and note-generation rules.
- `_alisa_llm_book_raw.md`: long-form LLM learning notes.
- `SKILL_INDEX.md`: discovery keywords and planned skill surfaces for agent skill search tools.

## Planned Skill Suite

The repository is intended to evolve into a skill group with focused skills such as:

- `paper-intake`: extract paper candidates from screenshots, copied lists, newsletters, Markdown, CSV, or mixed Chinese-English inputs.
- `paper-search`: resolve official paper titles, arXiv IDs, DOI links, project pages, GitHub reports, and model cards.
- `paper-pdf-acquisition`: download, verify, rename, and organize PDFs with manifests.
- `paper-metadata-normalizer`: normalize titles, authors, dates, venues, source URLs, and filenames.
- `paper-reading`: extract sections, claims, methods, experiments, limitations, and implementation clues.
- `paper-deep-dive`: produce structured single-paper analysis.
- `paper-comparison`: compare multiple papers across methods, benchmarks, novelty, limitations, and practical implications.
- `paper-synthesis`: create literature reviews, taxonomies, timelines, trend reports, and open-problem lists.
- `paper-knowledge-base`: maintain Obsidian, Markdown, CSV, and JSON indexes for long-running research work.
